9 questions, one table

9 questions, each comparable item by item with its peers.

Model & openness

Official stance: 500+ models at zero markup: the Kilo Gateway connects hundreds of models through one API (streaming, BYOK, usage tracking); Auto Model routes automatically across Efficient/Frontier/Free tiers; BYOK has its own official page (bring your own key and use it directly); local models via Ollama / LM Studio also have official pages. Billing has three parts: Free-tier usage is billed separately (at the provider's list price), Kilo Pass, Teams per-seat subscription, Enterprise (official pricing page; concrete prices are not collected by this site per D9).

Where it runs

Open source (GitHub MIT, main repo Kilo-Org/kilocode): VS Code extension + JetBrains plugin + CLI + Kilo Desktop (beta). Official docs state explicitly that Kilo CLI is a fork of OpenCode (supporting the same configuration). Cloud Agents: an isolated Linux container per session (Node.js/git/gh/glab preinstalled, apt available), automatic branch creation with continuous pushing, ephemeral environments — official stance: "no local machine required" (translated).

Local files

The IDE extension/CLI processes your codebase on your own machine (open source, auditable by you); Cloud Agents run inside vendor-hosted isolated containers, with the repo cloned into the container and automatic branch management. Storage and retention policies for code inside containers have not been verified item by item.

Tasks after shutdown

Cloud Agents are the hosted surface: start cloud sessions from any device with automatic git management; there is also Automation (scheduled/event automation, the docs have an Automate section), Code Reviewer (AI PR review), and Slack integration (use Kilo from Slack). The official homepage claims "5M+ developers".

Tools & extensions

MCP has official pages (Overview + Integrations); Custom Rules (custom rule files); Custom Modes; shared custom agents (Teams surface); the kilo-marketplace extension market (fork-and-submit flow has an official page).

Context & memory

Sessions & Sharing and Session History and Search have official pages; Custom Rules provide persistent project instructions. An automatic cross-session memory mechanism has not been verified in any official statement.

Permissions & limits

The official settings pages form a system: Auto-Approving Actions, Sandboxing, Cost Controls and Usage Safeguards. Enterprise surface: SSO/SAML, SCIM, audit logs, data residency (EU Sovereignty official page), SLA, restricting available models/providers, Shared Private Gateway BYOK (official pricing/enterprise pages).

Best for

Fits: people who want open source they can audit + 500+ models at zero markup + full BYOK/local-model support, VS Code/JetBrains/CLI/cloud multi-form, free start with pay-as-you-go. Does not fit: people wanting strong vendor-backed governance narratives (an enterprise surface exists but the entity is an open-source community company); people looking for the "official Roo Code successor" (Roo's official shutdown notice points to ZooCode/Cline and does not mention Kilo — see pitfalls).

Name history

Domain migration: kilocode.ai → kilo.ai (308 redirect measured 2026-10-22); the product name remains Kilo Code. Lineage with Roo Code/Cline: community consensus holds Kilo descends from a Roo Code fork, but the official docs never state this lineage (officially stated only that the CLI is an OpenCode fork) — this site records the official stance.

Top misconception

  • The domain moved to kilo.ai (old kilocode.ai 308-redirects) — many old tutorials/links still say kilocode.ai; raw docs markdown actually lives on kilocode-docs.vercel.app
  • 'Kilo is the Roo Code successor' is community lore, not an official statement — Roo Code's official shutdown notice (2026-05-15) recommends ZooCode (a community fork) and Cline, and never mentions Kilo; keep the two claims' sources separate
  • The Free tier's 'free' means no subscription — model usage is billed separately at provider rates (the official pricing page says usage billed separately), unlike flat monthly-credit tools
