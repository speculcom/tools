Model & openness

Anthropic's own Claude family.

v2.1.284 (2026-09-28) added Claude Sonnet 5.5 (claude-sonnet-5-5). The official notes it is the default Sonnet model on the Anthropic API. Spec is 1M context (API pricing on the official pricing page; not stored by this site).

Where it runs

A local process in the terminal; lifecycle bound to the terminal session. The repo includes .devcontainer for containerized development; sessions land in ~/.claude and can be resumed with continue/resume, but nothing keeps running after the terminal exits.

Local files

The permission model is strongly tied to the working directory —

the CHANGELOG records that auto mode asks "before reading files outside the working directories". It also added a "Yes, but ask again next time" option. That means: allow this one read, and keep asking afterwards.

1M context tier (see model_access).

Tasks after shutdown

The terminal form needs a resident client, but the official has a cloud form that keeps running after shutdown.

Official claude-code-on-the-web wording: "A cloud session is a Claude Code session that runs on cloud infrastructure instead of on your machine... The session keeps running after you close your laptop."

The CLI creates a cloud session with claude --cloud (the old --remote is an alias), and claude --teleport pulls a cloud session back into the terminal to continue;

Routines (created in the CLI via /schedule) run on Anthropic-managed cloud, official wording: "they keep working when your laptop is closed".

Cloud sessions and routines require a paid Pro / Max / Team or Enterprise seat.

Quotas and limits follow the plan. The official routines page has a standalone "Usage and limits" section.

Tools & extensions

MCP support is complete and continuously strengthening —

v2.1.284 added /mcp reconnect all. It retries all failed-or-unauthenticated MCP servers in one shot.

The same version fixed an issue: on session resume, MCP tool calls reported "No such tool available" while the server was actually still connecting. It now waits up to 10 seconds.

Context & memory

The context-compaction mechanism has explicit boundary handling —

v2.1.284 fixed a persistent error: when the request is still too long after compacting, it kept reporting "Prompt is too long". It now compacts once more, keeping less of the recent conversation.

That shows it genuinely has multi-round compaction, and edge cases are being patched continuously.

Permissions & limits

The granularity of its permission design is the finest in this category:

  • auto mode asks per path (reads outside the working directories need confirmation), and offers an "allow this once" middle option;
  • managed policies support availableModels and enforceAvailableModels to control usable models, and warn at startup when the policy mismatches;
  • /usage shows quota consumption and limits.
Best for

Users who value controllable permissions, need the MCP ecosystem, and want Anthropic's official models. Not a fit for scenarios needing an open-source license or self-hosting (the license is explicitly proprietary).

Permission design: the finest in this category

① Asks per path, with an "allow just this once"

v2.1.284 added an option:

Added a "Yes, but ask again next time" answer to auto mode's prompt
before a read outside the working directories, so you can allow that one
read and still be asked about later ones

This design deserves its own record. Most tools' approvals have only two states — allow / deny. Claude Code offers a third state: allow this once, but keep asking.

It resolves a real dilemma:

  • allow globally → lose the protection
  • confirm every time → workflow interruptions

② Managed policies control usable models

Added Claude apps gateway startup warnings when a managed policy's
availableModels is empty, or leaves out the model Claude Code starts on
without setting model or enforceAvailableModels

In enterprise scenarios:

  • usable models are controlled by the availableModels policy
  • enforceAvailableModels decides whether it is enforced
  • policy mismatches warn at startup — no silent degradation

③ Quota visibility

Added dollar amounts to the Claude apps gateway spend limit in /usage
and the status line
