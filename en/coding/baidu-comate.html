Baidu Comate (Wenxin Kuaima) is Baidu's AI coding family: a standalone Comate AI IDE + plugins for VS Code/JetBrains/Visual Studio/Xcode + CLI, with a model menu dominated by domestic LLMs (DeepSeek/GLM/Kimi/MiniMax switchable, enterprises can add Qianfan providers), a full extension stack (Skills/Rules/Subagents/MCP/Memory/Automation) and personal/enterprise/private-deployment tiers — 'data stays in-domain' private deployment is its official compliance flagship.

When to use it, when not to

Fits: domestic-compliance and private-deployment narratives (finance/healthcare named by the official pages), broad IDE coverage (including Xcode/Visual Studio), enterprise console + AgentHub asset hub. Not a fit: wanting an overseas frontier-model menu (the official model page is domestic-first); wanting personal BYOK with arbitrary keys (enterprise adds Qianfan/third-party providers; personal BYOK not verified).

Model & openness

The official "Models" docs page lists the selectable roster: DeepSeek V4 Flash/V4 Pro, GLM-4.7/5-Turbo/5.0/5.1/5.2/5v-Turbo, Kimi-K2.5/K2.6, MiniMax M2.5/M3/M2.7 — note the main line is third-party domestic LLMs, not just the ERNIE family; enterprise users can additionally add third-party model-provider APIs (the official page names the Baidu Intelligent Cloud Qianfan ModelBuilder roster). Switching goes through the Auto button in the chat box or the model-selection page (the official documents both methods).

Where it runs

A full form family (official docs navigation): Comate AI IDE (standalone IDE), VS Code / all JetBrains / Visual Studio / Xcode plugins, CLI; the enterprise console (permissions/usage/knowledge management/instruction management/open center) plus Deepwiki and AgentHub enterprise pages. Personal / Enterprise / private-deployment editions come in three tiers (the official FAQ spells out the differences: license management, data reports, large-scale private deployment).

Local files

Plugin/IDE/CLI forms work on local code; the official FAQ states that SaaS inference must pass the preceding context of the file being written to the model, and promises (translated from the official wording) "no subsequent accumulation, analysis or processing is done with this uploaded code"; under private deployment the models and services all sit in the customer's private domain — data never leaves the domain (per the FAQ wording).

Tasks after shutdown

Mission Mode (end-to-end delivery toward an explicit goal: autonomously decomposing goals and executing until done) and Spec mode (spec-driven) both have official pages; Automation (scheduled/event-driven automation) as an extension capability has its own page; the Comate NEXT plan (cloud workbench, autonomous agent collaboration) is per the official docs page.

Tools & extensions

Extension capabilities all have official pages: Subagent (built-in Explore subagent with its own independent context window), Skills (open-standard capability packs), Rules (custom instructions: code standards / framework preferences / project conventions), MCP, Command, Memory; the "@" shortcut adds File/Folder/Terminal/Doc/Rules context, the "/" shortcut adds Skills/Commands/Subagents.

Context & memory

Memory has an official page (cross-session memory); code indexing has an official page (repo-level index); enterprise-side knowledge management (private-domain knowledge injection). The built-in Explore subagent handles codebase exploration.

Permissions & limits

Accounts run on the Baidu Intelligent Cloud system; the enterprise console has permission management / three-level roles (enterprise admin / department admin / regular member per the enterprise docs); approval details for Agent file/terminal operations were official docs do not itemize every sub-detail.

Best for

Good fit: domestic compliance and private-deployment narratives (finance/healthcare customer segments are named by the official side), an IDE full family (including Xcode/Visual Studio that peers rarely cover), switchable domestic-model roster, enterprise console + AgentHub asset middle platform. Not a fit: needing an overseas frontier-model roster (the official model page's main line is domestic models), needing BYOK with any personal key (the enterprise side goes through Qianfan/third-party providers; personal BYOK is not itemized in official docs).

Name history

Brand history: Comate (2023-06 invite-only beta on Baidu Intelligent Cloud) → Comate X (2023-08 commercial edition) → Chinese name "Wenxin Kuaima" (2024-06 brand refresh at the ERNIE model conference); the official sites kuaima.baidu.com and comate.baidu.com both work in parallel, docs live at cloud.baidu.com/doc/COMATE — when searching, recognize both Comate and Wenxin Kuaima.

Top misconception

  • The Chinese name Wenxin Kuaima and the English name Baidu Comate are the same product (official rebrand 2024-06) — the site now leads with kuaima.baidu.com while the old comate.baidu.com still works
  • A 2026-09-07 media report (Jiemian via Cailianshe) says Comate merged into the general-agent platform DuMate (Baidu Dazi) — no official announcement was found by this site; the official site and docs remain independently active. Record both claims separately; do not treat it as retired
  • The current official model menu is mostly third-party domestic LLMs (DeepSeek/GLM/Kimi/MiniMax) — the old impression 'Comate = Wenxin model only' is outdated; enterprises can additionally add Qianfan and other providers
  • On the SaaS side, the code context of the file you are editing is sent server-side for inference (official FAQ), with a no-retention/no-processing promise; the official path for sensitive data is the private-deployment tier — don't assume 'plugin = fully local'
