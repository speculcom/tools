CodeBuddy is Tencent Cloud's three-surface coding assistant (plugin / AI IDE / CLI): Hunyuan as the anchor with other LLMs pluggable, Figma-to-code and one-click CloudStudio deploys; the Hunyuan model's filing number is published in the official docs.

When to use it, when not to

Fits: mainland teams wanting the compliance narrative (Hunyuan is filed), build-to-deploy inside the Tencent Cloud ecosystem (CloudBase/CloudStudio), switching across plugin+IDE+CLI on one account. Not a fit: self-selecting a global model list; deep dependence on overseas SaaS integration chains.

Model & openness

The official docs state explicitly: besides Tencent's self-developed Hunyuan LLM, other LLMs can be connected and switched (the official product-overview page names DeepSeek as an example). The concrete selectable list follows versions; kept at official category level. The international edition (codebuddy.ai) and domestic edition (codebuddy.cn) are two lines whose model surfaces may differ — each official page is authoritative.

Where it runs

Official framing: "plugin, IDE and CLI cover all development scenarios" — the IDE plugin (VS Code / JetBrains family), the standalone AI IDE (codebuddy.cn/ide), and the command-line form each have official docs pages. Execution happens on your machine (common to the plugin/IDE/CLI forms; this site's judgement — the official does not state execution location page by page).

Local files

Code lives in your local editor/project. The IDE form's deployment line (CloudStudio one-click deploy: a sandbox environment generates a share link) uploads artifacts to the Tencent Cloud side — upload scope and retention policy kept at official category level.

Tasks after shutdown

Permissions & limits

Account system (Tencent Cloud accounts). The enterprise edition has an admin console (audit logs, custom secure-coding instructions, etc. — paraphrased from official Tencent Cloud developer articles). Data surface: the official leads with a "meets domestic security requirements" compliance narrative (Tencent Cloud official PDF wording, contrasted with ChatGPT).

Best for

Good fit: domestic teams wanting a compliance narrative (Hunyuan is filed), one-stop build-to-deploy inside the Tencent Cloud ecosystem (CloudBase/CloudStudio), plugin + IDE + CLI switching under one account.

Not a fit: wanting to self-select from a global model list (the model surface follows what the official lists), deep dependence on overseas SaaS integration chains.

Top misconception

  • The domestic edition codebuddy.cn and the international edition codebuddy.ai are two lines — don't infer features or model availability from one to the other
  • 'Filed' in the official wording refers to the Hunyuan model (filing no. Guangdong-TencentHunyuan-20230901, published in official docs) — it does not mean every product surface has its own filing; keep the subject precise when relaying
  • One-click CloudStudio deploys push artifacts into a cloud-side sandbox — 'code stays on your machine' does not mean 'artifacts never leave it'
