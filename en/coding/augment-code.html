Model & openness

The official Available Models page lists the full roster: the Anthropic Claude family (Fable 5.1/5, Opus 5/4.8/4.7/4.6, Sonnet 5.5/5, Haiku 4.5), Google Gemini (3.8/3.7 Flash, 3.1 Pro), OpenAI GPT (6.1 Sol, 6 Astra, 5.6 Sol/Terra/Luna, 5.5), xAI Grok 4.6/4.5, Zhipu GLM 5.3 Flash/5.2 and Moonshot Kimi K3/K2.7 Code (hosted on Fireworks/Baseten), plus in-house Prism (a model ensemble combining Claude and GPT; the Prism option routes across curated model families). Billing is token-based (Token-Based Pricing page: three segments — LLM tokens + Cosmos compute + service fee).

Where it runs

The main line is the Cosmos platform (official Introduction: five building blocks — Environments/Experts/Sessions/Capabilities/Triggers): it chains plan-implement-review-feedback into a repeatable Software Factory workflow (four official loops: Requirements→Ticket, Ticket→PR, PR→Merge, Signal→Ticket). Environments come in three flavors: Augment-hosted cloud sandbox, your own VM/physical machine (self-hosted daemon), or even your local laptop. There is also the Auggie CLI (terminal agent: repo implementation / code exploration / running tests / CI automation) and IDE extension surfaces for VS Code / JetBrains.

Local files

IDE extensions and the Auggie CLI work on local codebases; Cosmos's Environments decide where the code lives — hosted cloud sandbox, self-hosted daemon (running on your own infrastructure, configured via daemon-config.json for workspace and isolation) or local. The self-hosted surface is an official first-class citizen (the official page explicitly says own virtual or physical infrastructure).

Tasks after shutdown

Cosmos leads with long-horizon multi-step delivery: durable environments, scheduled automations, cross-repo cross-tool coordination (wording from the official llms.txt usage guide); Triggers wire events into the loop. The official narrative is an "always-on software delivery system" — running continuously from spec to verification.

Tools & extensions

The MCP surface has multiple official pages: Cosmos Experts connect MCP servers (MCP Registry), CLI/IDE-side MCP configuration, Context Engine MCP (plugging the context engine into any agent via MCP), MCP context hookup for Code Review; the official side also ships a Docs MCP server (Streamable HTTP) so external agents can query Augment docs.

Context & memory

The signature is the Code Context Engine: the official stance is a world-class context engine with structured cross-codebase understanding; it is exported as MCP for other agents to use (Context Engine MCP page). Wisdom-class context (PR history, business requirements) is expanded on the Software Factory loop pages.

Permissions & limits

Enterprise positioning (the enterprise-grade stance runs through the official docs): Trust Center and Status Page entries sit in the navigation; the Analytics API uses scoped OAuth tokens or service-account bearer tokens, with write permissions requested on demand (per the official llms.txt). Tool permissions are enforced in the Auggie CLI and Cosmos cloud agents, but not in the IDE extension (official Tool Permissions page); Standard and Business cap at 50 seats while Enterprise is custom (official Pricing page).

Best for

Good fit: the enterprise "software factory" narrative — agent pipelines across the SDLC (ticket→PR→merge→monitor), self-hosted environments running agents on your own infrastructure, one of the fullest frontier-model rosters (with in-house Prism routing). Not a fit: looking for a personal free tier to get started (the main line is enterprise delivery with token billing); readers who need product ownership to be stable — since 2026-10 the Cosmos/Auggie CLI/Context Engine assets have been joining Harness.
