8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

Powered by DeepL’s own translation models; model parameters are not public. Glossary and document translation vary by tier.

Where it runs

Available through web, desktop app and API; translation happens in DeepL’s cloud.

Local files

Supports document translation with partial layout preservation; local files must be uploaded and cannot be batch-scanned from a directory.

Tasks after shutdown

Single documents return immediately and document jobs run within a session; there is no background agent that survives shutdown. Tasks are triggered per request and no resident agent remains.

Tools & extensions

Glossaries, document translation, API and browser extensions; can integrate with CAT tools and internal systems.

Context & memory

Context is mainly the current text, glossary and document; cross-project memory is limited. Cross-document and cross-session memory is limited, so complex work needs manual context and source citations.

Permissions & limits

Pro data processing and retention terms follow the contract; glossaries and translation memory may contain client-sensitive content.

Best for

Fits: technical documentation, assisted contract translation and teams that need terminology consistency. Does not fit: replacing legal review or creative localisation.
