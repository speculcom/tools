8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

In-house model line + open weights: Mochi 1, an open-source text-to-video model (GitHub genmoai/mochi, Apache-2.0, 3,757 stars, pushed 2026-10-22, GitHub API verified the same day); the in-product model-selection surface sits behind a login wall, and the exact tier follows the signed-in UI.

Where it runs

Web (genmo.ai, /playground 200); product generation on the vendor's cloud. Open weights + training/inference code can run locally (provided in the repo) — self-running is a repo-level fact; the product itself ships no offline client.

Local files

Product works are stored account-side in the cloud; open weights plus training/inference code go local once downloaded (Apache-2.0). The product ships no offline client — self-running is the Mochi repo surface, not in-product inference.

Tasks after shutdown

A product generation request queues on the vendor cloud, with waiting time varying by tier and queue; the product surface has no pause, resume or task-position control. Local Mochi inference is managed by the user's own process and stops when the machine shuts down.

Tools & extensions

Text-to-video (the Mochi 1 line); the homepage headlines the "Open world models" narrative; /docs and /api both 307 into a login wall, so public product documentation is limited and editing/interaction follows the playground UI.

Context & memory

Works are organised by account; the product surface has no cross-session memory entry. Reusable Mochi weights and code are asset reuse, not conversation context or persistent memory.

Permissions & limits

Account + subscription system (/pricing 200, D9: prices not collected); the training-use switch sits in account settings, with the exact path following the signed-in UI; training/commercial freedom of the open-weights repo follows Apache-2.0 itself.

Best for

Fits: creators and researchers who want open weights to self-run (Apache-2.0 is a rare permissive tier in this category), world-model narrative tracking, creative experiments. Does not fit: mainland compliance scenarios (not serving the mainland), enterprise SLA as the headline (no SLA commitment on the public page).

Licence and terms of use

Product free + subscription (pricing page direct-fetched 2026-10-30); the open-weights line (genmoai/mochi) is Apache-2.0 (LICENSE verified via GitHub API the same day). Licensing of product output is governed by the terms page, details not verified line by line.
