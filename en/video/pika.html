8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

First-party plus aggregated: the product runs Pika 2.5 (image/text-to-video at 480p/720p/1080p, 5/10 s) alongside partner models such as Seedance 2.5, MiniMax H3, GPT Image 2.5, Nano Banana 2.1, Seedream and ElevenLabs/Pika Music/Speech/SFX. Pika API Club claims 100+ video/image/audio models through one API (2026-11-21).

Where it runs

Web/app at pika.art plus an asynchronous API (https://api.dev.pika.art, X-API-Key auth); generation runs in the vendor cloud, with API billing separate from product credits (2026-11-21).

Local files

No local model: references arrive as public URLs, or via POST /v1/media/uploads for a five-minute presigned upload followed by a permanent Pika CDN URL; finished video sits at output.video.url, and DELETE /v1/media/jobs/{id} erases the media plus the submitted prompt and parameters (2026-11-21).

Tasks after shutdown

Async jobs: submission returns id and status=queued, clients poll GET /v1/media/jobs/{id} until completed/failed/cancelled and read the download URL on completion, with webhooks also available. A 429 carries Retry-After, and 503 should be retried with backoff (2026-11-21).

Tools & extensions

Pikaffects (23+ physical effects such as cake-ify, melt, levitate and crystalize), Pikaframes (interpolation across 2–5 stills), Pikadditions, Pikaswaps, Pikastream live sessions, Video/Image/Music/Speech/SFX Studio, Camera Director, Motion Transfer, Extend Video, Relight, Color Grade and Character Studio (2026-11-21).

Context & memory

Works are organised in Library/Projects, and characters and elements saved to the Library can be reused across generations (Character Studio produces a character sheet); PikaStream is conversational real-time interaction. Cross-session chat memory is not part of the product, so reuse relies on explicitly saved assets (2026-11-21).

Permissions & limits

Free/Starter/Creator/Fancy subscriptions plus credits; paid tiers include commercial rights, Free does not, and current downloads are watermark-free on every tier. Pika may use uploads and creations to improve its services/models, third-party models add their own terms, and API billing is separate and does not consume Pika credits (2026-11-21).

Best for

Fit: social short effects (Pikaffects-style), image-to-video, multi-shot clips, reusable character/product consistency and API batch production. Not fit: cinematic long takes, fully offline work or commercial use on the Free tier (2026-11-21).

Licence and terms of use

Free + subscription. Governed by the official terms page (pika.art/terms-of-service, direct-fetched 2026-10-22); commercial rights vary by plan, details not verified line by line.
