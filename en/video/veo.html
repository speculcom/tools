8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

Model versions disclosed on Google's official release line: Vertex AI release notes record Veo 3.1 GA (2025-11-17 entry), Veo 3.1 reference-to-video and video extension previews, Veo 3.1 Lite (2026-04-02 entry, officially called the most cost-effective Veo on Vertex AI) — verified via proxied direct fetch 2026-10-21.

Where it runs

Delivered via the Gemini API / Vertex AI cloud APIs and Google AI subscription plans (product entries such as Flow); generation processed on Google's cloud, no models run locally.

Local files

Supports reference-image input (the reference-to-video capability is in the Vertex release notes entries); retention of input content is in the permissions axis.

Tasks after shutdown

The API is request-poll based (generation tasks submitted then retrieved); no official statement of a "keep-running-after-shutdown" form.

Tools & extensions

The main form is a model interface (Gemini API / Vertex AI) integrated by Flow, third-party editing and agent workflows; outputs carry watermarks and SynthID provenance marks.

Context & memory

Generation is task-based, no cross-session memory form; context is organized by the caller — reference-to-video and video extension are in-request/across-task linking capabilities (see the Vertex release notes entries), not session memory.

Permissions & limits

Official Gemini API Additional Terms (effective 2026-03-23): content submitted and generated answers on non-paid services (AI Studio, free quota) are used to "provide, improve and develop Google products and machine-learning technology", and human reviewers may read them; paid services are not used to improve products and are handled under the data-processing additional terms. EEA/Switzerland/UK users are treated as paid even on the free quota.

Best for

Video-generation users and teams already in the Google cloud/Workspace ecosystem needing enterprise-grade data terms (paid means no training). The free-quota line does get trained — don't conflate them; for scenarios that care about provenance marks (SynthID) this is a plus.

Licence and terms of use

Official Gemini API Additional Terms, 'Use of Generated Content': 'Google won't claim ownership over that content.' Commercial use must comply with applicable law, and API-returned content may require attribution to your users. Google notes outputs may be similar across users and reserves watermarking and SynthID marks.

When something fails

Account and permissions · Rate limits and retries · File-reading issues

Top misconception

  • Applying “paid means no training” to the free quota — free-line content and answers are used to improve the model (EEA/Switzerland/UK exceptions)
  • Applying the Gemini Apps privacy notice to the API — two documents, two sets of terms
  • Assuming outputs are exclusive — the official docs say different users may get similar outputs
