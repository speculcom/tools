8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

Digital-human video lines: Avatar, Voice (dubbing/cloning) and Translation (video translation and lip-sync). Official pages do not disclose model-by-model versions; check the product capability table and API docs (2026-11-21).

Where it runs

Web (heygen.com) plus API (developers.heygen.com); generation runs in the vendor cloud, and the API returns a video_id for an asynchronous job that the client polls or receives via webhook. No model runs locally (2026-11-21).

Local files

Works live in the account cloud, with generation history visible on the web works page. Download URLs from the API expire after seven days and must be retrieved within that window; downloads then belong to the local machine. The official FAQ says 100% of user data is not used for model training (2026-11-21).

Tasks after shutdown

Generation queues asynchronously in the cloud: the API returns a video_id, and the client polls status or receives webhooks, so jobs do not depend on the local machine being online. Official pages offer no pause/resume queue panel; batch production is orchestrated through the API state machine (2026-11-21).

Tools & extensions

An avatar library plus real-person cloning (consent-gated), voice cloning, video translation with lip-sync, Interactive Avatar Streaming API, Template API and webhook events. The official API docs list Avatar, Photo Avatar, Video Translate, Streaming and Templates separately (2026-11-21).

Context & memory

Work is organised by project or brand space, and avatar assets provide cross-video consistency and context. The official FAQ and product pages list no conversational cross-session memory; scripts and templates carry the context (2026-11-21).

Permissions & limits

Accounts, subscriptions and enterprise tiers. The official product page says every custom avatar must pass an on-camera identity verification by the person, without which no avatar can be created, and HeyGen honours removal requests. The FAQ says consent, avatar-usage and content guidelines are strictly enforced, and 100% of user data is not used for training (2026-11-21).

Best for

Fit: enterprise training/marketing localisation through translation and lip-sync, authorised real-person clones and batch talking-head video. Not fit: creative narrative generation, entertainment with a deliberately AI look, or cloning someone without consent (a terms red line) (2026-11-21).

Licence and terms of use

Free, subscription and enterprise tiers. Governed by the official terms page (fetched 2026-10-22); avatar cloning requires on-camera identity verification, and the official FAQ says user data is not used for model training (2026-11-21).

When something fails

Account and permissions · Rate limits and retries · File-reading issues

Top misconception

  • Cloning real people's likenesses/voices has a consent-verification flow — 'clone anyone' does not work under the terms; don't read product boundaries from demo videos
  • Digital-human video and generative video (Runway-type) are two species — HeyGen's main function is 'people talking', not 'world-building'
  • Lip-sync quality in translated video varies a lot by language — test against the target language before use
