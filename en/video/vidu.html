Vidu is the Tsinghua-linked Shengshu Technology's video model entry: its signature is reference-to-video with multi-subject consistency — for narrative/animation work that needs character consistency, it's the one domestic player leaning hardest on that.

When to use it, when not to

Fits: multi-character narrative consistency, anime-style motion, domestic direct access. Not a fit: model self-selection, open weights, photoreal big-scene work.

8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

In-house Vidu Q video models (official API docs list viduq3-pro, viduq3-turbo, viduq2-pro, viduq2-turbo, viduq1 and vidu2.0, each with its own duration/resolution/audio capabilities) plus the S real-time interactive line (S2-Avatar, S2-Editing). Users pick model tiers, not raw weights (2026-11-21).

Where it runs

Web (vidu.cn domestic / vidu.com overseas) plus the open-platform API (https://api.vidu.com/ent/v2/text2video and others); generation runs in the vendor cloud, with clients polling a task or receiving a callback (2026-11-21).

Local files

No local filesystem access: input images arrive as URLs or Base64, and finished videos come back as download URLs from task queries that users save locally; work history is account-side. Official docs list no local model surface (2026-11-21).

Tasks after shutdown

Asynchronous tasks: creation returns a task_id and state (created/queueing/processing/success/failed), which can be polled or delivered through callback_url (three retries on failure). Off-peak jobs generate within 48 hours, auto-cancel with refunds if incomplete, and can be cancelled (2026-11-21).

Tools & extensions

Text-to-video, image-to-video, start-end frame video (/ent/v2/start-end2video) and multi-subject reference video (/ent/v2/reference2video, including a subject library). The API exposes 1–16 s durations, 540p/720p/1080p, 16:9/9:16/3:4/4:3/1:1 and seed control (2026-11-21).

Context & memory

Q-series work is task-based: each generation is independent and characters are reused through reference images or the subject library rather than conversation memory. The S-series real-time avatar explicitly carries short-term memory for continuous interaction, so the two memory surfaces are separate (2026-11-21).

Permissions & limits

Accounts plus subscriptions/credits and an API key (Authorization: Token ...). Commercial use of outputs follows the plan and terms, with enterprise API usage under contract; the mainland entry requires real-name and content compliance, with filing Beijing-Vidu-20241125S0003 on record (2026-11-21).

Best for

Fit: narrative/animation needing character consistency (multi-subject reference), start-end frame transitions, domestic direct access and API batch production. Not fit: model choice/open weights, realistic cinematic blockbusters or offline deployment (2026-11-21).

Licence and terms of use

Free, subscription and API tiers. Governed by the official terms page (vidu.com/terms, fetched 2026-10-22); commercial rights vary by plan, with enterprise API usage under contract (2026-11-21).

When something fails

Account and permissions · Rate limits and retries · File-reading issues

Top misconception

  • 'Reference-to-video' is the signature differentiator — judging it as a plain text-to-video tool misses the multi-subject consistency value
  • vidu.cn (domestic) and vidu.com (overseas) are two entries — account/content policy interop not verified
  • The filing number's subject is the Vidu service (CAC registry) — algorithm filings (the CAC algorithm-filing numbers) and service filings are two numbering systems; don't cross-quote them
