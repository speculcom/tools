8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

A hybrid of in-house and partner models: in-house covers Soul 2.0 (photoreal images), Soul Cinema (cinematic images), Higgsfield DOP (cinematic video), Keyframes (storyboards) and Cinema Studio (a 1,296-lens and colour workspace), with an in-house reasoning engine orchestrating both lines. The API catalogue also lists Seedance, Kling, Wan, MiniMax, LTX, PixVerse, Grok, Recraft, Ideogram and Qwen (2026-11-21).

Where it runs

Web at higgsfield.ai plus an asynchronous API (https://api.higgsfield.ai, Python/TypeScript SDKs). The web runs Cinema Studio/Soul ID workspaces, while the API submits to model endpoints, bills from a prepaid USD balance and unlocks 20 concurrent requests per key (2026-11-21).

Local files

No local model: image/video inputs arrive as URLs, and a submission returns request_id and status_url; clients poll or receive a webhook until completed, then download the output. Works live in the account library, with exports saved locally by the user (2026-11-21).

Tasks after shutdown

An asynchronous lifecycle: submit, store request_id, poll status_url or wait for a webhook, then download on completion. Each model has its own timeout, timed-out requests fail without charge and can be resubmitted; Cinema Studio supports up to 30 seconds and 50 reference images per generation (2026-11-21).

Tools & extensions

Cinema Studio 4.0 (30+ movement presets, seven genres, camera/lens/aperture f/1.4–f/11, lighting presets, 50+ colour palettes, Emotion Wheel, up to 1080p/30 s), Soul ID character consistency, Soul HEX colour control, Keyframes storyboards, audio/lip-sync translation and an official MCP (2026-11-21).

Context & memory

Organised around account works and Elements: Soul ID locks one character across shots, and Cinema Studio reuses the same camera logic across clips. These are generation-consistency mechanisms rather than conversational memory (2026-11-21).

Permissions & limits

Web subscriptions plus a prepaid API balance; API keys come as an ID:secret pair, shown once and meant for server-side use. Consumer terms allow commercial output and claim no ownership, but inputs/outputs may train models by default (except under enterprise agreements); uploading a person’s likeness requires consent, and outputs may carry C2PA watermarks (2026-11-21).

Best for

Fit: short films needing controllable camera language, cross-shot character consistency, advertising/fashion/narrative storyboards and API batch production. Not fit: open weights/offline use, zero-cost unlimited iteration, or keeping content out of training without an enterprise agreement (2026-11-21).

Licence and terms of use

Free + subscription. Governed by the official terms page (higgsfield.ai/terms-of-use-agreement, direct-fetched 2026-10-22); commercial rights vary by plan, details not verified line by line.
