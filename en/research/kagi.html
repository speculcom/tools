8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

A self-built search index is the core story. The answer layer is made up of FastGPT, Assistant and Universal Summarizer. The official privacy page describes third-party AI providers as called per request and, where possible, not stored or used for training. No model-by-model list is published. Search is the product and AI is the add-on, the reverse of most AI-first search tools (2026-11-21).

Where it runs

Web at kagi.com, the browser extension and Mini Bar are the entry points. The index is self-built, while FastGPT, Assistant and summarisation run in Kagi’s cloud. Official docs offer no local model package, private deployment or offline index. The client provides UI and optional cache only (2026-11-21).

Local files

Search itself writes no user files. The official privacy page lists only session, CSRF, last-page and location cookies plus kagi_sse_replay. That is a localStorage cache of recent result markup that avoids round trips. There is no account-level search-history store. Tor, Privacy Pass and pseudonymous email are optional anonymity paths (2026-11-21).

Tasks after shutdown

Search and summarisation return synchronously. Official docs list no job queue, scheduler or batch API. FastGPT and Assistant requests complete in the cloud, and closing the page leaves no resumable long-running task. Batch work must be orchestrated through the Kagi API by the caller (2026-11-21).

Tools & extensions

The surface includes ad-free search, FastGPT/Assistant answer lines, Universal Summarizer for URLs, video and documents, Kagi Translate and the API. The privacy page names Assistant, Summarizer, FastGPT and Translate as AI tools and states thread-retention rules (2026-11-21).

Context & memory

Search is organised per query. The official privacy page says queries are not linked to an account and no profile is built. Kagi Assistant threads are deleted permanently after one day by default and can be deleted immediately. Reported threads are kept for 30 days. There is no cross-session long-term memory entry point (2026-11-21).

Permissions & limits

There are two levels: subscription account and API key. The official terms state that only Kagi API products are licensed for commercial use. Front-end products such as Universal Summarizer are non-commercial by default and need a separate licence. Accounts can use pseudonymous email, crypto, Tor and Privacy Pass. Team and admin surfaces are not itemised in the official docs (2026-11-21).

Best for

Fit: users who pay for ad-free, tracking-free search, want search-plus-full-text answers and are sensitive to profiling. Not fit: free-tier-only users, Chinese-first search, or organisations needing a documented enterprise audit and team-admin surface (2026-11-21).

Licence and terms of use

Subscription-first (ad-free, not free-tier-led). Governed by the official terms and privacy page (kagi.com/privacy fetched 2026-11-21); commercial use is limited to API products, while front-end products are non-commercial by default.
