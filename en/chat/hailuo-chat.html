8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

MiniMax’s self-developed H series; the official site shows version narratives for MiniMax H3 and Hailuo Agent H3. The chat product offers no model choice, with tiers following the logged-in UI. The same vendor’s developer API line is documented separately in the Hailuo Video and MiniMax Audio entries (2026-11-21).

Where it runs

Web (hailuoai.com, chat at /chat) plus apps; generation runs in MiniMax’s cloud and no model runs locally. The vendor also runs a developer API line and a separate video domain; the three entries share the MiniMax account system but expose different products (2026-11-21).

Local files

Chat and creation assets live on the MiniMax account, and the site navigation has an Assets area for video, image and audio. The official privacy policy says chat inputs and feedback are used for model training after de-identification, and lists no local model or offline project file. Downloaded outputs belong to the local machine (2026-11-21).

Tasks after shutdown

Chat responses return immediately; video, image and audio generation queue in the cloud, and the product pages place generation inside the creation flow without a panel to pause, resume or export queue state. Whether a job continues after closing the page must be measured per generation entry (2026-11-21).

Tools & extensions

Site navigation exposes Design, Assets, Tools, video, image and audio creation surfaces. Web search and tool calls inside chat are not itemised in the official privacy policy. MCP support is not listed officially and requires wrapping the APIs yourself (2026-11-21).

Context & memory

Conversations are organised per chat, while creation assets sit in the account-level Assets area and connect to the chat creation flow. The official privacy policy only describes generating replies from surrounding context and lists no cross-session long-term memory or user-profile entry (2026-11-21).

Permissions & limits

Login is required, with free and membership tiers. The official user agreement grants a personal, revocable, non-commercial licence, with written authorisation required for commercial copying or distribution; the privacy policy says chat data is de-identified for training. Training switches and membership rights should be checked in-app (2026-11-21).

Best for

Fit: a mainland-accessible, all-in-one MiniMax creation entry spanning video, image, audio and chat. Not fit: model choice, local model execution or leaving the MiniMax account (2026-11-21).

Licence and terms of use

Free with login (some features need a membership). Output ownership follows the official user agreement and paid-service agreement; clause details are governed by the original text (2026-11-21).
