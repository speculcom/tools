8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

The main line is iFlytek’s self-developed Spark series, with a public version cadence and V-series numbers on the official news page. The iFlytek Open Platform is the developer API line from the same vendor. Model tiers inside the app follow the logged-in UI, and the chat product offers no third-party model choice (2026-11-21).

Where it runs

Web (xinghuo.xfyun.cn), iOS/Android apps and a PC client; generation runs in iFlytek’s cloud and no model runs locally. The Spark main line is not open-weight, unlike the DeepSeek/GLM/Qwen same-family route; the Spark MaaS platform separately lists fine-tuning and hosted inference (2026-11-21).

Local files

Chat history lives on the iFlytek account; documents, images, audio and video are uploaded and parsed in iFlytek’s cloud, and the official personal-information list names document Q&A as cloud recognition. The client handles input and display only, with no local model or offline index; downloaded outputs belong to the local machine (2026-11-21).

Tasks after shutdown

Chat responses return immediately, and the official pages list no separate async job queue; long-running work such as deep research and recording minutes runs in the cloud, and whether it survives closing the page must be measured per entry point. There is no queue panel for pausing, resuming or exporting job state (2026-11-21).

Tools & extensions

The product exposes web search, document Q&A, AI writing, homework help, deep research, recording minutes and Spark agents; the official agent page lists private knowledge bases, web apps and agent API publishing. Official docs list no MCP server, so MCP access requires wrapping the APIs yourself (2026-11-21).

Context & memory

Conversations are organised per chat and synced on login. The official personal-information list records Q&A history as continuity data and describes personalised content generation as memory extraction and recall that can reference history across sessions and over time. Cross-session memory has product-level controls and granularity; the default follows the in-app settings (2026-11-21).

Permissions & limits

Accounts register by phone number, and the official personal-information list itemises the purposes for chat, images, audio/video, documents, history and device data. Training-use and personalised-memory switches sit in in-app privacy settings; defaults and disable paths should be checked on the in-app page (2026-11-21).

Best for

Fit: voice-heavy interaction backed by iFlytek’s speech stack, Chinese Q&A and homework help, and education/office document work. Not fit: local model execution (Spark’s main line is not open-weight), leaving the iFlytek account, or needing auditable default-off cross-session memory (2026-11-21).

Licence and terms of use

Free with login (some capabilities need a subscription). Output ownership and training terms follow the official agreement and privacy policy; personalised memory can reference history across sessions (2026-11-21).

When something fails

Account and permissions · Rate limits and retries · File-reading issues

Top misconception

  • Mixing xinghuo.xfyun.cn (chat product) with the iFlytek open platform xfyun.cn (API/capability platform) — one vendor, two interfaces
  • Treating Spark as an open-weight family — the Spark line keeps weights closed; 'run Spark locally' is not a viable path
  • Voice strength is iFlytek's foundation — but each in-product voice capability (live interpretation, voice cloning) must be checked item by item against official pages; don't copy the marketing block wholesale
