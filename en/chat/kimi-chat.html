8 questions, each comparable item by item with its peers.

Model & openness

The model family is disclosed via the official product line: Kimi K3.1 Pro / Highspeed launched on 2026-10-24 (3T-class, 1M context, thinking mode only); K3 / K2.7 Code / K2.6 / K2.5 remain listed; the open-platform API provides model interfaces on a separate line.

Where it runs

Web is the main entry, plus desktop and mobile apps; generation is processed in the cloud and data is stored on servers within mainland China (official data usage & sharing notice).

Local files

Long-document parsing and retrieval are the flagship capabilities; product-line entries incl. PPT/deep research/documents/spreadsheets/build-apps are supported (verified via direct fetch of the official-site navigation); uploaded content is stored in the account.

Tasks after shutdown

The official-site navigation has a "scheduled tasks" entry (direct-fetch verified 2026-10-21); the Agent-task form has an official product line ("just ask, or make an Agent task"); offline-continuation details kept at the official category level.

Tools & extensions

The official product line includes PPT, deep research, documents, spreadsheets, design, build-apps and a plugin ecosystem; there is also the open-platform API (Moonshot open platform).

Context & memory

Has project spaces and history-session organization (syncs across devices when signed in); the cross-session memory mechanism is kept at the official category level — the official site has entries like an "inspiration library", but this site has outside this profile's scope official docs for a standalone memory-management interface.

Permissions & limits

Official data usage & sharing notice: on the premise of "processing with secure encryption, strict de-identification such that specific individuals cannot be re-identified", inputs, prompts and generated replies may be used for model training; opting out requires registering with customer service (5-7 business days after identity verification), it is an account-level uniform opt-out with no per-chat opt-out, and after opting out neither historical nor new data enters the training set. Kimi Business promises enterprise data never enters the model training pipeline, with personal and enterprise spaces fully isolated.

Best for

The workhorse for Chinese long-document scenarios. Opting out of training goes through customer-service registration, not a self-service switch — confirm this first if it matters to you; enterprise data goes through Kimi Business. For running models locally, it is not suitable.

Licence and terms of use

Official User Agreement v2 §5.2: users own the IP rights in their inputs and outputs; the agreement also grants the platform its operational license. Note the legacy modelUse agreement stated 'non-commercial use only' — v2 is current; both versions remain retrievable, and this site records the current one.

When something fails

Account and permissions · Rate limits and retries · File-reading issues

Top misconception

  • Assuming the training opt-out is a self-serve toggle — the official flow is customer-service registration, an account-level unified opt-out
  • Mixing the old and new agreements — the old “non-commercial only” and current v2 “owns input and output IP” coexist; follow the current version
  • Confusing the consumer line with the open-platform API — the two lines have different terms
