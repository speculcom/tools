8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

The main line is Alibaba’s Qwen family, with a public model-release blog and an open-weight line alongside cloud chat. In-app model tiers follow the logged-in UI; Alibaba Cloud Model Studio is the developer API line from the same vendor, and its file-Q&A page lists full-text citation, chunked retrieval and custom processing (2026-11-21).

Where it runs

Web (tongyi.aliyun.com), iOS/Android apps and a PC client; generation runs in Alibaba’s cloud and no model runs locally. Tongyi Wanxiang for image/video generation is a sibling product and not part of this entry; Model Studio handles APIs, file parsing and agent orchestration (2026-11-21).

Local files

Chat history lives on the Alibaba account; uploaded files are parsed by Model Studio. The official file-Q&A page states that uploads in the chat window are valid only for the current session and expire on close, refresh or timeout, while session_file_ids from the file API last at most seven days and are not stored long-term. No model runs locally; downloaded outputs belong to the local machine (2026-11-21).

Tasks after shutdown

Chat responses return immediately; deep research and agents execute multi-step work in the cloud, and the official file-Q&A page describes custom processing as the model calling plugins or MCP servers per task. Official docs provide no user-facing pause, resume or queue panel; long-task state should be checked at the specific agent entry (2026-11-21).

Tools & extensions

The product includes document parsing, image understanding, web retrieval and agents. The Model Studio file-Q&A page lists full-text citation, chunked retrieval (RAG) and custom processing, explicitly allowing plugins or MCP servers in the last mode. The chat-side MCP entry follows in-product configuration (2026-11-21).

Context & memory

Chat history syncs across devices on login; the official file-Q&A page says uploads last only for the current session and expire when the session closes, so context is session-scoped. Cross-session memory and user profiles are not itemised officially and should be checked in product settings (2026-11-21).

Permissions & limits

Accounts support Alibaba, Alipay and phone login; the official Model Studio page says uploaded files sit in the current Alibaba Cloud account’s Model Studio storage. Training-use switches and data authorisation follow in-site privacy settings; the Qwen filing number is in the cn block (2026-11-21).

Best for

Fit: Chinese Q&A and multimodal understanding, the Qwen open-weight family for cloud-plus-local choice, and Alibaba Cloud ecosystem links through Model Studio APIs. Not fit: office/social-suite integration (DingTalk is a separate surface) or fully leaving the account (2026-11-21).

Licence and terms of use

Free with login. Product terms follow the official in-site agreement; model and API services are governed by Alibaba Cloud Model Studio terms (file-Q&A page fetched 2026-11-21).

When something fails

Account and permissions · Rate limits and retries · File-reading issues

Top misconception

  • Mixing Tongyi Qianwen (chat), Tongyi Wanxiang (image/video) and Alibaba Cloud Bailian (API platform) — one vendor, three lines
  • Treating Qwen open weights as the product itself — local weight runs belong to the runner ecosystem, with a completely different data boundary
  • The terms page has no stable directly-fetchable URL (terms measures 404) — verify terms in-site by hand before quoting; never quote secondary reposts
