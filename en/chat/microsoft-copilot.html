Microsoft Copilot is the free chat entry of the Windows/Edge/Bing ecosystem: web search is the base capability, models are routed on Microsoft's side; it is three different products from Microsoft 365 Copilot and GitHub Copilot — don't mix them.

When to use it, when not to

Fits: Microsoft-ecosystem users, free web-connected Q&A, enterprises already in Microsoft's stack. Not a fit: model self-selection, mainland direct access (measures 000 direct).

8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

Models are routed by Microsoft; official narratives mention OpenAI-family models plus Microsoft’s own MAI family, without a model-by-model list of current tiers. Whether a selector exists and what it offers follows the logged-in UI. Routing can change, so a single UI snapshot is not a commitment (2026-11-21).

Where it runs

Web (copilot.microsoft.com), Windows integration, iOS/Android apps and Edge integration; generation runs in Microsoft’s cloud. Microsoft 365 Copilot is a neighbouring but distinct product surface — this entry covers the consumer Copilot (2026-11-21).

Local files

Chat history sits on the Microsoft account. The official privacy FAQ says conversations are saved by default, viewable in the Copilot app’s history, stored for 18 months by default and deletable individually or wholesale. Copilot for Windows references local recent items but does not scan or upload files automatically; browsing history stays on the device and is sent only according to settings (2026-11-21).

Tasks after shutdown

Chat responses return immediately, and the official privacy FAQ lists no pause/resume task queue. Consumer Deep Research retired on 2026-08-18, with deep research moving to the Researcher agent in Microsoft 365 Copilot (official support page, 2026-11-21).

Tools & extensions

Web retrieval on the Bing base, image generation on the Designer/DALL·E line and image understanding are built in; deep research has retired on the consumer side, while the Researcher agent provides multi-step research in Microsoft 365 Copilot. Microsoft 365 app integration is another surface; official pages do not list MCP as a consumer capability (2026-11-21).

Context & memory

Chat history syncs on login and is stored for 18 months by default. The official privacy FAQ and personalisation page say Copilot Memory infers preferences from prior conversations and uses them later; turning personalisation off stops memory and personalisation but does not delete history. Copilot Memory has a separate saved-memories management entry (2026-11-21).

Permissions & limits

Microsoft accounts span personal and enterprise lines. The official privacy FAQ says that, except for opted-out users, Microsoft uses Copilot conversations, uploaded images/files and voice activity to train AI, removing names, account identifiers and other identifying data first. Personalisation switches sit in Copilot settings, with paths checked on the account page (2026-11-21).

Best for

Fit: Windows/Edge/Bing ecosystem users, free web-grounded Q&A and enterprises already in Microsoft’s ecosystem. Not fit: model choice, leaving the Microsoft account or direct mainland access (see the cn block) (2026-11-21).

Licence and terms of use

Free with a Microsoft account (some capabilities require a Microsoft 365 subscription). Governed by the Microsoft Services Agreement (fetched 2026-10-22); the official privacy FAQ says conversations are saved for 18 months by default and, except for opted-out users, can be used for AI training (2026-11-21).

When something fails

Account and permissions · Rate limits and retries · File-reading issues

Top misconception

  • Confusing consumer Copilot with Microsoft 365 Copilot — the free web app and the office-suite product are different surfaces with different terms
  • Confusing it with GitHub Copilot — coding belongs to the coding category (copilot profile); this profile is general chat
  • Reading "routed by Microsoft" as "fixed to one model" — routing changes with official updates; do not treat a UI snapshot as a promise
  • Still looking for Deep Research in consumer Copilot — it was retired on 2026-08-18; deep research moved to Researcher in Microsoft 365 Copilot
