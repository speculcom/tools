Tencent Yuanbao is the general AI assistant living in the WeChat ecosystem: search official accounts/Channels, @-mention it in comment sections, integrate Tencent Docs and WeChat Read; long-document reading is its strong suit, powered by Tencent's self-developed Hunyuan (Hy) models.

When to use it, when not to

Fits: WeChat-ecosystem users, long-document reading, free allowance. Not a fit: running models locally, leaving the Tencent account system.

8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

The main line is Tencent's self-developed Hunyuan (Hy) series — Tencent's official news page has model-iteration records (Hy3 preview released 2026-04-24 etc.); Yuanbao was early on known for "Hunyuan + DeepSeek dual-model switching", but current external promotion has converged onto the Hy series; the model selector is only visible after signing in and this site did not verify while signed in — go by what the signed-in UI actually shows.

Where it runs

Web (yuanbao.tencent.com) + iOS/Android apps + PC/Mac clients, multi-surface; generation is processed on Tencent's cloud, no model runs locally. It and Tencent ima (a knowledge-base workbench) both belong to Tencent and both build on Hunyuan but are positioned differently — Yuanbao is a general assistant, ima is a personal knowledge-base RAG.

Local files

Chat history and favorites are stored on the account side; deep document reading supports multiple formats and can process ultra-long single documents (official narrative); uploaded content is stored in the cloud account. No model runs locally — the client is just an entry.

Tasks after shutdown

Chats return instantly with no official statement of an "offline continuation" form; deep thinking is an in-session reasoning tier, not an async task.

Tools & extensions

In-product capability lines incl. web search (exclusive WeChat Official Account / Channels sources are its differentiator), deep document reading, AI image generation, agent creation and AI coding (multi-language run-and-verify); integration with Tencent Docs / WeChat Read. No official statement verified for MCP support.

Context & memory

Chat history syncs across devices when signed in; there is an "incognito temporary chat" (not saved to history after chatting); the cross-session long-term memory mechanism is kept at the official category level.

Permissions & limits

Account system (WeChat/QQ/phone-number login); the training-use switch path kept at the official category level. The Hunyuan model filing number is in the cn block (official disclosure).

Best for

Suits: people living in the WeChat ecosystem (searching Official Accounts/Channels, @ to interpret in comment sections, integrating Tencent Docs and WeChat Read), long-document deep reading, free quota. Does not suit: running models locally, or leaving the Tencent account system.

Licence and terms of use

Free with login. Governed by the official user agreement page (direct-fetched 2026-10-22); output ownership and training terms follow that agreement — clause details not verified line by line.

When something fails

Account and permissions · Rate limits and retries · File-reading issues

Top misconception

  • Confusing Yuanbao with Hunyuan — Hunyuan is the model (hunyuan.tencent.com is a model/research site you cannot chat on); Yuanbao is the consumer entry built on it
  • Treating 'free dual-model switching' as current state — official promotion has converged onto the Hy series; whether DeepSeek remains selectable needs a logged-in check (not verified logged in)
  • Treating Yuanbao and Tencent ima as one product — both run on Hunyuan, but one is a general assistant and the other a personal knowledge-base workbench
