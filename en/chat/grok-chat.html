Model & openness

The Grok consumer product runs xAI’s official model line: Grok 4.7 now powers Expert mode on grok.com and Fast mode for paid subscribers, with the API grok-4.7 at 500K context, text+image input and no text output limit; Grok 4.6/4.5 remain listed. On the multimodal side Imagine Image 2.0 is GA as Quality Mode, Imagine Video 1.5 supports text/image/voice references, and the product page cites up to 2K and 15-second video (2026-11-21).

Where it runs

Web at grok.com, iOS/Android apps and Grok inside X; generation runs in xAI’s cloud. xAI also offers a separate API (text, vision, voice, images, video) sharing the model family under different terms (2026-11-21).

Local files

File/PDF uploads, image and video generation and project file trees are supported, with uploads and outputs stored account-side. Deleting a conversation, all conversations or the account removes data from xAI systems within 30 days, as does Private Chat (2026-11-21).

Tasks after shutdown

Multi-agent mode parallelises sub-problems within one answer, shows each agent’s reasoning and merges them into a cited response; cross-turn long work is carried by Projects, while the cloud task agent Grok Bot is a separate entry. Chat itself streams without an offline queue (2026-11-21).

Tools & extensions

Real-time web search plus X post search with citations, parallel multi-agent, Imagine text-to-image/video and editing, Voice conversation, file/PDF analysis, vision understanding, code generation, Canvas long-form editing, custom instructions, Projects, memory and shareable conversations; paid tiers also expose Grok Bot (2026-11-21).

Context & memory

The official product page states “Memory across chats”, remembering preferences and past conversations as background for later sessions; Threads keep context and Projects group conversations and files. Private Chat is neither saved nor viewable, Data Controls can turn off personalisation/training and delete one or all conversations, and account deletion clears data within 30 days (2026-11-21).

Permissions & limits

Free access is available, with SuperGrok adding higher limits, priority access and multi-agent; use inside X follows X’s terms and privacy policy. The xAI Consumer FAQ says users own Inputs/Outputs and may use them commercially with attribution under the Brand Guidelines; signed-in users can turn off training under Settings → Data → Improve the Model, Private Chat is not trained, and unauthenticated use in some regions (excluding EU/UK) offers no training opt-out (2026-11-21).

Best for

Fit: real-time X/web information, multi-agent deep answers, integrated image and video creation, cross-session memory and Projects, and commercially usable output. Not fit: contract-grade data terms (use the API/enterprise line), fully offline work or avoiding X-ecosystem ties (2026-11-21).

Licence and terms of use

Free plus SuperGrok subscription. Per the xAI Consumer Terms and Consumer FAQ: users own Inputs/Outputs and may use them commercially with attribution under the Brand Guidelines; the platform retains a broad use licence; training can be turned off in Data Controls, Private Chat is not trained, unauthenticated use in some regions has no opt-out, and use inside X follows X’s terms (2026-11-21).

Top misconception

  • Assuming Grok inside X and grok.com share one set of terms — inside X, the X privacy policy applies
  • Assuming everyone can opt out of training — the official docs explicitly say some regions (EU/UK excepted) lack that option in logged-out scenarios
  • Confusing the Grok chat app with Grok Bot — the latter is a cloud task-type agent with a separate profile (coding)
