成本总表

先把“月费”拆成五笔账

订阅费只是第一笔。席位、模型调用、超额 credits、存储/分钟数、人工复核时间，才是账单真正变大的地方。这张表把能看到的价格摊开；看不到的写“未核验”。

19 个产品快照价格核验 2026-11-25不是报价单

先排雷

五笔账，少算一笔就会低估

01

席位费

按人/月，不是按“用量”。团队先算活跃席位，别按全员买。

02

模型/用量

第三方模型、API token、AI credits、按分钟转写，通常另计。

03

超额

超出套餐后的单价往往比套餐贵；先找“overage”那一行。

04

存储/保留

会议录音、云端产物、日志的存储与保留期，可能单独收费。

05

人工复核

转写错、引用错、代码改错，都要人再花时间；这也是成本。

算自己的账

订阅还是 API？先找盈亏平衡点

粗略规则：把“每月 API 调用费”和“席位订阅费 + 超额”放在同一张表；如果 API 费低于订阅费的 60%，先按量；如果接近或超过，订阅更省心。真正的平衡点取决于你的调用量、缓存命中率与人工复核时间。

  • 打开成本工作台（API / 团队 / 本地 / 视频四组）
  • 用“本地 vs API”盈亏平衡小算器
  • 读成本控制指南：哪些费用常被漏算
