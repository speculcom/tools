CosyVoice is the Alibaba speech team's (QwenAudio, formerly FunAudioLLM) open-source LLM-TTS model family (Apache-2.0, three generations v1 → v2 → Fun-CosyVoice 3.0): download the weights and run inference/training/deployment locally — Chinese + dialect coverage and zero-shot cloning are the pitch; it is a model, not a product, and the official line sells no hosted service.

When to use it, when not to

Fits: local/private Chinese + dialect TTS, zero-shot cloning with a full training stack, an Apache-2.0 commercial base. Not a fit: out-of-box hosted APIs (the official line sells none), zero-ops setups.

Model & openness

The core is an open-source model family: v1 (CosyVoice-300M) → v2 (CosyVoice2-0.5B) → Fun-CosyVoice 3.0 (Fun-CosyVoice3-0.5B-2512, the three-generation line on record in the README same day); download the weights and run inference locally; hosted calls go through Alibaba Cloud Bailian's cosyvoice-v2/v3/v3.5 line (this dossier stays on the open-source repo).

Where it runs

Local Python runtime (the README gives conda install + inference/training/deployment full stack, official description "inference, training and deployment full-stack ability"); the repo moved to the QwenAudio org (FunAudioLLM/CosyVoice 301 → QwenAudio/CosyVoice, verified same day); the README's clone command still writes the old org name.

Local files

Weights, code and synthesized output all stay on your machine — an open-source model repo has no account-side data surface (the structural difference from hosted TTS products).

Tasks after shutdown

Local batch/streaming inference: Bi-Streaming is on record in the README (text-in/audio-out dual streams, official claim of latency as low as 150ms); no cloud task surface.

Tools & extensions

Pronunciation-control surface on record (README: Chinese Pinyin / English CMU phoneme pronunciation inpainting, text normalization without a traditional frontend, Instruct support for emotion/speed/volume commands); MCP does not apply (a model repo is not an agent host).

Context & memory

The conversational-context dimension does not apply — a TTS model works per synthesis request; zero-shot cloning conditions on reference audio (multilingual/cross-lingual zero-shot cloning on record in the README).

Permissions & limits

Apache-2.0 code and three-generation weight licenses (GitHub/HF API verified 2026-11-21); voice cloning touches personality rights — the README disclaimer covers sample content only (academic demonstration, takedown on infringement) and is not a cloning-consent clause; authorization is the user's responsibility; 9 languages + 18 Chinese dialects coverage on record in the README.

Best for

Fits: local/private Chinese + dialect TTS, zero-shot cloning with a full training/fine-tuning stack, an Apache-2.0 commercial base. Not a fit: wanting only an out-of-box hosted API (that is Bailian's CosyVoice line, not this repo), zero-ops setups.
