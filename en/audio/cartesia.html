8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

Own model lines: Sonic for TTS (sonic-2 covers 15 languages with 90ms model latency; sonic-turbo goes as low as 40ms), Ink for STT (Ink-Whisper streaming transcription) and Managed Agents; no third-party model selection. The site also cites 44 languages, but per-language capability should follow the 15-language table on the TTS Models page (2026-11-21).

Where it runs

Cloud API plus hosted agents: Sonic and Ink serve streaming requests through the Cartesia API with API-key auth, while Managed Agents host phone and support voice agents in the cloud. No model runs locally, and official docs ship no local inference package (2026-11-21).

Local files

No local user files are read or written. Synthesised audio streams back from the API and belongs to the local machine once downloaded, while voice and agent configuration stay in the Cartesia account. Official docs list no local model cache or offline project file (2026-11-21).

Tasks after shutdown

The API is streaming and request/response oriented, and Managed Agents are cloud-hosted. Official docs cover agent deployment and telephony integration but no user-controlled pause/resume job queue; batch synthesis needs client-side queueing and retries (2026-11-21).

Tools & extensions

Official docs list Sonic TTS, Ink STT, Agents, API Reference and integrations with MCP, LiveKit, Pipecat, Rasa and Twilio. cartesia-mcp is the official MCP server, letting Cursor, Claude Desktop and OpenAI Agents list voices and run TTS (2026-11-21).

Context & memory

Voice Agents keep dialogue state and transcription context within one session, with session orchestration delegated to the agent layer. Official docs list no cross-session long-term memory, user profile or persistent knowledge base; that requires external storage (2026-11-21).

Permissions & limits

Accounts come in free, subscription and enterprise (Contact Sales) tiers, with SSO/organisation controls on enterprise. The Terms require users to hold rights to uploaded voice samples and forbid impersonation through cloned voices; API keys are issued per project and permissions follow account roles (Terms version fetched 2026-11-21).

Best for

Fit: low-latency realtime TTS as a voice-agent base, 15-language coverage and hosted voice agents out of the box. Not fit: a mainland direct-access filing entry, third-party model choice or local model execution (2026-11-21).
