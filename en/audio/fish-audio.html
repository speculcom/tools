fish audio is the zero-shot voice-clone TTS console: upload a sample and the voice is cloned + a community voice market; between 'it works' and 'it's compliant' sits the consent red line.

When to use it, when not to

Fits: zero-shot cloning of your own voice, community voice treasure-hunting, API integration. Not a fit: cloning others (red line), enterprise compliance priority, mainland direct access (measures 000).

8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

In-house speech models: official docs list s2.1-pro (production), s2-pro, s2.1-pro-free (zero-cost testing tier) and drama-3 (plain-language direction with sounds, pauses and tags), with s1 marked for retirement on 2026-12-31; self-hosting runs on the fish_speech repo (2026-11-21).

Where it runs

Cloud API at https://api.fish.audio/v1/tts (plus /model for voice creation) and the fish.audio web app; official self-hosting docs provide a local GPU inference server (localhost:8080/v1/tts), so one integration can target cloud or self-hosted (2026-11-21).

Local files

Self-hosting keeps both weights and audio local: official docs walk through semantic tokens to DAC decoding on local hardware, writing output files; the cloud path returns bytes or stream chunks, with voice models stored account-side (2026-11-21).

Tasks after shutdown

Synthesis is synchronous or streaming: tts.convert() returns complete audio, tts.stream() emits chunks and WebSocket accepts live text. Voice training is an async state machine, with a new model moving from created to trained (fast mode is usually immediate) and retries on failure (2026-11-21).

Tools & extensions

TTS (multilingual, mp3/wav/pcm/opus, speed 0.5–2.0), instant cloning with reference audio plus transcript, persistent voice models (POST /model, private/unlist/public), the Voice Library and Drama 3 direction tags. The Voice Cloning page also lists Professional Voice Clone (verified, web only) (2026-11-21).

Context & memory

No conversational memory: each TTS request is independent, and voices are reused via reference_id; instant cloning passes the sample with the request, while persistent cloning trains a voice id, so the asset is a cross-request consistency mechanism rather than session context (2026-11-21).

Permissions & limits

API key (FISH_API_KEY) plus account/subscription. Clone samples must be the user’s own voice or authorised; Professional Voice Clone is listed as a verified tier. Public voices enter the Voice Library only when the user chooses private, unlist or public (2026-11-21).

Best for

Fit: fast cloning of one’s own voice, consistent brand voice, real-time assistants (about 300 ms to first audio in balanced mode) and self-hosted offline synthesis. Not fit: cloning someone else’s voice (a consent red line), enterprise audit chains, or direct mainland access (measured 000) (2026-11-21).

Licence and terms of use

Free, subscription and API tiers. Governed by the official terms page (fish.audio/en/terms, fetched 2026-10-22); clone consent and Professional Voice Clone verification follow the official Voice Cloning page (2026-11-21).
