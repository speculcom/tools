8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

Open-weights line: two models on record (README verified same day) — F5-TTS (Diffusion Transformer + ConvNeXt V2) and an E2 TTS reproduction; the v1 base model released 2025-03-12; download the weights and run inference locally, no official hosted service.

Where it runs

Local Python inference stack (conda + PyTorch; NVIDIA CUDA and AMD ROCm install paths on record in the README, ROCm Linux-only); community Gradio Spaces (E2-F5-TTS) exist for trying it out but are not an official hosted product.

Local files

Weights, code and generated audio all stay on your machine; the ModelScope weights page measured 200 direct from mainland (2026-10-30) — the acquisition path works from the mainland; no account or cloud data surface at all.

Tasks after shutdown

Local batch inference with no task queue; inference time varies with hardware and the official docs give no unified latency figure.

Tools & extensions

CLI/library usage is the main form (usage examples in the README); zero-shot cloning = give a reference clip + text and synthesize (usage on record); the Sway Sampling inference-time sampling strategy is on record. No hosted API.

Context & memory

No session concept — each inference call is independent and carries no state; cross-session memory does not apply (local model form; context management is entirely up to the caller's code).

Permissions & limits

MIT gives a commercial base (on record via GitHub same day); the model itself performs no consent check on the cloning side — there is no platform-side blocking (a local form has no platform), users carry the consent responsibility themselves (no legal notice on record in the official README, honestly marked not itemized).

Best for

Fits: local/private Chinese + English TTS and zero-shot cloning research, an MIT commercial base, mainland weight acquisition via ModelScope. Not a fit: wanting an out-of-box hosted API, zero-ops setups, SLAs.

Top misconception

  • It is a model, not a product — no account, no console, no SLA; an “F5-TTS service” does not exist in official terms (the HF Space is a community demo, not official hosting)
  • The official entry github.com measured 000 direct from mainland on the day — weights via ModelScope (the AI-ModelScope/E2-F5-TTS studio and SWivid weight pages) measured 200 direct; judge reachability by the acquisition path, not the repo domain
  • The lab signatures in the README (X-LANCE SJTU, SII, PCL) are research attribution, not a corporate entity — MIT's no-warranty terms apply as usual for commercial integration
