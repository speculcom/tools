8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

Its own music-generation model line (the 250+ styles narrative on record same day); no third-party model picking; you can upload audio/MIDI influence sources and build your own style models (the "Ultimate customizability" section on the official site, on record same day).

Where it runs

Web product (aiva.ai) + desktop app (the Download entry in the site navigation is on record); generation runs on AIVA's cloud; the export surface is pitched as "any file format" (MP3/MIDI named on the pricing page).

Local files

Downloaded MP3/MIDI and project files land on your machine; generation, preset styles and the account track library live in AIVA's cloud. The product surface has no local model download, so you cannot generate offline.

Tasks after shutdown

A generation request runs in AIVA's cloud task queue; closing the web/desktop client does not change the cloud job. The official narrative uses "in seconds" for return time and gives no pause, resume or queue-position control.

Tools & extensions

Editing surface on record ("Edit your generated tracks", MIDI export feeding DAW workflows); MCP and a public API are not part of the capability surface listed on the official site.

Context & memory

Works are organised in the account track library; each generation reads the style, reference audio/MIDI and current editing parameters. The product surface has no cross-session memory entry, so continuity comes from tracks and project files.

Permissions & limits

Account system (free + subscription; the €0 free tier on record same day); tier-split monetization rights are the core difference — the free tier keeps copyright with AIVA Limited and allows monetization only on YouTube/Twitch/TikTok/Instagram (on record in the terms page same day).

Best for

Fits: full-song generation for non-DAW users, MIDI-editable output feeding a DAW, full copyright under Pro for commercial scoring. Not a fit: a filed direct-mainland entry, picking third-party models, running models locally, free-tier monetization beyond four platforms.
