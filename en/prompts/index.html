Prompt library: reusable task instructions

6 method guides and 24 task patterns. Each pattern states input, output, checkpoint and failure branch; no universal template, no promised effect.

This is an index of 6 method guides and 24 reusable task patterns. It does not promise “one prompt for everything”; each case lists input, expected output, a checkpoint and a failure branch. Test with your own input before copying.

Method: read these six first

Guide

Structured output: three gates

Prompt format, API schema and protocol validation each cover a different failure. Valid JSON is not the same as correct content.

Guide

Context is a budget, not a warehouse

A larger window still dilutes attention. Put static instructions first, retrieve on demand, compress and keep notes; spend tokens on high-signal content.

Guide

The boundary of prompt safety

Injection exploits the blurry line between data and instructions. Delimiters, guardrails and least privilege each block one layer, with costs and failure modes.

Guide

Anatomy of a prompt

Split a prompt into role, instruction, delimiter, examples and reasoning. Each block has a job, a placement and a common failure.

Guide

How to iterate a prompt

Change with a baseline and a measurement: human comparison, meta-prompting, automatic search or a generate-evaluate loop. Each has a cost.

Guide

Define failure before improvement

An eval flywheel: label failure modes, build an automatic scorer, calibrate an LLM judge, then compare each prompt change.
