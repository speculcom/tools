When to use it, when not to

Model & openness

It calls no model itself — an interface implementation called by MCP clients. It wraps the Brave Search API (web search, news, images, local places) as tools for agents.

Where it runs

A local process (npx stdio) plus a remote-hosted line (the official docs describe a remote endpoint); GitHub 1,544★, last push 2026-10-27 (API verified).

Local files

Reads and writes no local files — it outputs search-result text/links; fetching page content is out of its scope (that is the fetch server's job).

Tasks after shutdown

stdio lives and dies with the client; no background-task semantics.

Tools & extensions

web_search / news_search / image_search / video_search / local_search etc., grouped by API family, trimmable via configuration; the complete inventory follows the repo README.

Context & memory

No cross-session memory — each search is independent.

Permissions & limits

A Brave Search API key (free/paid tiers follow the Brave API account); a pure read surface — it cannot write to any system; the risk surface is mainly query egress and quota consumption.

Best for

Fits: giving an agent a "live search" capability (after the archived Brave reference in the MCP repo, the official @brave package took over), a retrieval source independent of the LLM's built-in search. Not a fit: deep content fetching (the fetch/firecrawl line); zero-configuration scenarios without an API key.

Transport

stdio (npx @brave/brave-search-mcp-server) is primary; the official docs also describe a remote line — kept at the official category level. Verified against: the repo README (direct-fetched 2026-10-21).

Authentication

The BRAVE_API_KEY environment variable; the key's quota/plan tiers follow the Brave API account (prices not collected per our price-recording policy).

Permission scope

Pure read: the search-family tools (web/news/image/video/local). No write surface; no approval needed.

Licence and terms of use

MIT (GitHub API verified 2026-10-21).

When something fails

Authentication and permissions · Invalid tool inputs · Invalid output format

Top misconception

  • Using the archived Brave reference in the modelcontextprotocol repo — it is archived; the live line is the official @brave/brave-search-mcp-server (the official README states the replacement)
  • Reading 'search' as 'scrape' — it returns result summaries and links, not page bodies
  • Quota and billing follow the Brave API account — this site records no price figures (rule D9)
