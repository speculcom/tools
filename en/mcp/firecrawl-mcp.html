Model & openness

It calls no model itself — an interface implementation called by MCP clients. It wraps Firecrawl (the "context API for AI agents") search/fetch/parse/browser-interaction capabilities as tools for agents.

Where it runs

Official hosted remote server (https://mcp.firecrawl.dev/v2/mcp) + local npx (firecrawl-mcp), two lines; the official README states support for both cloud and self-hosted. GitHub 7,673★, last push 2026-10-23 (API verified); the release line lives on npm (firecrawl-mcp 3.34.1), GitHub releases stopped at v3.2.1 (2025-09-26) — behind npm.

Local files

Reads and writes no local files — it outputs web page text (markdown/structured JSON) and parsed artifacts (PDF and other documents).

Tasks after shutdown

The hosted line lives on Firecrawl's side; the monitor tool family can watch page changes on a schedule on Firecrawl's side and emit diffs/alerts — that is a "server-side task", not a local background process.

Tools & extensions

The full profile registers 27 tools by default (README wording, including the feedback tool; the FIRECRAWL_NO_SEARCH_FEEDBACK/NO_ENDPOINT_FEEDBACK env vars can trim it): scrape / search / parse / crawl / map / interact (real-browser clicks·form filling·navigation) / the monitor family / credit_usage / agent tasks / the developer·gov·research vertical search index families. The hosted keyless endpoint exposes only 3 (scrape/search/parse); the search-only endpoint is fixed at 9.

Context & memory

No server-side cross-session memory; interact sessions can continue across calls via scrapeId (official README: you cannot drive it step by step from within a single client call — each call runs one prompt/code round and hands control back).

Permissions & limits

The keyless free tier works (scrape/search/parse three tools, rate-limited); the other tools need an API key. Three hard rules from the official README: the key never goes into the server URL, never into the agent chat, only into the client or a secret manager. The OAuth endpoint (/v2/mcp-oauth) uses interactive account connection.

Best for

Fits: agents that want the full chain covered in one package — "search→fetch text→structured JSON→browser interaction→site-level crawl/map→page monitoring"; gradual onboarding that starts keyless and upgrades to a key. Not a fit: holding a browser session long-term and driving it step by step (the README states plainly this is not its interaction model); minimal scenarios that only need single-page reading (the fetch reference is lighter).

Transport

streamable-http (hosted https://mcp.firecrawl.dev/v2/mcp; plus /v2/mcp-oauth and /v2/mcp-search endpoints) + stdio (npx -y firecrawl-mcp), two lines; the README also mentions SSE support. Verified: repo README (fetched directly 2026-10-23).

Authentication

Keyless free tier (rate-limited) → API key (Authorization Bearer, configured in the client/secret manager) → OAuth interactive connection (/v2/mcp-oauth). The local npx line uses the FIRECRAWL_API_KEY env var.

Permission scope

Mostly read (search/fetch/parse/monitor); interact can click and fill forms in a real browser — the boundary between "reading" and "touching things on a web page" must be gated yourself against the target site's authorization boundaries. No local write surface.

Licence and terms of use

MIT (GitHub API verified 2026-10-23).

When something fails

Authentication and permissions · Invalid tool inputs · Invalid output format

Top misconception

  • Treating GitHub releases as the release line — releases stop at v3.2.1 (2025-09) while npm is at 3.34.x; watch npm
  • Treating the keyless tier as full-featured — hosted keyless exposes 3 tools only; crawl/map/agent etc. need a key
  • Putting the API key in the server URL or the agent chat — the README forbids both; client config or secret manager only
  • Treating interact as a step-by-step driven browser session — each call runs one prompt/code turn and returns control; persistence across calls goes through scrapeId
  • Referencing the old repo name mendableai/firecrawl-mcp-server — it moved to the firecrawl/ org (301 confirmed); update references
