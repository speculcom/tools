Shopify official Dev MCP server (npm ISC, local stdio, no auth): gives your coding agent Shopify platform context — doc retrieval (search_dev_docs/fetch_docs_by_path) + Admin GraphQL schema probing (introspect_admin_schema). It is one of the three forms of the Shopify AI Toolkit (plugin / agent skills / Dev MCP); there is no standalone dev-mcp GitHub repo (code ships with npm), and the inventory's old agents-of-change URL is now 404. Pure read — it never touches store data; store operations go through the Shopify CLI line, don't mix them.

When to use it, when not to

Fits: Shopify developers having agents write correct API fields/schema/CLI; zero-auth zero-config start. Not a fit: agents operating the store directly (no store surface); non-Shopify ecosystems.

Model & openness

It calls no model itself — a local server (stdio) called by MCP clients. It feeds your coding agent "Shopify platform context": shopify.dev documentation retrieval, Admin GraphQL schema introspection, and the like.

Where it runs

A local npx line (npx -y @shopify/dev-mcp@latest, Node 18+); the official docs state plainly "the server runs locally and doesn't require authentication". The release line lives on npm (1.18.0, 2026-10-27, 143 versions); there is no standalone dev-mcp GitHub repo (Shopify/dev-mcp is 404) — the code ships with the npm package, while the plugin/skills line lives in the Shopify/Shopify-AI-Toolkit repo (MIT 621★, pushed 2026-10-27). The official package also ships instrumentation telemetry (opt out via OPT_OUT_INSTRUMENTATION).

Local files

Reads and writes no local files — it outputs documentation search results and schema structures; it serves the scenario of "you writing Shopify code", and the code files land on disk via your agent/editor, not through it.

Tasks after shutdown

No persistent background — the stdio server is spawned by the MCP client; the process lifecycle follows the client.

Tools & extensions

Four core tools (official docs wording): search_dev_docs (search shopify.dev docs) / introspect_admin_schema (access and search the Admin GraphQL schema) / fetch_docs_by_path (retrieve doc pages by path) / get_started (API onboarding guidance); built-in prompt: shopify_admin_graphql (helps you write Admin API GraphQL operations). Polaris Web Components support is opt-in via the POLARIS_UNIFIED env var (experimental).

Context & memory

No server-side cross-session memory; context is carried by the MCP client session. The schema is queryable by API version (including field-level docs and deprecation notices — official docs wording).

Permissions & limits

No authentication needed (the official docs state the local server needs no auth) — it only reads public docs and schemas, it never touches your store data; store operations (creating apps/themes, running the CLI) go through Shopify CLI's authenticated context, which is a different line of the AI Toolkit, not this MCP server's capability. Instrumentation telemetry is on by default; OPT_OUT_INSTRUMENTATION=true opts out.

Best for

Fits: Shopify developers giving a coding agent "platform context" — doc retrieval + schema probing so the model stops guessing API fields; zero-auth zero-config onboarding. Not a fit: agents operating the store directly (it has no store surface); non-Shopify ecosystems (single-vendor only).

Transport

stdio (npx -y @shopify/dev-mcp@latest; the official example is claude mcp add --transport stdio). Verified: the shopify.dev AI Toolkit page and the Polaris using-mcp page (200 direct on 2026-10-31).

Authentication

No auth (the official docs state the local server requires no auth). Instrumentation telemetry is on by default, opt out via the OPT_OUT_INSTRUMENTATION env var; Polaris support is opt-in via POLARIS_UNIFIED.

Permission scope

Pure read (public docs + schema), no store-data surface, no local write surface — among the lightest permission surfaces in MCP servers.

Licence and terms of use

The npm package is ISC (npm registry metadata verified 2026-10-31); the companion AI Toolkit plugin repo is MIT (GitHub API verified).

When something fails

Top misconception

  • Treating the old inventory URL (shopify.dev/docs/agents-of-change) as the docs line — measured 404 on 2026-10-31; the current docs page is docs/apps/build/ai-toolkit (the Dev MCP is one of three AI Toolkit forms)
  • Looking for a GitHub source repo — Shopify/dev-mcp does not exist (404); the code ships with npm; plugins/skills live in the Shopify/Shopify-AI-Toolkit repo, don't mix
  • Treating it as "an MCP that operates the store" — it only reads docs and schema, no auth and no store surface; store operations go through the Shopify CLI line
  • Ignoring instrumentation — telemetry is on by default; set OPT_OUT_INSTRUMENTATION=true if you mind
  • Treating the early per-surface skills (shopify-admin/shopify-liquid and 23 others) as current — the official line deprecated them for a single shopify skill (npx skills add Shopify/shopify-ai-toolkit)
