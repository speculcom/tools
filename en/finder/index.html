AI tool finder: narrow 282 tools to three candidates

A rule-based shortlist: task, budget, hard constraints and data sensitivity. The result is three candidates to verify, not a ranking.

Rule-based shortlist

Three constraints first, then three candidates

The interactive selector narrows 282 tool profiles to three candidates. It does not rank “the best”; it removes tools that violate your hard constraints, then explains why each candidate remains.

01

Task

Select one or more jobs: research, coding, meetings, writing, tables, image, video, local models, transcription, automation or general chat. A tool that does not do the job never enters the shortlist, however cheap it is.

02

Budget

Free only, up to $50/month, up to $150/month, or capability first. The filter uses public entry prices; it does not guess enterprise or hidden costs.

03

Hard constraints

Mainland direct access, local execution, or citations/sources. A violated hard constraint is a veto; “will support it later” does not count.

04

Data sensitivity

Public, internal, or confidential / cannot leave the machine. Sensitive data pushes local or private deployment ahead of cloud convenience.

Three example paths

Research: Perplexity Pro for global sources and citations; Kagi for ad-free search and privacy; NotebookLM for source-grounded notes. Verify each citation before relying on it.

Coding: GitHub Copilot for IDE coverage; Cursor for an IDE agent plus cloud tasks; Claude Code for terminal-first refactors with explicit permissions. Price the model separately from the seat.

Local / private: Ollama or llama.cpp for local model serving; Whisper for local transcription. The subscription is zero, but hardware, electricity and staff time are not.

What this page does not do

It does not make a procurement decision, does not provide a “best” ranking, and does not upload or store your input. The result is a shortlist to verify, not a purchase order. The interactive rule engine is on the Chinese page; this English edition explains the same rules and gives worked examples.
