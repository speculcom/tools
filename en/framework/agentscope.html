Model & openness

Each vendor's model connects via a wrapper (Tongyi/DashScope line first, plus the OpenAI-compatible surface and local models — following the official docs, kept at category level); multi-agent message passing is its core abstraction (Msg objects flowing between agents).

Where it runs

A Python library (pip-installed into your process); GitHub 34,871★, last push 2026-10-30 (API verified). The official narrative is "a production-oriented framework for multi-agent systems" — including a visual workbench (Studio) and a distributed-execution line.

Local files

The library form runs inside your process; where data lands is your call. The official Studio workbench is a visualization surface started locally.

Tasks after shutdown

A library has no resident semantics; whether a multi-agent app stays resident depends on your deployment. The distributed-execution line's details were kept at the official category level.

Tools & extensions

Tool calling and toolkits are within the official module family; MCP support status was kept at the official category level (the official docs have related lines, details unverified).

Context & memory

The memory modules (short-term/long-term memory components) are its explicit surface — long-term memory needs external storage attached; cross-session memory gives a pattern, not hosting.

Permissions & limits

No account system (library form); the permission surface is whatever vendor keys and tool capabilities you connect. Tongyi/DashScope-line access runs on the Alibaba Cloud account line — that is the model service's account, not the framework's.

Best for

Fits: multi-agent collaboration apps (the message-passing model is a clear abstraction), Tongyi-line stacks, wanting a visual debugging workbench. Does not fit: thin single-agent apps (the multi-agent abstraction is a cost); wanting the largest integration ecosystem (LangChain's surface is wider).

Top misconception

  • Reading 'multi-agent framework' as 'multi-agent is always better' — single-agent is simpler for single tasks; multi-agent is an explicit cost
  • Blurring AgentScope with Tongyi Qianwen models — the framework is open-source Apache-2.0; the model service is a separate billing line
  • Assuming capabilities of the distributed-execution and Studio lines — use them per current official docs; do not assume unverified parts
