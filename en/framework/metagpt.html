Where it runs

A Python multi-agent framework: a role pipeline of "product manager → architect → engineer → QA" collaborates to produce software artifacts. GitHub FoundationAgents/MetaGPT 71,097 stars (API verified); last push 2026-01-21, latest release v0.8.2 (2025-03-09) — mainline repo updates clearly slowed (other org repos remain active, see pitfalls).

Local files

Runs locally: install via pip and it executes on your own machine; generated code, documents and temp artifacts all land in your working directory; there is no cloud-runs-it-for-you hosted execution line (the official docs offer no hosted surface).

Tasks after shutdown

Batch-style pipelines are the main mode (one task runs through one software-production pipeline), not a resident message-receiving form; the research line is active (org repos such as CEO-Arena still pushing in 2026-10).

Tools & extensions

Built-in role-action / code-execution / document-output tool lines; MCP support status not itemized.

Context & memory

Encoding SOPs (standard operating procedures) into role interactions is its core design — context is organized as inter-role messaging (per the official docs).

Permissions & limits

Code execution happens on your machine; intermediate artifacts of a fully automatic multi-agent pipeline should be human-reviewed before landing — the output quality and responsibility surface of a fully automatic "software company" sits with the user.

Best for

Fits: multi-agent collaboration research, SOP pipeline experiments, academic reproduction of the software-generation process (heavily cited paper line). Does not fit: production selections needing active maintenance (pushes/releases slowed), fine-grained single-agent control.
