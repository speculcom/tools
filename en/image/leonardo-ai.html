Model & openness

In-house model line (Phoenix/Lucid frontier image models, official-site narrative) + a model hub aggregating third-party models (as seen in site navigation); no open-weights line (no official release seen).

Where it runs

Web (leonardo.ai) + API (an API entry exists on the official site; details follow the API docs); generation runs in the vendor cloud, with production queueing and quotas tied to the account.

Local files

Works and training artifacts (Elements) stored account-side in the cloud; no officially stated local data surface or export surface — whether training artifacts can be taken away, no clear statement on official pages (not itemized).

Tasks after shutdown

Generation is instant/queued (varies by account tier, official docs do not itemize every sub-detail); no "keep-running-after-shutdown" task surface (no claim verified); training jobs run on the cloud after submission and you can leave the page and wait for completion (official FAQ narrative, details official docs do not itemize every sub-detail).

Tools & extensions

Element training (the officially named few-shot fine-tuning line, style/character consistency), a real-time canvas, the model hub marketplace, game-asset-oriented workflows (official narrative: concept art/textures/asset batching); the Motion video line (as seen in site navigation).

Context & memory

Organized by project; the product surface has no cross-session memory entry. Element training is its consistency mechanism — reusable trained elements are not memory.

Permissions & limits

Account + subscription system (D9: prices not collected); the training-use switch not itemized in official docs line by line. Acquired by Canva in 2024-07 (Canva official newsroom announcement) — whether data policy unified under Canva post-acquisition, not itemized.

Best for

Fits: game-asset/concept-art workflows, Element training for style and character consistency, picking models inside an aggregating platform. Does not fit: open weights running offline, leaving the account, deep per-model parameter control.
