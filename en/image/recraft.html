8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

Own model family (V3/V4 lines): the official API docs list model values (recraftv3 / recraftv3_vector etc.); closed-source, no open weights. The differentiator is vector-native — it can output real SVG files (official docs state the vector/SVG output line plainly).

Where it runs

Web (recraft.ai) + API (external.api.recraft.ai, the endpoint in official docs); generation on the vendor's cloud. The official ComfyUI node is an API bridge (needs a key, online) — not offline weights.

Local files

Artwork lives in the cloud account; SVG/PNG downloads land locally. Generation and style models stay in the cloud; no local model runtime surface.

Tasks after shutdown

Generation is instant/queued (varies by account tier, official docs do not itemize every sub-detail); no "keep-running-after-shutdown" task surface (no claim verified); on the API side, batching runs on the caller's own concurrency.

Tools & extensions

The product includes a style library + custom brand styles (brand kit), inpainting/outpainting, background replacement, mockup generation, text placement (official docs: the V3 line is the only one that can place text precisely inside images); the full API operation surface is documented.

Context & memory

Organized by project; the product surface has no cross-session memory entry. Brand styles are its consistency mechanism — reusable styles are not memory.

Permissions & limits

Account + subscription system; free-plan works are public by default and not licensed for commercial use (official docs framing) — this is its most critical tier difference from most peers; paid plans grant commercial rights (D9: prices not collected).

Best for

Fits: design-oriented output (logos/icons/illustrations needing editable SVG), brand consistency (brand kit), precise in-image text layout. Does not fit: free commercial use (the free plan's no-commercial line is hard); a photorealistic-realism focus (it leans design).

Licence and terms of use

Free + subscription. Governed by the official terms page (recraft.ai/terms, direct-fetched 2026-10-22); per official docs, free-plan works are public and not licensed for commercial use while paid plans grant commercial rights — output ownership follows those terms, details not verified line by line.

When something fails

Account and permissions · Rate limits and retries · File-reading issues

Top misconception

  • Free-plan works are public and not licensed for commercial use — an official-docs hard line; don't apply the 'free = commercial' habit
  • ComfyUI official nodes ≠ offline weights — they call the Recraft API (key required); 'running Recraft locally' is not viable
  • 'Vector output' is the V3 Vector line only (recraftv3_vector) — not every model value emits SVG
