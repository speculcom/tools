8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

Models are routed by Microsoft; the official FAQ describes the product as generative-AI image creation and editing without publishing model-by-model versions, and users choose features rather than raw models. Designer shares ecosystem and quota conventions with the Copilot/Bing image line (2026-11-21).

Where it runs

Web (designer.microsoft.com) plus image capabilities embedded in Bing, Copilot and Office apps; generation runs in Microsoft’s cloud and no model runs locally. The official FAQ says Designer is integrated across the web and Microsoft apps and tools (2026-11-21).

Local files

Designs save automatically to Microsoft’s cloud and return through My projects, counting against the universal Microsoft storage quota; uploaded personal images go to OneDrive and must be deleted there. No model runs locally, and exported downloads belong to the local machine (2026-11-21).

Tasks after shutdown

Generation returns immediately; the official FAQ lists no async job queue or resume-after-shutdown surface, and embedded Office image features run in the host app’s foreground. Long-task state should be measured per entry (2026-11-21).

Tools & extensions

The product includes text-to-image, image editing such as background removal, design templates for social posts and posters, and image-to-video capabilities; the official FAQ describes Designer as a generative-AI graphic design tool. It overlaps template design tools such as Canva, but AI generation is the main axis (2026-11-21).

Context & memory

Work is organised by project: projects persist in My projects in the cloud and link to OneDrive/Office, while the official FAQ lists no cross-session chat memory or user profile — project context lives in design files rather than a conversation thread (2026-11-21).

Permissions & limits

A Microsoft account is required. The official FAQ licenses Designer for personal, non-commercial use only; commercial use must be checked against the subscription tier and Microsoft terms. Training-use controls sit in the Microsoft privacy panel, while uploaded images live in OneDrive under account quota and deletion (2026-11-21).

Best for

Fit: lightweight design output for Microsoft-ecosystem users (social/post templates plus AI generation) and a free start. Not fit: model choice, open weights or leaving the Microsoft account (2026-11-21).

Licence and terms of use

Free with a Microsoft account (some capabilities ride on Microsoft 365 subscriptions). Governed by the Microsoft Services Agreement (fetched 2026-10-22); the official FAQ licenses Designer for personal, non-commercial use, with projects and uploads counting against Microsoft cloud/OneDrive quota (2026-11-21).

Top misconception

  • Designer and Copilot's image generation are the same ecosystem, different entries — quotas link per Microsoft's accounting, not two independent products
  • Template surface resembles Canva but the inclusion boundary differs — this site includes Designer (AI generation is the main axis), excludes Canva (AI is secondary)
