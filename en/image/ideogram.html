Ideogram is the typography-first image generator (text rendering inside images is its signature): 4.0 released open quantized weights (free but non-commercial), 4.5 is closed; direct access from the mainland measures 000.

When to use it, when not to

Fits: posters/packaging with in-image text, typography-heavy output, trying 4.0 quantized weights. Not a fit: commercial use of the open weights (non-commercial line), mainland direct access.

8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

Own model family: 4.0 open weights (quantized version on HF, inference code Apache-2.0 on GitHub ideogram-oss), 4.5 closed-source hosted (official docs only give the api.ideogram.ai hosted-call line); the platform catalog also aggregates third-party image/video models (official narrative, not inventoried item by item). The signature differentiator is in-image type rendering (the official "crystal-clear type" framing).

Where it runs

Web (ideogram.ai) + API (developer.ideogram.ai direct-fetched 200) + official MCP server (official docs state plainly "Connect Ideogram to Claude, Cursor, and other MCP clients"); 4.0 weights can be self-hosted.

Local files

On the hosted line works live account-side; on the 4.0 self-hosted line everything is on your side — the two lines have different data boundaries (the official licensing page lists "keep your data in your stack" as a licensing selling point).

Tasks after shutdown

Hosted generation is immediate/queued; the product surface has no keep-running-after-shutdown task entry. Self-hosted background behaviour is up to your deployment.

Tools & extensions

The product includes generation, editing (4.5 precise edit: verbatim copying of untouched pixels is the official selling point), dedicated apps for background removal/object removal etc., style controls; the API switches models on a unified endpoint; the MCP server is officially provided.

Context & memory

Organized by project/artwork; the product surface has no cross-session memory entry. Multi-turn editing drift control is the 4.5 official narrative.

Permissions & limits

Account + subscription system; the open-weights line has two licensing tiers, non-commercial agreement / commercial license (D9: prices not collected; the tiers' existence is the fact); output commercial restriction = do not train competing models (official FAQ direct-fetch framing).

Best for

Fits: high demands on in-image type (posters/brand materials), wanting open weights for non-commercial research + a commercial self-hosting path, wanting the official MCP hookup into agent flows. Does not fit: wanting free commercial self-hosting (commercial self-hosting needs a paid license), wanting 4.5 weights (closed-source).

Licence and terms of use

Product free + subscription. Open side is special: Ideogram 4.0 ships quantized weights (HF direct 401 = repo exists behind gating; GitHub ideogram-oss org direct 200) free for non-commercial use under the Ideogram Non-Commercial Model Agreement; commercial self-hosting needs the Self-Serve commercial license (official licensing page, direct-fetched). Per the official FAQ, Ideogram does not claim output ownership; outputs are commercially usable (except to train competing models).

When something fails

Account and permissions · Rate limits and retries · File-reading issues

Top misconception

  • 'Open weights' ≠ 'commercially free' — the 4.0 open line is quantized and non-commercial-free per official licensing; commercial use needs the paid line
  • 4.5 is closed — the 'Ideogram is open' narrative only covers the 4.0-era releases
  • ideogram.ai measures 000 direct from the mainland (2026-10-22; 403 via proxy = CF challenge) — unreachable without a network path, not a dead site
