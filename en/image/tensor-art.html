Model & openness

Community-model hosting and online runs are the core: checkpoint/LoRA/ControlNet/Textual Inversion upload, sharing and online generation (a Civitai-style community model ecosystem; clause 1.2 names it the "image generation and posting service"); base models (SD1.5 and the like) available for direct generation; online LoRA training (the privacy policy's Model Training features); no official statement found for an in-house model line.

Where it runs

Web (tensor.art) + an official software application (the terms repeatedly mention the Tensor.Art software application, downloadable); generation runs on the vendor's cloud via credits; no local runtime is provided — the downloadable app is a client, not a local inference engine (details not itemized in official docs line by line).

Local files

Works and models live on the account side in the cloud; the terms mention a downloadable app (an on-machine install surface is on record), but its local data surface is not itemized; the community-model download surface is not itemized in official docs today (the whole site sits behind Cloudflare anti-bot — curl returns 403; only some official pages were reached via WebFetch).

Tasks after shutdown

Credit-based instant generation: VIP members get 300 credits refreshed daily, non-rollover (membership terms on record); no persistent-task surface (no statement verified); LoRA training runs in the cloud after submission (Model Training feature on record; queue/duration details not itemized).

Permissions & limits
