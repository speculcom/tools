Clipdrop is the single-image atomic-operation toolkit: cutout/cleanup/relight (its signature)/upscale/uncrop each as a standalone tool; ownership moved three times (InitML→Stability→Jasper, Feb 2024) — API terms now run on Jasper's side.

When to use it, when not to

Fits: e-commerce product-image batches, atomic operations (cutout/relight/upscale), API integration into own products. Not a fit: creation-oriented generation, style consistency, project management flows.

8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

A tool suite: official API docs list Uncrop, Remove Background, Image Upscaling (up to x16), Cleanup, Remove Text, Text to Image and Replace Background (beta). Text-to-image and background replacement build on Stable Diffusion, while the other tools use dedicated models. Users choose a tool, not raw weights (2026-11-21).

Where it runs

Web app at clipdrop.co plus the API (https://clipdrop-api.co/...); processing runs in the vendor cloud. The API takes a multipart/form-data single image and returns the processed image binary directly (2026-11-21).

Local files

Uploads are multipart and results come back as PNG/JPG binary for the caller to save. Official API docs are organised as single request-response calls without project or history endpoints; web-side works and history follow the account UI (2026-11-21).

Tasks after shutdown

Single-image atomic operations with synchronous responses: one request handles one image, and batching or concurrency is orchestrated by the caller (official docs give per-image endpoints plus file-size/resolution limits). No hosted queue or resume-after-shutdown task surface (2026-11-21).

Tools & extensions

Remove Background, Cleanup, Replace Background, Uncrop, Image Upscaler (up to x16), Relight (a web-side signature tool), Text Remover, Universal Resizer and Text to Image; the API covers seven of these endpoint lines (2026-11-21).

Context & memory

No projects or memory: a single-image-in, single-image-out tool flow. Context is maintained entirely by the caller (human or API integrator), and outputs carry no cross-request state (2026-11-21).

Permissions & limits

Free tiers apply per-tool daily caps, with paid plans raising limits; API access uses an API key. Ownership follows Jasper/Clipdrop terms: customer content is not claimed by the vendor, and uploads must be owned or licensed (including likeness and trademarks); training terms follow the agreement and Jasper privacy policy (2026-11-21).

Best for

Fit: e-commerce product-image batches, atomic cutout/object-removal/relight/upscale operations and API integration into one’s own product. Not fit: generative creation (text-to-image is a side tool), style consistency or project management (2026-11-21).

Licence and terms of use

Free (per-tool daily caps) + subscription. Governed by the official terms page (clipdrop.co/terms, direct-fetched 2026-10-22); output ownership and training details not verified line by line.

Top misconception

  • Ownership moved three times: InitML (2020) → Stability AI (Feb 2023) → Jasper (Feb 2024) — 'under Stability' is outdated; API terms now run on Jasper's side (per official FAQ)
  • Relight is the signature that separates it from other toolkits — judging it as just another background remover underestimates it
  • Free-plan caps are per tool per day — not one shared site-wide quota
