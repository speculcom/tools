8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

The Wan family runs on two tracks: the product/API side covers reference-to-video, image-to-video, text-to-video, file/web-to-video, video editing, text-to-image, image editing and image-set generation, across generations including Wan2.5 (native multimodal, audio-video sync, 10 s at 1080p/24fps) and Wan3.0 (the Alibaba Cloud product page cites 30 s and four-modality references). The open side ships Wan2.2 on GitHub/HF under Apache-2.0, with TI2V-5B running 720p/24fps on a 4090-class consumer card (2026-11-21).

Where it runs

Web at tongyi.aliyun.com/wanxiang, mobile apps and the Alibaba Cloud Bailian API (HTTP/SDK, sync or async tasks); the open line runs the same family locally on GPUs through ComfyUI/Diffusers (2026-11-21).

Local files

Product-side assets and works live in the Alibaba Cloud account, while the open line keeps weights, inference and outputs entirely local. The two data boundaries are distinct: API result URLs last 24 hours and must be copied out (2026-11-21).

Tasks after shutdown

Cloud async tasks: creation returns a task_id valid for 24 hours for queries, states move PENDING → RUNNING → SUCCEEDED/FAILED, clients poll for results, and successful image/video URLs last 24 hours. The open line follows the local process, with no hosted resume (2026-11-21).

Tools & extensions

Product/API surface: reference-to-video (video/image/audio/text inputs), image-to-video, text-to-video, file/web-to-video, general video editing, text-to-image, image editing, image-set generation, start-end frames and audio-driven avatar video. The open line includes Wan2.2 T2V/I2V/TI2V, Animate-14B and S2V-14B (2026-11-21).

Context & memory

The product organises work by project and builds no cross-session chat memory; open models are stateless, with context managed by the caller through frames and prompts. Character consistency comes from reference images or start-end frames, not memory (2026-11-21).

Permissions & limits

Product access uses an Alibaba Cloud account with credits/quotas and a Bailian API key (Bearer); the open line needs no account, and Apache-2.0 permits commercial use with licence and notice retention. Product-side training terms follow Alibaba’s agreement and privacy policy. Filing Shanghai-TongYiWanXiang-202410090024 is on record (2026-11-21).

Best for

Fit: a dual cloud-product plus open-weight track, image and video in one family, Chinese semantics, reference-to-video/audio-driven work and local runs for compliance-sensitive cases. Not fit: fully hosted long jobs or a product experience detached from an Alibaba account (2026-11-21).

Licence and terms of use

Product free + credits. Open side: Wan weights are published on GitHub/HF (Wan2.1/Wan2.2 repos verified Apache-2.0 via GitHub API) — weights and code are governed by each repo's LICENSE; the product line follows Alibaba's in-site agreements, details not verified line by line.

When something fails

Account and permissions · Rate limits and retries · File-reading issues

Top misconception

  • Mixing the console with the weights — Tongyi Wanxiang (cloud console) and the Wan open-weight family are two things: the console is a subscription service, the weights run locally via the runner ecosystem
  • Mixing Wanxiang (image/video) with Qianwen (chat) and Bailian (API platform) — one vendor, three lines
  • Apache-2.0 verified via GitHub API for the Wan repos — but per-checkpoint licenses inside repos can differ; check the specific repo before commercial use
