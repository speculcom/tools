Model & openness

The multi-model picker is an explicit product surface (same-day homepage: the Model item in Agent Settings shows "Smartest (Claude 5.5 Opus)"; the usage panel lists per-vendor consumption for GPT-6.1 Sol / Claude Opus 5.5 / Grok 4.7 / Kimi K3 / DeepSeek V4.1 Flash) — models are billed via credits; the available list per vendor follows the UI.

Where it runs

Cloud-hosted form (www.gumloop.com direct 200); no official self-hosted distribution found (a community clone repo open-gumloop exists, unofficial); agents run in Gumloop's cloud, metered by credits.

Local files

Workflow and agent data live in Gumloop's cloud; the local-file concept does not apply — artifacts land in third-party systems via connectors (Slack/HubSpot/Gong/Gmail/Salesforce); the SDKs (gumloop-py/js) offer a code-side entry but the runtime stays in the cloud.

Tasks after shutdown
