Coze is ByteDance's cloud-hosted agent-building platform: the domestic edition leads with “free model switching + always-on cloud phone/cloud PC + direct distribution via WeChat/Douyin/Feishu”; coze.com is the same product's other entry. There is no self-hosted form — data and runtime live in the cloud.

When to use it, when not to

A fit for: domestic distribution channels, free switching among Chinese models (Doubao-Seed/Kimi/GLM/Minimax), zero-deployment starts. Not a fit for self-hosting for data control (see Dify or self-hosted n8n); source-level control (go to the framework category).

8 questions, one table

8 questions, each comparable item by item with its peers.

Model & openness

The domestic Coze official homepage names "free model switching: Doubao-Seed / Kimi / GLM / Minimax, native support for the latest domestic models"; the international coze.com model catalog has not been verified item by item. The platform ships no model of its own; switching happens in the app configuration.

Where it runs

Cloud-hosted form: apps are built on the Coze platform and run on ByteDance's cloud; official docs list publishing channels (Feishu/WeChat/Douyin/Doubao/stores etc.). No official statement of a self-hosted form (unknown means unknown).

Local files

Knowledge bases/databases/object storage are hosted by the platform (official docs: managed structured and unstructured data solutions); the Coze coding line provides a cloud sandbox (filesystem/terminal/preview). The local machine hosts no runtime.

Tasks after shutdown

Official homepage framing: Coze agents are "fully online continuously, with cloud phones/cloud PCs, long-term memory that understands you better the more you use them, and tasks advanced autonomously" — cloud-resident is the flagship official form.

Tools & extensions

Plugins/workflows/skills are the official trio; official docs list external integrations (Feishu messaging, WeChat, Volcengine Ark etc.); the domestic homepage says local Claude Code / Codex CLI / Openclaw can be connected in one click.

Context & memory

The official homepage describes long-term memory and project assets (each project has its own storage); memory persists as in-project assets and knowledge bases, with no standalone cross-session memory switch.

Permissions & limits

Spaces/workspaces are the official organizational boundary (space admins configure external integrations); enterprise-edition details official docs do not itemize every sub-detail. Data sits on ByteDance's cloud — the official statement on domestic data staying domestic has not been verified item by item.

Best for

Fits: agent building with direct reach into domestic distribution chains (WeChat/Douyin/Feishu), free switching among domestic models, zero-deployment start. Does not fit: self-hosting to control data; source-level control (belongs to framework).

When something fails

Account and permissions · Rate limits and retries · File-reading issues

Top misconception

  • Treating coze.com and coze.cn as two products — same product, two entries, different model and channel ecosystems (this site keeps one file covering both)
  • Reading “cloud phone/cloud PC” as controlling your own machine — those are platform-hosted execution environments
  • Assuming self-hosting exists — the official docs make no such statement
