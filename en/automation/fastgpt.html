8 questions, each comparable item by item with its peers.

Model & openness

The platform ships no in-house model — it connects to various LLMs (OpenAI-compatible interfaces are the main axis); the hosted versions (fastgpt.io/fastgpt.cn) pre-integrate LLMs, embeddings and rerankers, with the live catalog shown in Account → Model provider by region/plan (official Model Providers page); the self-hosted version can attach local models (paired with runner-class tools).

Where it runs

Two forms: open-source repo self-hosted (labring/FastGPT, GitHub direct 200, pushed same day 2026-10-30) + official hosted versions (fastgpt.io international direct 200; fastgpt.cn mainland direct 200, footer entity Guangzhou Huanji Cloud Computing Co., Ltd. + an ICP website registration on record, number in the cn block).

Local files

In the self-hosted form data lives in your own databases (MongoDB/vector store/S3 — official Cloud vs Self-Hosted comparison); the hosted version keeps data in the official cloud, with isolated Global and China regions. Knowledge-base files are ingested and vectorized after upload; raw files and vectors live in the deployment store.

Tasks after shutdown

The product's main axis is RAG knowledge-base Q&A and application orchestration (doc.fastgpt.io docs on record); FastGPT Cloud adds scheduled Dataset sync and Agent VM sandboxes (official Cloud Overview); background execution is carried by the platform.

Tools & extensions

The workflow-node ecosystem is on record in the docs (knowledge retrieval / HTTP request / code-execution nodes etc.); MCP works both ways: external MCP tools can be imported as tool sets (since v4.9.6; Streamable HTTP first, fallback to SSE on non-429 4xx), and FastGPT apps can be published as an MCP Server (Streamable HTTP; standalone SSE for self-hosted).

Context & memory

The knowledge base (RAG) is the core persistent knowledge surface (the product's main axis); multi-turn context and variable storage are stored per application; cross-application memory is not a separately documented product surface, so no inference is made here.

Permissions & limits

Open source and auditable (Apache + extra terms rather than the GPL family, see license); hosted versions follow official cloud terms; the mainland version fastgpt.cn carries an ICP registration on record; the FastGPT Cloud Privacy Policy explicitly says data is not used for additional backup storage or model training, with access/correction/deletion rights; Cloud excludes SSO and custom branding (official Cloud Overview comparison).

Best for

Fits: Chinese knowledge-base Q&A / RAG apps (self-hosted and controllable), a direct-mainland hosted entry (fastgpt.cn). Not a fit: wanting pure Apache 2.0 without extra terms (multi-tenant SaaS restricted), code-level agent frameworks (canvas/configuration is the main axis).
