运行位置Where it runs

云端 API + 托管 agent。Sonic/Ink 通过 Cartesia API 提供流式请求。官方 quickstart 以 API key 鉴权。

Managed Agents 在云端托管电话/客服类语音 agent。本机不跑模型，官方文档未给本地推理包（2026-11-21）。

Cloud API plus hosted agents: Sonic and Ink serve streaming requests through the Cartesia API with API-key auth, while Managed Agents host phone and support voice agents in the cloud. No model runs locally, and official docs ship no local inference package (2026-11-21).

本地文件Local files

不读写用户本机文件。合成音频由 API 流式返回，下载后归本机。音色与 agent 配置保存在 Cartesia 账户侧。官方文档未列本地模型缓存或离线工程文件（2026-11-21）。

No local user files are read or written. Synthesised audio streams back from the API and belongs to the local machine once downloaded, while voice and agent configuration stay in the Cartesia account. Official docs list no local model cache or offline project file (2026-11-21).
