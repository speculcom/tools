API平台API platform 实时流式Real-time streaming 转写Transcription TTSTTS 开发者向Developer-focused partial lifecycle: active 核验Checked 2026-10-22

Deepgram 是开发者向的语音 API 平台：Nova 转写 + Aura TTS 双线，实时流式转写是主打； 它是「造语音产品」的底座，不是终端转写产品。

Deepgram is the developer-facing speech API platform: Nova transcription + Aura TTS, real-time streaming is the lead; it's the base for building speech products, not an end-user transcription product.

适合与不适合When to use it, when not to

适合：实时语音应用（客服/会议/字幕流）、低延迟 API 集成、英文向高准确率。 不适合：非开发者直接使用、隐私敏感音频、中文向主打。

Fits: real-time speech apps (CS/meetings/caption streams), low-latency API integration, English-first accuracy. Not a fit: non-developers using it directly (it's an API platform), privacy-sensitive audio, Chinese-first work.
