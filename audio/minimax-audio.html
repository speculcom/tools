官方 API 概览给 40 种语言、300+ 系统音色。另有音色复刻与音色设计两条资产生成线。

MiniMax’s in-house speech line: speech-2.8-hd/2.8-turbo, speech-2.6-hd/2.6-turbo and speech-02-hd/02-turbo. The API overview lists 40 languages and 300+ system voices, plus voice cloning and voice design asset lines. Paid music-generation APIs closed to new users on 2026-08-20, while Music 3 open weights live on Hugging Face/ModelScope (2026-11-21).

运行位置Where it runs

网页端为 MiniMax Audio（hailuoai.com/audio 与 minimax.io/audio），另开放平台 API（platform.minimaxi.com）。合成在云端完成。

同步走 HTTP/WebSocket，长文本走异步通道。语音接口为无状态设计（2026-11-21）。

MiniMax Audio web (hailuoai.com/audio and minimax.io/audio) plus the open-platform API (platform.minimaxi.com); cloud synthesis with synchronous HTTP/WebSocket and asynchronous long-text channels, and speech APIs are stateless by design (2026-11-21).

本地文件Local files

不碰本机模型。复刻音频先上传拿 file_id。异步长文本产出 task_id 与 file_id。下载 URL 自返回起 9 小时内有效。网页端作品与音色存账户侧。音乐模型另有开源权重可本地跑（2026-11-21）。

No local model: clone audio is uploaded for a file_id, async long-text jobs return task_id → file_id, and download URLs are valid for nine hours from issue; web works and voices stay account-side. Music models additionally offer open weights for local runs (2026-11-21).

关机后的任务Tasks after shutdown

同步 T2A 单次最长 10,000 字符，实时流式。异步 T2A 单次最长 100 万字符，创建任务拿 task_id。查询后用 file_id 走文件接口下载，支持句级时间戳。两条通道都不依赖本机在线（2026-11-21）。

Synchronous T2A handles up to 10,000 characters per call with real-time streaming; asynchronous T2A handles up to one million characters, returns a task_id, and exposes a file_id for the file API after polling, with sentence-level timestamps. Neither channel depends on the local machine being online (2026-11-21).

工具与扩展Tools & extensions

TTS 覆盖 40 语言、300+ 音色。支持音量、语调、语速与按比例混音，输出 mp3/pcm/flac/wav。音色快速复刻支持单人/双声道，可加示例音频增强。音色设计用 prompt 生成 voice_id。

另有异步长文本，带字幕时间戳。官方 MCP 覆盖语音合成、克隆、视频与音乐（2026-11-21）。

TTS (40 languages, 300+ voices, volume/pitch/speed, proportional mixing, mp3/pcm/flac/wav), fast voice cloning (mono/dual channel, optional prompt audio), voice design from a prompt, async long text with subtitle timestamps and an official MCP covering speech, cloning, video and music (2026-11-21).

上下文与记忆Context & memory

接口无状态。官方明确单次调用只处理传入内容，不存储用户数据，也不涉及业务逻辑状态。音色资产 voice_id 是跨请求一致性机制，不是会话记忆。复刻或设计的音色，7 天内未用于合成会被删除（2026-11-21）。

Stateless APIs: official docs say a single call processes only the supplied content, stores no user data and involves no business-logic state. Voice assets (voice_id) provide cross-request consistency rather than session memory, and cloned/designed voices are deleted if unused for seven days (2026-11-21).

权限与限制Permissions & limits

账号加 API Key。声音克隆须先完成个人实名或企业认证，官方 FAQ 与接口文档一致。客户内容须拥有知识产权或合法授权，输出责任由用户承担。

协议允许用输入/输出做服务优化与安全风控。前提是去标识化、不可重识别（2026-11-21）。

Accounts plus API keys; voice cloning requires personal real-name or enterprise verification, consistent across the FAQ and API docs. Customer content must be owned or licensed, output responsibility rests with the user, and the agreement permits de-identified, non-reidentifiable use of inputs/outputs for service optimisation and security (2026-11-21).

适合什么任务Best for

适合中文与多语言高质量 TTS。也适合自有声音克隆、长文本有声书（异步加字幕）、API 集成与国产直连。不适合克隆他人声音，这是授权红线。也不适合要开放权重音频模型或离线跑 TTS 的场景（2026-11-21）。

Fit: high-quality Chinese/multilingual TTS, cloning one’s own voice, long-form audiobooks (async plus subtitles), API integration and domestic direct access. Not fit: cloning others (a consent red line), open-weight speech models or offline TTS (2026-11-21).
