Agent 记忆：写什么、怎么读、什么时候忘Agent memory: what to write, how to read, when to forget

「有记忆」不是把聊天记录全存下来。最少要分三层：工作记忆（当前任务）、情节记忆（做过什么）、语义记忆（稳定事实与偏好）。每层都要有写入策略、检索策略、过期与删除策略，否则记忆会变成噪声。“Having memory” is not storing every chat turn. At minimum, separate working memory (current task), episodic memory (what happened) and semantic memory (stable facts and preferences). Each layer needs write, retrieval, expiry and deletion policies, or memory becomes noise.

  3. 做删除与纠错路径：用户说「忘掉」时必须能真删Build deletion and correction paths: when a user says “forget”, it must really delete

边界Boundary

站群没有做过「多套记忆方案」的召回率、污染率或成本对比；记忆质量取决于你的写入规则与检索评测集。涉及个人数据时，存储位置、保留期限、删除请求与跨境传输要按适用法规处理，不能只靠产品默认设置。The sites have not compared recall, pollution rate or cost across memory schemes; quality depends on your write rules and retrieval test set. For personal data, storage location, retention, deletion requests and cross-border transfer follow applicable law; product defaults are not enough.
