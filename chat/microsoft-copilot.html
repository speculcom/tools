Microsoft Copilot 是 Windows/Edge/Bing 生态的免费对话入口：联网检索是底座能力， 模型由微软侧路由；与 Microsoft 365 Copilot、GitHub Copilot 是三个不同产品面，别混。

Microsoft Copilot is the free chat entry of the Windows/Edge/Bing ecosystem: web search is the base capability, models are routed on Microsoft's side; it is three different products from Microsoft 365 Copilot and GitHub Copilot — don't mix them.

适合与不适合When to use it, when not to

适合：微软生态用户、免费联网问答、企业已在微软体系。 不适合：要模型自选、大陆直连场景（直连 000）。

Fits: Microsoft-ecosystem users, free web-connected Q&A, enterprises already in Microsoft's stack. Not a fit: model self-selection, mainland direct access (measures 000 direct).

头号误解Top misconception

  • 把 C 端 Copilot 与 Microsoft 365 Copilot 混为一谈——免费网页版与办公套件内嵌是两个产品面，条款与能力不同Mixing consumer Copilot with Microsoft 365 Copilot — the free web edition and the office-suite edition are two product surfaces with different terms and capabilities
  • 与 GitHub Copilot 也不是一个产品——编码向归 coding 大类（copilot 档案），本档案是通用对话It is also not GitHub Copilot — the coding tool belongs to the coding category (copilot profiled there); this profile is general chat
