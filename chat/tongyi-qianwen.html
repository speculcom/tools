网页（tongyi.aliyun.com）+ iOS/Android App + PC 客户端。生成在阿里云端处理，本机不跑模型。

Web (tongyi.aliyun.com), iOS/Android apps and a PC client; generation runs in Alibaba’s cloud and no model runs locally. Tongyi Wanxiang for image/video generation is a sibling product and not part of this entry; Model Studio handles APIs, file parsing and agent orchestration (2026-11-21).

本地文件Local files

对话历史存于阿里账号侧。文件上传后由百炼解析。官方文件问答页说明聊天窗口上传仅在当前会话有效，关闭、刷新或超时即失效。

文件上传 API 的 session_file_ids 最长 7 天、不支持长期保存。客户端不跑模型，下载的生成内容归本机（2026-11-21）。

Chat history lives on the Alibaba account; uploaded files are parsed by Model Studio. The official file-Q&A page states that uploads in the chat window are valid only for the current session and expire on close, refresh or timeout, while session_file_ids from the file API last at most seven days and are not stored long-term. No model runs locally; downloaded outputs belong to the local machine (2026-11-21).

关机后的任务Tasks after shutdown

对话即时返回。深度研究/智能体在云端多步执行。官方文件问答页把「自定义处理」描述为模型按任务调用插件或 MCP Server。官方文档未给用户可暂停、续跑或查看队列的后台任务面板。

长任务状态按具体智能体入口核对（2026-11-21）。

Chat responses return immediately; deep research and agents execute multi-step work in the cloud, and the official file-Q&A page describes custom processing as the model calling plugins or MCP servers per task. Official docs provide no user-facing pause, resume or queue panel; long-task state should be checked at the specific agent entry (2026-11-21).

工具与扩展Tools & extensions

产品内含文档解析、图像理解、联网检索与智能体。百炼文件问答页列全文引用、切片检索（RAG）、自定义处理三种模式，并明确自定义处理可调用插件或 MCP Server。

对话产品侧的 MCP 入口以产品内配置为准（2026-11-21）。

The product includes document parsing, image understanding, web retrieval and agents. The Model Studio file-Q&A page lists full-text citation, chunked retrieval (RAG) and custom processing, explicitly allowing plugins or MCP servers in the last mode. The chat-side MCP entry follows in-product configuration (2026-11-21).

需按产品内设置核对（2026-11-21）。

Chat history syncs across devices on login; the official file-Q&A page says uploads last only for the current session and expire when the session closes, so context is session-scoped. Cross-session memory and user profiles are not itemised officially and should be checked in product settings (2026-11-21).
