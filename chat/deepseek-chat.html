模型与开放条件Model & openness

消费应用与 API 共用官方 V4 家族。

API 模型页列 deepseek-flash（DeepSeek-V4.1-Flash-1017，文本+图像输入） 与 deepseek-v4-pro（DeepSeek-V4-Pro-0813，文本输入）。

两者均为 1M 上下文、最大 384K 输出、默认思考模式。App 与网页可用「专家模式」切到 V4 Pro。开源权重是同一厂商的另一面。本地跑归 runner 档案（2026-11-21）。

The consumer app and API share the official V4 family. The API model page lists deepseek-flash (DeepSeek-V4.1-Flash-1017, text and image input) and deepseek-v4-pro (DeepSeek-V4-Pro-0813, text input). Both are at 1M context, up to 384K output and thinking mode by default. The app and web can switch to V4 Pro via Expert mode. Open weights are the same vendor’s other face, with local runs covered by runner entries (2026-11-21).

依据： 网页 chat.deepseek.com、iOS/Android App 与 API 都能用。API 地址是 https://api.deepseek.com， 兼容 OpenAI Chat Completions、Responses 与 Anthropic Messages。生成在厂商云端，本机不跑模型（2026-11-21）。

Web at chat.deepseek.com, iOS/Android apps and the API all work. The API base is https://api.deepseek.com, compatible with OpenAI Chat Completions, Responses and Anthropic Messages. Generation runs in the vendor cloud with no local model (2026-11-21).

本地文件Local files

对话历史、上传文件与图片存账户侧云端。隐私政策允许在设置中复制或删除聊天历史。API 侧输入随请求处理，文件能力由服务端解析后拼进上下文。

产品本体不承载本地模型文件（2026-11-21）。

Chat history, uploads and images live account-side in the cloud. The privacy policy lets users copy or delete chat history in settings. On the API side inputs are processed per request, with file parsing done server-side and folded into context. The product itself hosts no local model files (2026-11-21).

关机后的任务Tasks after shutdown

对话流式返回，长回答在会话内生成。没有独立离线任务队列。深度思考是单次请求内的推理档位（low/high/max），不是异步任务。

云端任务型 agent 属 DeepSeek Harness 另档（2026-11-21）。

Conversations stream and long answers generate within the session. There is no separate offline task queue. Deep thinking is a per-request reasoning level (low/high/max), not an async job. Cloud task agents belong to DeepSeek Harness, a separate entry (2026-11-21).

The app and web product support web search, file input (PDF/Office/images), link reading, voice interaction and safety checks. The same capabilities are available as API tools: deepseek_web_search, deepseek_read_url, file parsing, OCR, ASR and TTS. The API also offers JSON Output, Tool Calls, chat prefix completion and Responses/Anthropic compatibility (2026-11-21).

上下文与记忆Context & memory

上下文按会话与模型窗口计。V4 全系 1M 上下文、最大 384K 输出。会话历史按对话保存，登录后跨端同步，可在设置中复制或删除。官方功能面只列单会话上下文与历史管理。

跨会话复用由用户手动带回（2026-11-21）。

Context is counted per conversation and model window. The V4 family has 1M context and up to 384K output. History is stored per conversation, synced across devices after login and can be copied or deleted in settings. The official feature surface only covers single-session context and history; cross-session reuse is manual (2026-11-21).

权限与限制Permissions & limits

账号（邮箱、手机号或第三方登录）即可免费使用。API 按 token 计费，峰谷定价。北京时间工作日 9–12、14–18 为高峰，其余半价。

隐私政策允许在设置中管理聊天历史，并提供训练用途退出权。条款把 Outputs 权利让渡给用户。对外传播须核实真实性并标注 AI 生成（2026-11-21）。

An account (email, phone or third-party login) allows free use. The API bills per token on peak/off-peak pricing: weekday 9–12 and 14–18 Beijing time are peak, other hours half price. The privacy policy lets users manage chat history and opt out of training. The terms assign Output rights to the user and require accuracy checks plus AI-origin labelling when redistributing (2026-11-21).
