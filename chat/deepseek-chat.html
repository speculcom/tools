DeepSeek 是「推理向问答 + 官方模型文档可回溯」的国产对话产品：云端对话与 API 文档同族， 开源权重线在站外可选；备案号经两家云厂商官方公示页交叉核验。

DeepSeek is the domestic chat product built on reasoning-first Q&A with traceable official model docs: cloud chat and API docs share one family, open-weight models are selectable off-site; the filing number is cross-verified on two cloud vendors' official disclosure pages.

Fits: Chinese reasoning Q&A, traceable official model docs, cloud + local open weights in one family. Not a fit: background long tasks, office/social ecosystem integration.

运行位置Where it runs

网页（chat.deepseek.com）+ iOS/Android App；生成在厂商云端处理，本机不跑模型。 API 线（platform.deepseek.com）是开发者入口，与对话产品同厂商两接口。

本地文件Local files
