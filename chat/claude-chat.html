Long-document analysis, writing and content production. If training matters, opt out in settings (the safety-review exception is explicitly written by the official side); enterprise data goes through the API/Enterprise line.

Not a fit for coding-agent needs — that is a separate product line (Claude Code) with its own profile.

运行位置Where it runs

网页、桌面（macOS/Windows）、移动应用；对话生成在 Anthropic 云端处理。 Cowork 线有本地会话形态（跑在你的电脑上），与云端会话并列——本条目主轴是对话应用。

本地文件Local files

可上传文档做长文分析；上传内容存于 Claude 账户。删除的对话前端立即消失、后端 30 天内删除（官方隐私政策）。

关机后的任务Tasks after shutdown

Cowork 远程会话（beta）官方明说「Work continues when you close your laptop, and scheduled tasks run with no device online」（release notes 2026-07-07）——关机续跑与定时任务有官方出处。

工具与扩展Tools & extensions

连接器生态（Microsoft 365 含写工具、Salesforce 插件等官方条目）；Artifacts 产出代码与内容； Skills/插件安全扫描（Enterprise beta）。

上下文与记忆Context & memory

记忆功能为分类条目制：Settings > Memory 可查看全部 Topics、逐条编辑或删除；敏感话题默认不入记忆； Free/Pro/Max 默认开、Team/Enterprise 默认关（release notes 2026-08-25）。

权限与限制Permissions & limits

官方隐私政策（2026-09-10 生效）：消费者对话默认可能用于训练，账户设置里可 opt out； 即使退出，被安全审查标记的对话仍会被用；API/Enterprise 数据由客户协议管辖，不适用本政策。

适合什么任务Best for

重长文阅读与写作质量的人。要「对话绝不进训练」就在设置里 opt out（注意安全审查例外）； 要合同级数据条款走 API/Enterprise。与 Claude Code 是两条产品线，别混。

头号误解Top misconception

  • 把对话应用与 Claude Code 当成一条产品线——两条线、两份档案Treating the chat app and Claude Code as one product line — two lines, two profiles
  • 以为训练 opt-out 覆盖一切——被安全审查标记的对话是官方明写的例外Assuming the training opt-out covers everything — conversations flagged by safety review are an explicitly documented exception
  • 把记忆当成不可控黑箱——官方提供逐条查看/编辑/删除入口Treating memory as an uncontrollable black box — the official side provides per-item view/edit/delete controls
