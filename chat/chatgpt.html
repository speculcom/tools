适合与不适合When to use it, when not to

适合什么都能问一点的通用问答、写作与文件分析，前提是接受云端处理。 在意「对话绝不进训练」就关数据控制开关或用临时聊天；企业数据走 Team/Enterprise/API。 要本机运行或自由换模型，它不合适——去看本地模型运行器与开源框架。

General Q&A, writing and file analysis where you accept cloud processing. Users who want “conversations never trained on” should turn off the data-improvement toggle or use Temporary Chat; enterprise data goes through the Team/Enterprise/API line.

Not a fit for running locally or freely swapping models — see the local model runners and open-source frameworks.

模型与开放条件Model & openness

模型家族官方披露并按档位分流：release notes（2026-10-07）写明 Plus/Pro/Business/Enterprise 用 GPT-6 Sol、Free/Go 用 GPT-6 Luna，Pro 推理选项用 GPT-6 Astra；聊天内可选模型。

The model family is officially disclosed and routed by tier: release notes (2026-10-07) state Plus/Pro/Business/Enterprise use GPT-6 Sol, Free/Go use GPT-6 Luna, and Pro reasoning options use GPT-6 Astra; models are selectable in chat.

运行位置Where it runs

网页、iOS/Android、macOS/Windows 桌面端；全部生成与检索在 OpenAI 云端处理，本机不跑模型。 桌面端快捷聊天/截屏功能也只是入口，处理仍在云端。

Web, iOS/Android, macOS/Windows desktop apps; all generation and retrieval are processed on OpenAI's cloud — no model runs locally. Desktop quick-chat/screenshot features are just entry points; processing still happens in the cloud.

本地文件Local files

可上传文件、图像与音频（音频上传见 release notes 2026-10-06：转写、摘要、问答）； 上传内容存于 OpenAI 账户，归谁与留存见 permissions 维。

Can upload files, images and audio (audio upload per release notes 2026-10-06: transcription, summarization, Q&A); uploaded content is stored in the OpenAI account — ownership and retention are covered by the permissions dimension.

关机后的任务Tasks after shutdown

对话即时返回；Codex Cloud 线明确「任务可在你电脑休眠时继续」（release notes 2026-09-29）。 对话产品本体没有关机续跑形态。

Chats return instantly; the Codex Cloud line explicitly says "tasks can continue while your computer sleeps" (release notes 2026-09-29). The chat product itself has no offline-continuation form.

工具与扩展Tools & extensions

官方连接器（Gmail/Calendar 等）与合作 Apps；Slides/Sites/Finances 等内建功能线； 另有独立 API 线。插件（plugins）在 Codex 线披露，消费对话端扩展面以官方连接器为主。

Official connectors (Gmail/Calendar etc.) and partner Apps; built-in feature lines like Slides/Sites/Finances; a separate API line exists. Plugins are disclosed on the Codex line; the consumer chat surface extends mainly via official connectors.

上下文与记忆Context & memory

有记忆功能与 Projects 组织历史；临时聊天不进历史、不建记忆。 跨会话记忆的完整边界以官方帮助页为准。

Has memory and Projects for organizing history; temporary chats leave no history and build no memory. The full boundary of cross-session memory is per the official help pages.

权限与限制Permissions & limits

官方政策页：个人服务默认可能用对话训练模型，可在「设置 → 数据控制」关闭或在隐私门户选 「请勿使用我的内容训练」；临时聊天不训练；Team/Enterprise/API 默认不训练（API 需显式 opt-in）； 你提交的点赞/点踩反馈，其整段对话仍可能用于训练。

Official policy pages: personal services may use chats for model training by default; you can turn this off under "Settings → Data controls" or choose "Don't use my content for training" in the privacy portal; temporary chats are not used for training; Team/Enterprise/API do not train by default (API requires explicit opt-in); for the thumbs up/down feedback you submit, the whole related conversation may still be used for training.

适合什么任务Best for

适合「什么都能问一点」、接受云端处理的通用问答与写作。敏感内容先关训练开关或用临时聊天； 企业数据走 Team/Enterprise/API 线。要本机处理或可换模型，这类闭源云助手都不合适。

Suits "ask anything a bit" general Q&A and writing, provided you accept cloud processing. For sensitive content, turn off the training switch first or use temporary chat; enterprise data goes through Team/Enterprise/API. For local processing or swappable models, closed cloud assistants like this are not suitable.
