People already working inside the Google ecosystem (Search, Workspace, Chrome) — the integration is a real advantage. If training matters, turn off Keep Activity (future conversations only); per the official reminder, don't enter confidential content.

Not a fit for running locally or freely swapping models — see the local model runners and open-source frameworks.

运行位置Where it runs

网页为主入口；桌面端有官方应用——Windows 应用（release notes 2026-09-10，Alt+Space 唤起） 与 macOS 应用（2026-07-29 语音创作条目、2026-10-13 Antigravity 编码条目）；生成在 Google 云端处理。

Web is the main entry; official desktop apps exist — a Windows app (release notes 2026-09-10, Alt+Space to summon) and a macOS app (2026-07-29 voice-creation entry, 2026-10-13 Antigravity coding entry); generation is processed on Google's cloud.

本地文件Local files

支持多模态输入与文件上传；官方隐私声明明确不直接拿 Gmail/Drive/Photos 原库训练， 但回答过程中产生的摘要、摘录与推断会被用于训练（Connected Apps 个人化页）。

Supports multimodal input and file uploads; the official privacy notice states Google does not train directly on your Gmail/Drive/Photos source libraries, but summaries, excerpts and inferences produced during answering are used for training (Connected Apps personalization page).

关机后的任务Tasks after shutdown

对话即时返回；Skills 功能（release notes 2026-09-30）是可复用的指令集、可自动匹配触发， 但没有「关机续跑」形态的官方声明。

Chats return instantly; the Skills feature (release notes 2026-09-30) is a reusable instruction set with automatic matching/triggering, but there is no official statement of an "offline continuation" form.

Google ecosystem integration (Search, Workspace, Chrome) is the main selling point; Connected Apps can connect third-party tools (incl. MCP server tools, official help page 16836988); the Gemini macOS app embeds the Antigravity coding agent (2026-10-13).

Has memory and personalization; Gems (custom instructions) are being replaced by Skills and migrate automatically (release notes 2026-09-30). The full boundary of cross-session memory is per the official help pages.

权限与限制Permissions & limits

官方 Gemini Apps 隐私声明（2026-10-13 更新）：Keep Activity 开启时提示、生成内容与反馈 用于改进 Google 服务（含训练生成式模型）；关闭后未来对话不用于训练（除非提交反馈）； 临时聊天与关闭活动记录时保留 72 小时、不用于训练；人工审核员会审阅部分数据——官方提醒勿输入机密信息。

Official Gemini Apps privacy notice (updated 2026-10-13): with Keep Activity on, prompts, generated content and feedback are used to improve Google services (incl. training generative models); with it off, future chats are not used for training (unless you submit feedback); temporary chats and activity-recording-off data are kept 72 hours and not used for training; human reviewers review some data — the official notice warns against entering confidential information.

头号误解Top misconception

  • 把「不直接训练 Gmail/Drive 原库」读成「你的对话内容不训练」——回答中产生的摘要与推断仍会被训练（官方明写）Reading “won't directly train on raw Gmail/Drive” as “your conversations aren't trained on” — summaries and inferences produced during answering are still trained on (explicitly stated)
  • 把 Keep Activity 与临时聊天混为一谈——两套机制，前者管未来对话训练，后者管留存与历史Confusing Keep Activity with Temporary Chat — two mechanisms: the former governs future-conversation training, the latter retention and history
  • 把 API 条款套到消费应用——Gemini Apps 隐私声明与 Gemini API 附加条款是两份文件Applying API terms to the consumer app — the Gemini Apps privacy notice and the Gemini API additional terms are two documents
