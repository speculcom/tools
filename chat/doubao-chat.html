The Doubao consumer app runs ByteDance’s Seed family. The official Seed 2.1 release lists Pro and Turbo tiers with 1M context and multimodal understanding. It also says the office-task mode on Doubao PC or the Doubao app is the way to try it. The Volcengine Ark model list carries doubao-seed-2-1-pro-260915 and doubao-seed-2-1-lite-260915. Both are listed with 1024K context, multimodality, GUI and tool calling. A weekly doubao-seed-evolving is listed too. In-app tiers follow the signed-in interface (2026-11-21).

关机后的任务Tasks after shutdown

对话流式返回。「办公任务」模式会在会话内多步规划。产出文档、表格、PPT 与网页。它属于前台任务，不形成关机后续跑的离线队列。

录音转写与会议纪要在云端处理，结果落云盘（2026-11-21）。

Conversations stream. Office-task mode can plan several steps inside a session and produce documents, spreadsheets, PPTs and web pages. It is a foreground task, not an offline queue that resumes after shutdown. Recording transcription and meeting notes are processed in the cloud and saved to cloud drive (2026-11-21).

工具与扩展Tools & extensions

对话侧支持文字、语音、图片与文件。也支持联网搜索和文档解析。产出侧覆盖 PPT、写作、表格、文生图与生视频。

另有翻译与同声传译、录音转写、屏幕共享/视频通话、编程与应用发布，以及记忆功能。桌面端可操作虚拟桌面与浏览器。也能定点编辑文档、PPT 与网页（2026-11-21）。

Chat handles text, voice, images and files, plus web search and document parsing. Output covers PPT, writing, spreadsheets, image and video generation. It also offers translation and simultaneous interpretation, recording transcription, screen sharing and video calls, coding and app publishing, and memory. The desktop app can operate a virtual desktop and browser and edit documents, PPTs and web pages in place (2026-11-21).

上下文与记忆Context & memory

记忆功能默认开启。它会从对话里提炼兴趣、偏好与习惯，作为后续回复的背景。可在【设置-记忆】开关、逐条查阅或删除，也可一键删除全部。对话中还能直接要求记住或忘记。

同一账号的记忆互通，不同账号与不同智能体之间隔离。关闭开关后不再更新或参考记忆。但旧记忆不会自动删除（2026-11-21）。

Memory is on by default. It distils interests, preferences and habits from conversations into background for later replies. A switch under Settings → Memory allows per-item review or deletion and a “delete all” action. In-chat remember and forget commands also work. Memory is shared across devices on one account but isolated between accounts and agents. Turning the switch off stops new memories and their use without deleting existing ones (2026-11-21).

权限与限制Permissions & limits

账号体系，分免费档与付费套餐。个人版隐私政策 §1.10 写明。在加密、去标识化且不可重识别的前提下。输入、指令与回复可能用于分析与模型训练。

可在 App 的「设置-隐私与权限-帮助模型改进效果」关闭。PC 与网页在「设置-帮助模型改进效果」关闭。记忆与云盘可分别管理。API 侧走火山引擎另一套协议（2026-11-21）。

The product uses accounts, with free and paid plans. §1.10 of the personal-edition privacy policy says inputs, instructions and replies may be analysed and used for model training after encryption, de-identification and non-reidentification. Users can opt out under Settings → Privacy & Permissions → Help improve the model in the app. On PC and web the switch is Settings → Help improve the model. Memory and cloud drive are managed separately; the API line follows Volcengine’s separate agreement (2026-11-21).

适合什么任务Best for
