中文日常问答与文生图的国产主力：App 训练开关自助可关， 「App 默认可能训练、API 默认不训练」是两条线相反口径、最容易被混的一组条款。

The domestic workhorse for everyday Chinese Q&A and text-to-image: the App training toggle is self-serve — “App may train by default, API doesn't train by default” is the opposite-direction pair of clauses most easily mixed up.

适合与不适合When to use it, when not to

适合中文日常问答、文生图与语音对话场景，境内直连可用、已备案。 在意训练用途就关「帮助模型改进效果」开关（只管未来对话）；企业数据走火山方舟 API 线。 要本机跑模型或自由换模型，它不合适——去看本地模型运行器与开源框架。

Everyday Chinese Q&A, text-to-image and voice chat scenarios; direct domestic access works and it is filed. If training matters, turn off the “help improve the model” toggle (future conversations only); enterprise data goes through the Volcano Engine Ark API line.

Not a fit for running models locally or freely swapping models — see the local model runners and open-source frameworks.

权限与限制Permissions & limits

官方隐私政策 §1.10：在「经安全加密技术处理、严格去标识化且无法重新识别特定个人」前提下， 输入数据、指令与生成回复可能用于模型训练；可在「设置 → 隐私与权限 → 帮助模型改进效果」（移动端） 或「设置 → 帮助模型改进效果」（PC/网页端）关闭。API 侧另一口径：火山引擎《豆包模型服务协议》§4.1 ——除非你单独同意，不使用你提交或输出的内容训练基础模型。

Official privacy policy §1.10: on the premise of "processing with secure encryption, strict de-identification such that specific individuals cannot be re-identified", input data, prompts and generated replies may be used for model training; you can turn it off via "Settings → Privacy & Permissions → Help improve the model" (mobile) or "Settings → Help improve the model" (PC/web). The API line has a different term: Volcengine's Doubao Model Service Agreement §4.1 — unless you separately consent, content you submit or output is not used to train the foundation models.
