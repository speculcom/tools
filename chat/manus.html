Manus 是「整段任务扔给云端沙箱」的通用任务 agent：云 VM 里执行代码/浏览/产出/发布（manus.space）， 模型由产品侧编排不开放选择；积分制，异步是本体形态。

Manus is the general-task agent you hand whole tasks to in a cloud sandbox: code execution/browsing/output/publishing (manus.space) run in a cloud VM, models are orchestrated by the product with no user selection; credits-based, async is its core form.

适合与不适合When to use it, when not to

适合：研究报告、数据整理、建站发布类整段任务异步外包。 不适合：要选模型、要本机文件参与、要免费大量用。

Fits: whole-task outsourcing (research reports, data wrangling, site building/publishing) to a cloud agent asynchronously. Not a fit: model selection, local files in execution, heavy free use (credits).

运行位置Where it runs

任务跑在 Manus 的云端沙箱（manus.computer 域名的 sandbox 面直抓所见）： agent 在云 VM 里执行代码、浏览网页、产出文件；网页端下达与跟进，本机不装东西。

本地文件Local files

产物（文件/网页/报告）生成在云端沙箱，可下载导出；上传数据存于账户侧。 与「本机 agent」完全相反——执行面在厂商云上。

关机后的任务Tasks after shutdown

异步任务是它的本体形态：任务提交后可离开页面，agent 在云端继续跑（官方叙事「把任务交给它」）； 有宽限期/排队机制的产品化痕迹（积分制与并发限制）。

适合什么任务Best for

适合：把「整段任务」（研究报告、数据整理、建站发布）异步交给云端 agent、要产物直接发布（manus.space）。 不适合：要选模型、要本机文件参与执行、要免费大量使用（积分制）。
