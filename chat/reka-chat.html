Reka Chat 是一家已整体转向 physical AI 的研究室留下的对话入口（app.reka.ai「Edge Chat」）： 公司当日招牌是 omni 模型、Reka Cloud、视频与数据基础设施；对话产品面薄，真正的可核验面在 API（OpenAI 兼容、自家 Edge/Flash+精选开源档）与 Reka Edge 开放权重本机路线。

Reka Chat: a chat entry left behind by a lab that fully pivoted to physical AI — the homepage's marquee today is omni models, Reka Cloud, and video/data infrastructure; the chat surface (app.reka.ai "Edge Chat") is thin, and the verifiable surface is the API (OpenAI-compatible; in-house reka-edge-2603/reka-flash-3 + curated open tiers deepseek4-flash/glm5.3/qwen3.8-27b/gemma4-26b) plus the Reka Edge open-weights local route. Key wording: the company's mainline is world-model research (news line: Rho-1 2026-10-05) — reading Reka as a "chat product company" misplaces it.

适合与不适合When to use it, when not to

适合：跟 Reka 模型线、经一家 API 横排精选开源档、要 Edge 开放权重本机路线。 不适合：要成熟 C 端对话产品、要大陆直连对话服务。

Fits: following the Reka model line (Edge/Flash), lining up curated open tiers through one API, the Edge open-weights local route. Not a fit: mature consumer chat products; mainland-direct chat service (not filed).
