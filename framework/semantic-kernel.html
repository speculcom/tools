Microsoft
开源Open source MITMIT 企业向Enterprise-focused 多语言Multilingual 微软生态Microsoft ecosystem partial lifecycle: active 核验Checked 2026-10-31

Semantic Kernel 是微软的企业级 AI 嵌入 SDK（MIT，C#/.NET + Python 双线）： connector 接模型、skills/plugins 挂函数，把 LLM 嵌进现有应用进程。1.x 线仍在发版 （python-1.46.0，2026-10-28）；但官方已指明 Microsoft Agent Framework 为其指定后继—— 现役维护与新投资重心是两条线。

Semantic Kernel is Microsoft's enterprise AI-embedding SDK (MIT, C#/.NET + Python both releasing): connectors for models, skills/plugins for functions. The 1.x line still ships — but the official docs name Microsoft Agent Framework as its designated successor.

适合与不适合When to use it, when not to

适合：.NET/企业栈嵌入 AI、Azure 生态、要双语言 SDK。 不适合：新项目起步（先看 MAF）。

Fits: .NET/enterprise stacks embedding AI into existing apps, the Azure ecosystem, dual-language SDKs. Not a fit: greenfield starts (look at MAF first).
