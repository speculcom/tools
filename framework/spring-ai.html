模型与开放条件Model & openness

可移植的 Model API。用统一接口接多家模型供应商。官方文档列出 ChatClient 与模型 API。当前支持列表以官方文档为准，本档不逐条复制完整清单。

A portable Model API behind one interface across providers; official docs list ChatClient and the model APIs. The current supported list follows official docs and is not enumerated here.

运行位置Where it runs

运行在 Spring Boot 应用内。官方提供 starters 与 auto-configuration。模型与向量库以 Spring Bean 方式注入。

Runs inside a Spring Boot application: official starters and auto-configuration inject models and vector stores as Spring beans.

本地文件Local files

文档摄取（ETL）与向量库由应用配置。框架本身不托管数据， 索引落盘位置与检索链路由所选向量库决定。

Document ingestion (ETL) and vector stores are configured by the application; the framework hosts no data itself.

关机后的任务Tasks after shutdown

库形态，不内建任务队列；异步与长任务由 Spring 侧自行编排。

A library with no built-in task queue; async and long-running work is orchestrated on the Spring side.

工具与扩展Tools & extensions

支持工具调用与 MCP。官方文档写明可消费 MCP server。也可把 Spring 服务暴露给 AI 生态。

Supports tool calling and MCP: official docs state it can consume MCP servers and expose Spring services to the AI ecosystem.

上下文与记忆Context & memory

对话记忆由 ChatClient 与 memory 配置管理。持久化需自己接存储。

Conversation memory is managed through ChatClient and memory configuration; persistence is yours to attach.

权限与限制Permissions & limits

Spring Security 体系内运行。权限由应用配置，无内置多租户隔离。

Runs within Spring Security; permissions are application-configured, with no built-in multi-tenant isolation.
