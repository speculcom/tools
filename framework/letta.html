Letta 是常驻的 agent 服务器：原 MemGPT。许可证 Apache-2.0。agent 服务器常驻，会话可中断续接。记忆分 core 与 archival 两层。形态是它与其它框架最大的差异：它是服务器，不是库。

Letta (formerly MemGPT) makes agents persistent entities (Apache-2.0): a resident agent server, layered memory (self-edited core + retrieval-backed archival), sessions that interrupt and resume. Form is its biggest difference from other frameworks — it is a server, not a library.

适合与不适合When to use it, when not to

适合：长期记忆/「持久人格」agent。自托管 agent 服务器。MemGPT 设计路线落地。 不适合：无状态一次性调用；只要库不要服务的架构。

Fits: long-memory 'persistent persona' agents, self-hosted agent servers, landing the MemGPT design. Not a fit: stateless one-shot calls; architectures wanting a library without a service.
