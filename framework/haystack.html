Haystack 是「检索质量工程」那一派的 RAG 框架（Apache-2.0，deepset）：索引/查询管线分离、 hybrid 检索与 reranker、评估环——生产味最浓的一条 RAG 线。2.x 管线 API 大改，旧教程要警惕。

Haystack is the RAG framework of the 'retrieval-quality engineering' school (Apache-2.0, deepset): separated indexing/query pipelines, hybrid retrieval with rerankers, an evaluation loop — the most production-flavored RAG line. The 2.x pipeline API was rewritten; beware old tutorials.

适合与不适合When to use it, when not to

适合：生产 RAG（要检索质量与可审计组件图）、自建存储的数据主权场景。 不适合：薄聊天壳；深度 agent 编排（LangGraph 更专）。

Fits: production RAG (retrieval quality and auditable component graphs), data sovereignty on self-chosen storage. Not a fit: thin chat shells; deep agent orchestration (LangGraph is more specialized).
