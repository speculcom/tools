Gumloop 是画布+连接器形态的企业向 AI agent 平台，多模型选择器是显性卖点（首页当日招牌：Build AI agents for work；Agent Settings 里 Model 可选「Smartest (Claude 5.5 Opus)」，用量面板按 GPT-6.1 Sol / Claude Opus 5.5 / Grok 4.7 / Kimi K3 / DeepSeek V4.1 Flash 归因 credits 消耗）：GTM/客服场景用例为主轴，法律主体是 AgentHub Inc.。

Gumloop is a canvas+connectors enterprise AI agent platform with the multi-model picker as an explicit selling point (same-day homepage headline: Build AI agents for work; Agent Settings' Model item offers "Smartest (Claude 5.5 Opus)", the usage panel attributes credits across GPT-6.1 Sol / Claude Opus 5.5 / Grok 4.7 / Kimi K3 / DeepSeek V4.1 Flash): GTM/support use cases as the main axis; the legal entity is AgentHub Inc.

适合与不适合When to use it, when not to

适合：GTM/客服多模型 agent（画布+连接器+Skills）、要按 credits 统一治理各家模型用量。 不适合：要自托管（社区复刻≠官方）、要大陆直连备案入口、要免费无限量（credits 制）。

Fits: multi-model agents for GTM/support (canvas + connectors + Skills), unified credits-based governance of per-vendor model usage. Not a fit: self-hosting (a community clone ≠ official), a filed direct-mainland entry, free unlimited usage (credits metering).
