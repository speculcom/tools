LangGenius（国产出海）
国产 低代码 agentic工作流 知识库 MCP 自托管 Apache2.0附加条款 partial lifecycle: active 核验Checked 2026-10-21

Dify 是国产出海的 agentic 工作流平台：把提示词逻辑做成可见、可测、可交接的 Workflow/Chatflow 执行路径， 知识库管道与 Marketplace 集成是一等公民。许可是「Apache 2.0 + 两条附加条件」，多租户限制最该先读。

Dify is the China-origin, globally-facing agentic workflow platform: prompt logic becomes visible, testable, handoff-ready Workflow/Chatflow execution paths, with knowledge pipelines and Marketplace integrations as first-class citizens. The license is “Apache 2.0 + two additional conditions” — the multi-tenant restriction is the first thing to read.

适合与不适合When to use it, when not to

适合：要自托管、要「产品/法务/工程在同一画布上对齐」的团队；知识库+agent 一体交付。 不适合：拿源码做多租户 SaaS 售卖（商业授权线）；纯代码编排（去 LangGraph 等 framework 大类）。

A fit for: teams wanting “product/legal/engineering aligned on one canvas”, self-hostable China-origin stacks, knowledge-base + agent delivered together. Not a fit for running multi-tenant SaaS from the source (commercial license line); pure code orchestration (go to LangGraph and the framework category).
