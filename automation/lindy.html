Lindy is a cloud automation platform packaged as "hiring an AI employee" (same-day homepage headline: Hire an AI Employee That Gets Work Done — 40+ built-in Skills, editable Memory, scheduled Routines, Watch and Learn: show it once and it takes over): email/calendar/call/CRM scenarios as the main axis, 1,500+ integrations + MCP; not a canvas, not a code framework — a hired-agent product.

适合与不适合When to use it, when not to

适合：邮件/日历/通话/CRM 的例行自动化（定时例程、演示即学）、要现成集成与 MCP。 不适合：要自托管、要大陆直连备案入口、要代码级控制。

Fits: email/calendar/call/CRM routine automation (scheduled routines, learn-by-demonstration), ready integrations with MCP. Not a fit: self-hosting, a filed direct-mainland entry, code-level control.
