模型与开放条件Model & openness

不内置模型权重。AI pieces 经凭据接各家模型（OpenAI 等）。另提供 AI SDK 在 flow 内搭 agent。自托管时凭据留在自己实例上（2026-11-21）。

No built-in model weights: AI pieces connect to providers (OpenAI and others) through credentials, and an AI SDK supports building agents inside flows; self-hosting keeps credentials on the user’s instance (2026-11-21).

运行位置Where it runs

开源自托管 + 官方云两条线。生产自托管用 Docker Compose + PostgreSQL + Redis。单机 hobby 容器用 PGLite + 内存队列（不可扩到企业版）。

仓库 25,150★、最近推送 2026-10-21（2026-11-21）。

Open-source self-hosting plus official cloud: production self-hosting uses Docker Compose with PostgreSQL and Redis, while the single-machine hobby container uses PGLite and an in-memory queue (not upgradable to Enterprise). The repo has 25,150 stars and last pushed 2026-10-21 (2026-11-21).

本地文件Local files

自托管数据落自有环境。hobby 容器写 ~/.activepieces，生产写自己的 PostgreSQL/Redis。

pieces 凭据与执行数据都在实例内，云版则归厂商托管（2026-11-21）。

Self-hosted data stays in the user’s environment: the hobby container writes to ~/.activepieces, production uses the user’s PostgreSQL/Redis, and piece credentials and execution data remain on the instance; cloud data is vendor-hosted (2026-11-21).

关机后的任务Tasks after shutdown

自托管实例常开承载定时与 webhook 触发。生产用 Redis 队列 worker 跑多实例。human-in-the-loop 支持延时等待与审批。

A always-on self-hosted instance carries schedule and webhook triggers; production uses Redis queue workers across instances, human-in-the-loop supports delays and approvals, and flows ship with auto retries and versioning (2026-11-21).

社区版 MIT Expat，企业功能在 packages/ee 商业许可区。SSO/项目/权限等企业能力按 ee 线。

The community edition is MIT Expat, with enterprise features under the commercial packages/ee licence; SSO, projects and role controls sit on the ee line. MCP connections use OAuth2 with limited scopes, 256-bit encrypted credentials and no read-back API (2026-11-21).
