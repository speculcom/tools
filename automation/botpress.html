Botpress 是企业向客服场景的 AI agent 平台（首页当日招牌：enterprise-grade AI agent platform for customer support，「会执行退款/账户更新等真实动作」）：云托管现役线 + Hub 集成生态；GitHub 主仓是集成/开发工具面（MIT）， 产品本体闭源——「开源 Botpress」的说法要按仓内容拆开看。

Botpress is an enterprise-oriented AI agent platform for customer support (same-day headline: "enterprise-grade AI agent platform for customer support", "takes real action on refunds/account updates"): hosted Cloud line + Hub integration ecosystem; the GitHub main repo is the integrations/devtools surface (MIT) while the product itself is closed — "open-source Botpress" needs splitting by repo content.

适合与不适合When to use it, when not to

适合：客服/支持 agent（工单分流、升级交接、AI 动作）、现成集成生态（Intercom/Zendesk/Salesforce）。 不适合：要产品本体开源、要大陆直连备案入口、要个人用途（ToS 明言企业向）。

Fits: support-ticket agents (deflection, escalation & handoff, AI actions), ready integration ecosystems (Intercom/Zendesk/Salesforce). Not a fit: wanting the product itself open source, direct mainland access with a filing, personal use (the ToS says business-only).
