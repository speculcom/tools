扣子（Coze）是字节的云托管 agent 搭建平台：国内版主打「模型自由切换 + 云手机/云电脑常驻 + 微信/抖音/飞书直达分发」， 国际版 coze.com 是同产品另一入口。没有自托管形态——数据与运行时都在云端。

Coze is ByteDance's cloud-hosted agent-building platform: the domestic edition leads with “free model switching + always-on cloud phone/cloud PC + direct distribution via WeChat/Douyin/Feishu”; coze.com is the same product's other entry. There is no self-hosted form — data and runtime live in the cloud.

适合与不适合When to use it, when not to

适合：要国内分发链路直达、要国产模型（Doubao-Seed/Kimi/GLM/Minimax）随切、零部署起步。 不适合：要自托管掌控数据（去看 Dify 或 n8n 自托管）；要源码级控制（归 framework 大类）。

A fit for: domestic distribution channels, free switching among Chinese models (Doubao-Seed/Kimi/GLM/Minimax), zero-deployment starts. Not a fit for self-hosting for data control (see Dify or self-hosted n8n); source-level control (go to the framework category).
