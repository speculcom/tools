OpenVINO 是 Intel 的推理运行时与模型服务器：先把模型转成 IR，再在 CPU/GPU/NPU 上跑； OVMS 可暴露 OpenAI 兼容端点。

跨大类对照：Dify。

Intel's inference runtime and model server: convert the model to IR, run it on CPU/GPU/NPU, and expose OpenAI-compatible endpoints through OVMS.

适合与不适合When to use it, when not to

适合：Intel CPU/GPU/NPU、边缘部署、要把模型压到本地运行。 不适合：NVIDIA 独占优化场景、想要 GGUF 即下即跑。

Fits Intel CPU/GPU/NPU, edge deployment and squeezing models onto local hardware. Does not fit NVIDIA-only optimisation (TensorRT-LLM/vLLM are more direct) or download-and-run GGUF.

运行位置Where it runs

Runtime 库 + Model Server（OVMS）：OVMS 可暴露 OpenAI 兼容接口， 也可用 Docker 部署；本地/边缘/服务器都能跑。

Runtime library plus Model Server (OVMS): OVMS can expose an OpenAI-compatible endpoint and be deployed with Docker; it runs on local, edge and server hardware.

Self-hosted, with models and IR files on the local machine; no cloud account dependency.

Runtime is a library while OVMS is a long-running service; long tasks and concurrency are orchestrated by the deployer.
