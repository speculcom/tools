TabbyAPI: the official API backend server for ExLlamaV3 (AGPL-3.0, 1,502 stars, pushed 2026-10-30) — a FastAPI local inference server with OpenAI-compatible endpoints and official GHCR images covering CUDA 12.8/13 and AMD ROCm. 权限与限制Permissions & limits

本机运行；可配 API key（config.yml）；权限面=本机文件与 GPU。Docker 口径要 --shm-size 调大 （ExLlamaV3 用 POSIX 共享内存做张量并行/CPU MoE 卸载，默认 64MiB 不够——README 明写）。

Runs locally; an API key can be configured (config.yml); the permission surface = local files and GPU. The Docker wording requires a larger --shm-size (ExLlamaV3 uses POSIX shared memory for tensor parallelism and CPU MoE offload; the 64 MiB default is not enough — stated plainly in the README).
