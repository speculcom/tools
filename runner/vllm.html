vLLM 是开源模型的推理与服务化引擎：PagedAttention 把显存管理做成核心竞争力。OpenAI 兼容 server 直接对接现有客户端。

依据： Apache-2.0、PyTorch 基金会生态。数字口径：官方自报性能数字在 models 站 guides 已核验快照，本站不实测。

vLLM is an inference and serving engine for open models: PagedAttention makes memory management its core strength, and the OpenAI-compatible server plugs straight into existing clients. Apache-2.0, PyTorch Foundation umbrella. Numbers: vendor-claimed performance figures live in the models-site guides snapshot; this site does not benchmark.

适合与不适合When to use it, when not to

适合：生产部署多模型/高并发推理服务、GPU 集群吞吐优先。 不适合：个人单机开箱（Ollama 更省事）。GGUF 量化档深度依赖（llama.cpp 路线）。

Fits: production serving of many models/requests, GPU-cluster throughput, OpenAI-compatible endpoints. Not a fit: single-machine casual use (Ollama is easier); deep GGUF dependence.

第一次怎么用

  1. 在 NVIDIA GPU 机器上安装 vLLM，先跑 vllm --help 确认版本。
  2. 用 vllm serve <model> 起 OpenAI 兼容服务。模型名与上下文长度按官方文档配。
  3. 多人并发前先测显存峰值与 tokens/s，再调 batch 与并行参数。
  4. PagedAttention 管显存，但上下文越长 KV 缓存越吃显存。
  5. 生产环境加监控与限流；不要直接把默认参数暴露到公网。
pip install vllm
vllm serve <model> --host 0.0.0.0 --port 8000
# 然后按 OpenAI 兼容客户端调用；参数以官方文档为准
