vLLM 是开源模型「服务化」的标杆：PagedAttention 把显存管理做成核心竞争力，OpenAI 兼容 server 直接对接现有客户端。 Apache-2.0、PyTorch 基金会生态。数字口径：官方自报性能数字在 models 站 guides 已核验快照，本站不实测。

vLLM is the benchmark for serving open models: PagedAttention makes memory management its core strength, and the OpenAI-compatible server plugs straight into existing clients. Apache-2.0, PyTorch Foundation umbrella. Numbers: vendor-claimed performance figures live in the models-site guides snapshot; this site does not benchmark.

适合与不适合When to use it, when not to

适合：生产部署多模型/高并发推理服务、GPU 集群吞吐优先。 不适合：个人单机开箱（Ollama 更省事）、GGUF 量化档深度依赖（llama.cpp 路线）。

Fits: production serving of many models/requests, GPU-cluster throughput, OpenAI-compatible endpoints. Not a fit: single-machine casual use (Ollama is easier); deep GGUF dependence.
