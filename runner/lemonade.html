An AMD-ecosystem local model server: run models on your machine, expose an OpenAI-compatible API, support the llama.cpp backend and an experimental vLLM ROCm backend on Ryzen AI MAX+.

适合与不适合When to use it, when not to

Fits AMD Ryzen AI / NPU users who want a local OpenAI-compatible endpoint for offline or private work. Does not fit NVIDIA-only optimisation or an out-of-the-box GUI chat app (see LM Studio and similar).

模型与开放条件Model & openness

本地模型服务器。从 Hugging Face 拉取模型并在本机运行。支持 llama.cpp 后端。AMD Ryzen AI MAX+ 上另有实验性 vLLM ROCm 后端（官方 FAQ）。

A local model server: pulls models from Hugging Face and runs them on the machine; supports the llama.cpp backend, plus an experimental vLLM ROCm backend on AMD Ryzen AI MAX+ (official FAQ).

运行位置Where it runs

本地常驻服务。Windows 安装器或完整 SDK。提供 OpenAI 兼容 API。也可与 Ryzen AI 工具链配合。

A long-running local service: Windows installer or the full SDK; exposes an OpenAI-compatible API and can work with the Ryzen AI toolchain.

本地文件Local files

模型与数据在本地。不依赖云端账号，适合离线/隐私场景。模型缓存目录与更新由本地服务管理。

Models and data stay local; no cloud account dependency, which suits offline and privacy-sensitive use.
