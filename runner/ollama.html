Ollama Inc.
开源Open source MITMIT 本地推理Local inference GGUFGGUF OpenAI兼容OpenAI-compatible 模型库Model library partial lifecycle: active 核验Checked 2026-10-30

Ollama 是「本地跑开源模型」的事实标准入口：一条命令装完，从官方模型库一键拉模型， 本机起一个 OpenAI 兼容 API。诚实标注：工具 MIT，但权重许可跟着模型走；官方 README 明写还有云端线。

Ollama is the de-facto entry point for running open models locally: one command installs it, the official model library pulls models in one click, and an OpenAI-compatible API comes up on your machine. Honest notes: the tool is MIT but weight licenses follow each model; the official README explicitly mentions a cloud line.

适合与不适合When to use it, when not to

适合：快速把 DeepSeek/Qwen/Llama 这类开源模型跑起来、给本地应用接 OpenAI 兼容端点、桌面与服务器同一套命令。 不适合：高并发服务化调度（vLLM/SGLang 更合适）；对云端线数据边界有硬要求但没逐条核验过。

Fits: getting DeepSeek/Qwen/Llama running with one command, OpenAI-compatible local endpoints, desktop and server alike. Not a fit: high-concurrency serving (vLLM/SGLang), hard data-boundary requirements on the cloud line.
