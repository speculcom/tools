MLX 是 Apple 硅的官方本地推理栈：统一内存架构的原生框架（mlx）+ 官方 LLM 运行线（mlx-lm）， MIT、活跃维护。 Mac 用户跑本地模型的「亲儿子」路线——连微调都在同一栈里。

MLX is Apple's official local-inference stack for Apple silicon: a native framework for unified memory (mlx) plus the official LLM layer (mlx-lm), MIT, actively maintained. The 'native son' route for Mac users — even fine-tuning lives in the same stack.

适合与不适合When to use it, when not to

适合：M 系 Mac 要原生性能与统一内存红利。要在 Mac 上做 LoRA 微调。mlx-community 模型生态。 不适合：非 Apple 硬件（框架专属）；要跨平台单一技术栈。

Fits: native performance on M-series Macs (unified-memory dividend), LoRA fine-tuning on Mac, the mlx-community model ecosystem. Not a fit: non-Apple hardware; one cross-platform stack.
