MLC LLM：编译式跨平台推理引擎（Apache-2.0，23,284★ 推送 2026-10-30）—— 「Universal LLM Deployment Engine with ML Compilation」：把模型编译成目标平台原生码， 一套 MLCEngine 覆盖 NVIDIA/AMD/Intel GPU、Apple Metal（含 iOS）、浏览器 WebGPU/WASM（WebLLM）、 Android OpenCL，全部走 OpenAI 兼容 API。两条根口径：safetensors 编译路线 ≠ GGUF 预量化路线； 发版线在 PyPI 不在 GitHub releases（名义 v0.20.0/dev 标签 v0.26.dev0）。

MLC LLM: a compile-to-native cross-platform inference engine (Apache-2.0, 23,284 stars, pushed 2026-10-30) — "Universal LLM Deployment Engine with ML Compilation": compile models into platform-native code, one MLCEngine covering NVIDIA/AMD/Intel GPUs, Apple Metal (incl. iOS), browser WebGPU/WASM (WebLLM) and Android OpenCL, all behind an OpenAI-compatible API. Two root wordings: the safetensors-compile route ≠ the GGUF pre-quantization route; the release line is on PyPI, not GitHub releases (nominally v0.20.0 / dev tag v0.26.dev0).

适合与不适合When to use it, when not to

适合：一套引擎多平台部署（尤其移动端与浏览器端）；编译期优化换性能的工程路线。 不适合：GGUF 即下即跑的省事路线（llama.cpp/Ollama）；不想碰编译步骤的用户。

Fits: one engine deployed across platforms (especially mobile and browser ends); an engineering route trading compile-time optimization for performance. Not a fit: the GGUF download-and-run convenience route (llama.cpp/Ollama); users who do not want to touch a compile step.

模型与开放条件Model & openness

自带编译式推理引擎（MLCEngine）——不是调外部模型的服务，是把模型编译成目标平台的原生执行码 （「Universal LLM Deployment Engine with ML Compilation」官方定位）。模型侧吃 safetensors 系 （HF 权重编译路线），与 llama.cpp 的 GGUF 预量化路线是两条根。

Ships its own compiled inference engine (MLCEngine) — not a service calling an external model; it compiles models into native executables for the target platform (the official positioning: "Universal LLM Deployment Engine with ML Compilation"). On the model side it takes the safetensors family (the HF-weights-compile route), a different root from llama.cpp's pre-quantized GGUF route.
