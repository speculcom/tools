SGLang 是服务化推理的「前缀复用」一代：RadixAttention 把多轮/共享前缀的 KV 缓存复用做成主轴， agent 工作流场景收益直接。Apache-2.0，LMSYS 系学术开源。自报数字走 models 站 guides 快照口径。

SGLang is the prefix-reuse generation of serving engines: RadixAttention makes KV-cache reuse across turns and shared prefixes the main axis, so agent workloads benefit directly. Apache-2.0, LMSYS-line academic open source. Vendor figures follow the models-site guides snapshot.

适合与不适合When to use it, when not to

适合：agent 多轮调用、大量共享 system prompt/few-shot 的服务化部署、要官方结构化输出特性。 不适合：单机开箱（Ollama）；要最宽生态兼容面（vLLM 更成熟）。

Fits: agent multi-turn calls, serving workloads with shared system prompts/few-shots, official structured-output features. Not a fit: casual single-machine use; needing the widest ecosystem surface (vLLM is broader).
