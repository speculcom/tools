ExLlamaV3 是 ExLlamaV2 的接续线。 用 EXL3 量化格式在 NVIDIA GPU 上做低延迟本地推理。 它是引擎本体，不是 GGUF 工具，也不是 API server。

跨大类对照：LlamaIndex。

The successor to ExLlamaV2: low-latency local inference on NVIDIA GPUs using the EXL3 quantisation format. It is an engine, not a GGUF tool and not an API server.

适合与不适合When to use it, when not to

适合：NVIDIA 单机/多卡、追 EXL3 量化、愿意自己配 CUDA 环境。 不适合：AMD/CPU、想要开箱 GUI、依赖 GGUF 生态。

Fits NVIDIA single/multi-GPU users chasing EXL3 quantisation and low-latency inference who are willing to set up CUDA. Does not fit AMD/CPU, an out-of-the-box GUI, or the GGUF ecosystem.
