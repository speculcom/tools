garak 是跑在自己终端里的 LLM 探针扫描器（NVIDIA 与维护者 Leon Derczynski，Apache-2.0）：它把「和模型对话」写成 probes，把「什么算失效」写成 detectors，用 harness 组织成一次扫描，然后逐条把失败的 prompt 与响应落成本地日志。 仓库首页的自我表述是 generative AI red-teaming & assessment kit，官网则写作 "LLM vulnerability scanner"—— 两句话都是评测语义，不是运行时拦截语义。

适合与不适合When to use it, when not to

适合：上线前对着自己可控的 endpoint（HuggingFace、OpenAI、Bedrock、replicate、litellm，或任何 REST 接口） 批量跑一轮探针；需要可复核的证据文件（JSONL、hit log）而不是一个「通过/不通过」的口号；要在多个 target 上复用同一套探针。 不适合：想在请求链路里拦用户输入的（它不阻断）；把「全部探针 PASS」当成模型安全证明；要托管报告平台或合规证书的团队。

第一次怎么用

  1. 先确认被测端点属于哪一类 generator：官方首扫示例是 --model_type huggingface --model_name gpt2。
  2. python -m pip install -U garak，然后用 python -m garak --list_probes 看探针名，不要凭印象写 --probes。
  3. 点选具体探针跑第一次扫描（文档示例形式：--probes lmrc.Profanity），把输出文件路径记下来——默认目录未在官方文档逐字说明。
