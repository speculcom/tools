适合与不适合When to use it, when not to

The primary form is the vendor-hosted cloud (SaaS), with BYOC and enterprise self-hosting: the official line reads that self-hosted LangSmith is an add-on to the Enterprise plan and runs in your own Kubernetes cluster, storage is bundled by default and external storage services are recommended for production (self-hosted docs fetched today). The console lives in the browser; SDKs, the CLI and the API are the code surfaces.

适合什么任务Best for

Fits teams that want one console covering traces, datasets, evaluators and alerts without operating their own observability stack; applications already on OpenTelemetry can feed in first and decide later whether to fan out elsewhere. Not a fit where licensing thresholds are treated as secondary: self-hosting is, per official docs, an Enterprise add-on that also needs your own cluster and external storage. This site records which evaluation types are supported, not the scores they produce, and does not rank peers.
