LangSmith 是托管型的观测与评测平台。 当日在册的官方自我定位是「agent 与 LLM 观测平台」，评测是其中一个面板。

LangSmith is a hosted observability and evaluation platform. Its official self-description on file is an agent and LLM observability platform, with evaluation as one panel.

适合与不适合When to use it, when not to

适合想要一个控制台同时管 trace、数据集、评测器和告警。又不想自运维观测栈的团队。

已有 OpenTelemetry 的应用可以先接进来。之后再决定要不要同时发往别的后端。不适合把许可门槛当次要问题的团队。

自托管按官方口径是企业版加购，还要自备集群与外部存储。本档只写它支持哪些评测类型，不写它测出来的分数，也不做同类排名。

Fit: teams wanting one console for traces, datasets, evaluators and alerts without running the observability stack themselves. Apps already on OpenTelemetry can connect first and later decide whether to dual-send to another backend. Not fit: teams treating licence terms as secondary; self-hosting is officially an Enterprise add-on and needs your own cluster and external storage. This entry records supported evaluation types, not scores or peer rankings.

运行位置Where it runs

主形态是厂商托管云（SaaS）。另有 BYOC 与企业版自托管。官方写「Self-hosted LangSmith 是 Enterprise 加购」「在你自己的 Kubernetes 集群里跑」。

The primary form is the vendor-hosted cloud (SaaS), with BYOC and enterprise self-hosting: the official line reads that self-hosted LangSmith is an add-on to the Enterprise plan and runs in your own Kubernetes cluster, storage is bundled by default and external storage services are recommended for production (self-hosted docs fetched today). The console lives in the browser; SDKs, the CLI and the API are the code surfaces.
