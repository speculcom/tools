Inspect 是英国 AI 安全研究所（与 Meridian Labs）做的开源评测框架：用 Python 把 Dataset、Solver、Scorer 拼成一个 Task，用 inspect eval 在你自己的环境里跑，靠沙箱、工具审批与本地日志把「不受信的模型代码」这件事管起来——官方文档首页同时把它定位成 frontier AI evaluations 的写作与复用工件，而不是托管打分服务。

适合与不适合When to use it, when not to

适合：要自己写评测与 agent 任务（含多 agent 与外部 agent）、要把模型生成的不受信代码放进 Docker / Kubernetes 一类沙箱、要在终端批量跑评测集并在本地日志里逐样本复核、要在多家 provider 之间复用同一份任务定义。 不适合：只想在网页控制台点几下就拿到结论、只需要几个打分指标不想维护 Python 工程、把别人跑出的分数当交付物（本站也不这样用）。

适合什么任务Best for

适合：自己写评测与 agent 任务、要把不受信模型代码关进沙箱、要工具审批与本地日志复核、要跨 20 余家 provider 跑同一份任务。 不适合：只想点托管控制台、只要一个指标库而不想维护 Python 评测、把跑分榜单当交付物。

Fits: writing your own evals and agent tasks, putting untrusted model code into a sandbox, keeping tool approval plus local logs for sample-by-sample review, and running one task definition across 20+ providers. Not a fit: wanting only a hosted console, needing a metric library without maintaining Python evaluations, or treating somebody else's leaderboard numbers as the deliverable.

第一次怎么用First run

  1. 先确定模型接入：官方快速上手示例是「装对应 SDK + 导出 API key」，本地推理走 HuggingFace / vLLM / SGLang。
  2. pip install inspect-ai，用 inspect eval <task.py> --model <provider/model> 跑第一个任务。
  3. 需要模型执行代码或操作文件时，先读官方 Sandboxing 口径，把任务放进 Docker 等沙箱后端，再考虑工具审批。
  4. 想看逐样本结果，用官方列出的 Inspect View；要边写边调，官方推荐（但非必需）VS Code 扩展。
  5. 批量跑多任务时查官方文档的 Eval Sets 与 Parallelism 条目，而不是自己写循环。
  1. Decide the model access first: the official quick-start pattern is "install the matching SDK + export the API key", and local inference goes through HuggingFace / vLLM / SGLang.
  2. pip install inspect-ai, then run the first task with inspect eval <task.py> --model <provider/model>.
  3. If the model executes code or touches files, read the official Sandboxing position first and put the task into a sandbox backend such as Docker, then consider tool approval.
  4. To go through results sample by sample use the Inspect View tool listed in the docs; for authoring and debugging the official docs recommend (but do not require) the VS Code extension.
  5. For batch runs, use the docs entries on Eval Sets and Parallelism rather than writing your own loop.
