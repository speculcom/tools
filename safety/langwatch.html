LangWatch 是把线上调用、评测与提示版本收在一处的 LLMOps 平台：官方列出的能力是追踪每一次模型调用、工具使用与用户交互，并在其上跑评测与代理测试。开源核心可自托管（文档写为 Apache-2.0），另提供托管版。

LangWatch is an LLMOps platform that puts online calls, evaluation and prompt versions in one place: officially it traces every model call, tool use and user interaction, then runs evaluation and agent tests on top. The open-source core can be self-hosted (docs say Apache-2.0), and a hosted version is also offered.

适合与不适合When to use it, when not to

适合：需要把 trace、评测与提示变更放在一起复盘，同时希望保留自托管退路的团队。 不适合：只想要一个现成基准分数；或对「调用记录是否离开自己环境」有硬性限制却打算用托管版的场景。

Fit: teams that want traces, evaluation and prompt changes reviewed together while keeping a self-hosting exit. Not fit: wanting a ready-made benchmark score, or teams with a hard rule that call records must not leave their environment but planning to use the hosted version.

第一次怎么用

  1. 先决定运行位置：能接受托管版就核对留存与删除条款；不能接受就按文档自托管开源核心，并逐项确认你需要的是否在核心内。
  2. 接入时只送必要字段：把客户姓名、订单号、密钥这类内容在进入 trace 前处理掉，事后清理比事前控制难。
  3. 评测从你自己的样本集开始：先写判法（哪些能机器判、哪些必须人判），再挂到线上 trace 上，别用平台默认指标替代验收标准。
  4. 每次改动记录三件东西：提示版本、模型标识、评测样本集版本；缺一件，下一轮的对比就失去解释力。
