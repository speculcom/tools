README（2026-11-06 抓取）对四层的原样表述：Heuristics 在输入到达 LLM 前过滤可疑内容； LLM-based detection 用专用 LLM 分析 prompt 并识别攻击；VectorDB 存历史攻击 embedding 以拦相似攻击； Canary tokens 在 prompt 里加令牌以检测泄漏，并据此刻录本次输入的 embedding 防未来攻击。
