适合与不适合When to use it, when not to

适合：要把多轮自适应攻击（文档点名的 Crescendo、TAP）编排成可重复 assessment；需要本地 memory 后端把过程落进 你自己的 SQLite 或 Azure SQL；团队想让复核人员在 CoPyRIT 界面里逐条看结果；已经把 garak 风格探针纳入同一套扫描流程 （官方 scenario 页直接给 pyrit_scan run garak.prompt_inject 这种形式）。不适合：只想一条命令扫完就走； 要托管报告平台或合规交付物；指望工具替代红队人员的判断。

第一次怎么用

  1. pip install pyrit（注意 PyPI 的 Python 区间 =3.10,3.15）。
  2. 按官方 secrets 页把凭据放进环境变量或 .env：至少要有能驱动攻击的模型端点三件套，再加被测 target。
  3. 选一个 scenario 家族跑第一轮（pyrit_scan run garak.prompt_inject --target openai_chat 是官方在册示例形式）， 先确认 memory 后端把过程写到了哪里。
  4. 需要人工复核时再起 CoPyRIT；要把流程固化进发布门禁，就把这轮 run 的参数与记录一起版本化。
  5. 从 0.x 升上来的项目，先读 v1.0.0 的 release notes 再改代码。
