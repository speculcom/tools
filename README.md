# AI 工具

> 让 AI 替你干活 —— 装在哪、连什么、边界在哪

**tools.specul.com** · 独立信息项目（非厂商官方榜单）

按任务分 10 大类，归三族：找现成的（编程 / 对话 / 图像 / 视频 / 音频 / 研究）、自己搭（自动化 / 框架）、接上与跑起来（MCP 工具 / 本地运行器）。各族坐标系不同，不做横向排名。

## 10 个大类，归三族

| 大类 | 主题 | 对象数 | 主要坐标系 |
|---|---|---|---|
| [AI 编程](./coding/) | 装在编辑器、终端，或厂商云里 | 41 | 8 通用维度，按形态分组 |
| [AI 对话助手](./chat/) | 通用对话产品，含国产 | 21 | 8 通用维度 |
| [AI 图像创作](./image/) | 文生图与图像工作台 | 15 | 8 通用维度 |
| [AI 视频创作](./video/) | 文生视频与数字人 | 14 | 8 通用维度 |
| [AI 音频与语音](./audio/) | 音乐生成、语音合成与转写 | 17 | 8 通用维度 |
| [AI 搜索与研究](./research/) | AI 搜索、学术检索与研究工作台 | 11 | 8 通用维度 |
| [AI 自动化与工作流](./automation/) | 可视化搭 AI 工作流与 agent | 22 | 8 通用维度 |
| [框架与运行时](./framework/) | 运行时、编排框架、SDK | 27 | 8 通用维度，按抽象层分组 |
| [MCP 工具](./mcp/) | 缺什么，装什么 —— 给 agent 装的 MCP 工具 | 32 | 8 通用 + 3 MCP 特有 |
| [本地模型运行器](./runner/) | 在自己机器上跑开源模型 | 16 | 8 通用维度 |

**为什么不把所有对象塞进一张总表**：三族的坐标系不同，混排会制造假的可比性。
成品工具与自己搭的底座都能进同一个八维坐标系，但它们解决的不是同一个问题；
MCP 工具层用的是另外三个维度（传输 / 认证 / 权限范围），八维套不上去。

## 方法

- **不给总分排名**——缺少跨工具的统一实测，排名会误导
- **「未知」是合法答案**——查不到就写未知并说明原因，不用推测填充
- **不同族不混排**——铁律都写在数据仓 `METHODOLOGY.md` 里
