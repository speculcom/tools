Not a fit: wanting a self-serve menu of overseas models (the mainline model set is domestic LLMs); still relying on the VS Code plugin (maintenance ended).

模型与开放条件Model & openness

官方模型选择器页明示三档用法。Auto 智能路由、Fast 快速档位、直接指定模型。

可指定清单含 Qwen3.8/3.7 系、DeepSeek-V4-Pro/Flash、GLM-5.3/Flash、Kimi-K3/K2.8-Preview、MiniMax-M3.1-Flash。

各带 Credits 用量参考系数，清单与系数以客户端为准。

还可通过 API 密钥接入自己的模型。官方「自定义模型」页有说明，CLI 侧称 BYOK 向导。系列页官方口径称，底层支持多家国内主流大模型。包括 GLM、DeepSeek、Kimi 与 MiniMax。

The official model-selector page states three usage tiers: Auto smart routing, Fast tier, direct model selection; the selectable list includes the Qwen3.8/3.7 series, DeepSeek-V4-Pro/Flash, GLM-5.3/Flash, Kimi-K3/K2.8-Preview, MiniMax-M3.1-Flash (each with a Credits usage reference factor; the list and factors follow the client); you can also bring your own models via API keys (official "custom models" page; the CLI side calls it a BYOK wizard). The series page's official line: "under the hood it supports GLM, DeepSeek, Kimi, MiniMax and other mainstream domestic LLMs".

运行位置Where it runs

Qoder CN 是产品系列（官方家族页）。

一体化 AI 工作空间 Qoder CN（桌面应用）、Qoder CN IDE、Qoder CN JetBrains 插件、Qoder CN CLI。

Agent SDK（TypeScript/Python）、Cloud Agents CN（云端全托管 Agent 平台）、QoderWake CN（数字员工）、移动端与网页版。

Credits 跨产品共享（订阅口径见官方账号与订阅页）。编码主线是 IDE/插件/CLI 三形态。官方「什么是 Qoder CN IDE」页明示 VS Code 插件已停止维护。

Qoder CN is a product family (official family page): the all-in-one AI workspace Qoder CN (desktop app), Qoder CN IDE, Qoder CN JetBrains plugin, Qoder CN CLI, Agent SDK (TypeScript/Python), Cloud Agents CN (a fully managed cloud Agent platform), QoderWake CN (digital employees), mobile and web editions; Credits are shared across products (subscription terms on the official account & subscription page). The coding mainline is the IDE/plugin/CLI trio; the official "what is Qoder CN IDE" page states the VS Code plugin is no longer maintained.

本地文件Local files

IDE、插件与 CLI 形态处理你本机代码与工程。官方安全页称，Qoder CN 可处理本地代码、已安装扩展、远程连接和外部服务。

CLI 的记忆文件含 AGENTS.md 与自动记忆，保存在本机。可在设置中查看与清空。模型推理发生在服务侧。系列页官方口径「全链路在国内云上部署」。

Cloud Agents CN / QoderWake CN 线的数据边界按官方文档口径。

The IDE/plugin/CLI forms work with your local code and projects (official security page: Qoder CN can handle local code, installed extensions, remote connections and external services); the CLI's memory files (AGENTS.md and automatic memory) are stored on your machine, viewable and clearable in settings. Model inference happens server-side — the series page's official line: "the full chain is deployed on domestic cloud"; the data boundaries of the Cloud Agents CN / QoderWake CN lines were official docs do not itemize every sub-detail.

关机后的任务Tasks after shutdown

依据： 后台/异步面是官方叙事的一部分：Cloud Agents CN 全托管长时异步任务（官方原文：关闭客户端后任务继续运行）、 批量并发执行。CLI 有定时任务、/loop 循环执行、Cloud Mode 与 Remote Control。 移动端可查看智能体进展、审批关键操作（官网口径）。 注意官方公告「Qoder CN IDE『Quest』视窗下线通知」。旧教程里的 Quest 面已过时。

The background/async surface is part of the official narrative: Cloud Agents CN runs fully managed long-running async tasks (official wording: tasks keep running after the client closes (translated)), batch concurrent execution; the CLI has scheduled tasks, /loop repeated execution, Cloud Mode and Remote Control; the mobile app can view agent progress and approve key operations (official-site framing). Note the official notice "Qoder CN IDE 'Quest' panel retirement notice" — the Quest surface in old tutorials is outdated.

工具与扩展Tools & extensions

官方文档给全扩展面。MCP 可接连接器市场或自定义服务器。配置文件在 ~/.qoder/settings.json。

另有 Skills、Plugins、Subagents、Hooks、自定义指令与命令。Subagents 是专家团，覆盖前后端、数据库、运维与测试。

依据： CLI 内置文件读写、Shell 执行与 Grep/Glob。也支持 Web 搜索与网页抓取。支持非交互模式接入脚本与 CI/CD。

另有 Repo Wiki，为代码仓库生成项目知识。还有代码安全扫描，在提交/推送前渐进式扫描。

Official docs cover the full extension surface: MCP (connector marketplace or custom MCP servers, configured in ~/.qoder/settings.json), Skills, Plugins, Subagents (expert teams: frontend/backend/database/ops/testing domain agents), Hooks, custom instructions and commands; the CLI has built-in file read/write, Shell execution, Grep/Glob, web search and page fetching, with a non-interactive mode for scripts and CI/CD; there is also Repo Wiki (generates project knowledge for a code repository) and code security scanning (progressive scans before commit/push).

上下文与记忆Context & memory

记忆机制官方成页。全局记忆与项目记忆两类、可分别开关与清空，保存在本机记忆目录。

官方把上下文来源分三层。记忆保存跨任务偏好背景。Repo Wiki 为代码库生成项目知识。知识库是团队维护的结构化资料。

另有上下文压缩、代码库索引、规则设置、多模态输入（图片/PDF）。

The memory mechanism has official pages: two classes — global memory and project memory, each toggleable and clearable, stored in the local memory directory; the official docs split context sources into three layers — memory (cross-task preferences and background), Repo Wiki (project knowledge generated from the codebase), knowledge base (structured material maintained by teams); there is also context compaction, codebase indexing, rule settings, multimodal input (images/PDF).

权限与限制Permissions & limits

账号体系（阿里云账号）。CLI 有权限模式、规则配置与工具调用审批流（官方权限页）。终端与沙箱页明示在任务中运行项目命令并审查需要授权的操作。

安全与授权页给账号/凭证/扩展/连接的核查清单。企业侧有企业标准版与企业专属版（VPC 部署）。

Account system (Alibaba Cloud account); the CLI has permission modes, rule configuration and a tool-call approval flow (official permissions page); the terminal & sandbox page states that running project commands during tasks and reviewing operations that need authorization requires approval; the security & authorization page gives a checklist for accounts/credentials/extensions/connections. On the enterprise side there is an Enterprise Standard and an Enterprise Dedicated edition (VPC deployment).

改名史Name history

品牌改名史（档案要写清）。智能编码助手通义灵码 Lingma 于 2023 首发。后转为 Qoder CN 系列，2026-05-20 官方正式更名。

桌面应用曾用名 Lingma IDE、Qoder CN Desktop。 同一产品不同时期多个名字。检索时通义灵码/Lingma/Qoder CN 都要认。

The brand renaming history (dossiers must state it clearly): the intelligent coding assistant Tongyi Lingma (Lingma, first launched 2023) → the Qoder CN series (officially renamed 2026-05-20); the desktop app was formerly named Lingma IDE, Qoder CN Desktop — the same product under multiple names across periods; when searching, recognize Tongyi Lingma / Lingma / Qoder CN alike.
