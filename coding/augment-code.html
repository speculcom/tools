Augment Code 是企业级「软件工厂」平台：Cosmos 把规划-实现-评审-反馈连成可重复的 agent 流水线， Environments 可托管云/自有基础设施/本机三选一，Code Context Engine 招牌可经 MCP 插进别的 agent， 前沿模型清单最全之一（含自研 Prism 路由）——2026-10-08 官方公告 Cosmos/Auggie CLI/Context Engine 资产加入 Harness。

Augment Code is an enterprise 'software factory' platform: Cosmos chains plan-implement-review-feedback into repeatable agent loops, Environments run on Augment-hosted cloud, your own infrastructure (self-hosted daemons) or your laptop, the Code Context Engine plugs into other agents via MCP, and the model menu is among the broadest (including the proprietary Prism router) — per the 2026-10-08 official notice, Cosmos, Auggie CLI and the Context Engine assets are joining Harness.

适合与不适合When to use it, when not to

适合：企业级跨 SDLC 的 agent 流水线、self-hosted 把 agent 跑在自己基础设施、要多前沿模型清单与 token 透明计费。 不适合：找个人免费档入门、要产品归属完全稳定（正处 Harness 并入过渡期）。

Fits: enterprise cross-SDLC agent pipelines, self-hosted environments running agents on your own infrastructure, a broad frontier-model menu with transparent token-based billing. Not a fit: looking for a personal free tier on-ramp (the mainline is enterprise delivery with token billing); needing fully stable product ownership (mid-transition into Harness).

模型与开放条件Model & openness

官方 Available Models 页列全清单：Anthropic Claude 系（Fable 5.1/5、Opus 5/4.8/4.7/4.6、Sonnet 5.5/5、Haiku 4.5）、 Google Gemini（3.8/3.7 Flash、3.1 Pro）、OpenAI GPT（6.1 Sol、6 Astra、5.6 Sol/Terra/Luna、5.5）、 xAI Grok 4.6/4.5、智谱 GLM 5.3 Flash/5.2 与 Moonshot Kimi K3/K2.7 Code（托管在 Fireworks/Baseten）、 自研 Prism（组合 Claude 与 GPT 的模型集成，Prism 选项按策展模型族路由）。 计费走 token 制（Token-Based Pricing 页：LLM token + Cosmos 算力 + 服务费三段）。

运行位置Where it runs

主线是 Cosmos 平台（官方 Introduction：Environments/Experts/Sessions/Capabilities/Triggers 五积木）： 把规划-实现-评审-反馈连成可重复的 Software Factory 工作流（Requirements→Ticket、Ticket→PR、 PR→Merge、Signal→Ticket 四条官方 loop）。Environments 三选一：Augment 托管云沙箱、你自己的 VM/物理机 （self-hosted daemon）、甚至本机笔记本。另有 Auggie CLI（终端 agent：仓库实现/代码探索/跑测试/CI 自动化） 与 VS Code / JetBrains 的 IDE 扩展面。

本地文件Local files

IDE 扩展与 Auggie CLI 处理本机代码库；Cosmos 的 Environments 决定代码在哪——托管云沙箱、 self-hosted daemon（跑在你自己基础设施上，daemon-config.json 配工作区与隔离）或本机。 self-hosted 面是官方一等公民（官方页明示 own virtual or physical infrastructure）。

关机后的任务Tasks after shutdown

Cosmos 主打长时多步交付：durable environments、scheduled automations（定时自动化）、 跨仓库跨工具协调（官方 llms.txt 使用指引原文）；Triggers 把事件接进 loop。 官方叙事「always-on software delivery system」——从 spec 到验证常跑。

工具与扩展Tools & extensions

MCP 面官方成页多处：Cosmos Experts 接 MCP servers（MCP Registry）、CLI/IDE 侧 MCP 配置、 Context Engine MCP（把上下文引擎以 MCP 插进任何 agent）、Code Review 的 MCP context 接入； 官方还提供 Docs MCP server（Streamable HTTP）给外部 agent 查 Augment 文档。

上下文与记忆Context & memory

招牌是 Code Context Engine：官方口径 world-class context engine，跨代码库的结构化理解； 以 MCP 形式输出给别的 agent 用（Context Engine MCP 页）。 Wisdom 类上下文（PR 历史、业务需求）在 Software Factory 各 loop 页有展开。
