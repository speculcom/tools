Plugin/IDE/CLI forms work on local code; the official FAQ states that SaaS inference must pass the preceding context of the file being written to the model, and promises (translated from the official wording) "no subsequent accumulation, analysis or processing is done with this uploaded code"; under private deployment the models and services all sit in the customer's private domain — data never leaves the domain (per the FAQ wording).
