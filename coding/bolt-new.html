Bolt.new 是 StackBlitz 的浏览器内全栈 AI 构建器：跑在 WebContainers 上（浏览器里直接跑 Node.js， 免装环境），agent 分 Standard/Max 两档、按 token 计量，Bolt Cloud 给托管+数据库，GitHub 双向同步线在位。

Bolt.new is StackBlitz's in-browser full-stack AI builder: it runs on WebContainers (Node.js directly in the browser, no local setup), the agent comes in Standard and Max tiers billed by tokens, Bolt Cloud adds hosting plus a database, and a GitHub sync line is in place.

适合与不适合When to use it, when not to

适合：免装环境直接建应用、GitHub 同步、内置托管一条龙、非技术者与开发者共用。 不适合：深度离线场景、要完全掌控构建模型（Forge 按计划绑定）。

Fits: building full-stack apps in the browser with zero local setup (WebContainers), the GitHub sync line, hosting plus database in one place (Bolt Cloud), non-coders and developers sharing one environment. Not a fit: deep offline work (the platform-internal narrative); full control over the build model (Forge is a plan-bound open-source-model line).
