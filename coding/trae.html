Trae 是字节跳动的三端 AI IDE（桌面/Web/移动）：Desktop 双窗口（Agent/IDE）+ SOLO 模式整段委托， 内置多模型可加自定义 key，Privacy mode 与沙箱执行是官方显式给的开关。

Trae is ByteDance's three-client AI IDE (desktop / web / mobile): dual windows on desktop (Agent/IDE) with SOLO mode for whole-task delegation, built-in multi-model plus custom keys, Privacy mode and sandboxed execution as official switches.

适合与不适合When to use it, when not to

适合：三端同一任务流、SOLO 整段委托、多模型免配 key 起步。 不适合：假设国内外两版功能一致、要完全离线。

Fits: one task flow across desktop+web+mobile, whole-task delegation via SOLO mode, starting with built-in multi-model without configuring your own keys. Not a fit: expecting the domestic and international editions to match (two separate lines); fully offline use (cloud tasks are part of the product semantics).

模型与开放条件Model & openness

官方文档（docs.trae.ai/ide/models）明示内置多模型并支持 API key 添加自定义模型； 内置清单随版本变化（本次抓到的清单含 GPT 系/DeepSeek/Gemini 系等条目，未逐条清点为完整列表）。 国际版（trae.ai）与国内版（trae.cn）模型面不同，以各自官方页为准。

The official docs (docs.trae.ai/ide/models) explicitly state built-in multi-model support, plus adding custom models via API key. The built-in list changes with versions (the list captured this pass includes GPT-family / DeepSeek / Gemini-family entries; not enumerated as a complete list). The international edition (trae.ai) and domestic edition (trae.cn) differ in model surface — each official page is authoritative.

运行位置Where it runs

官方口径三客户端：Desktop（独立应用，不依赖 TRAE IDE 运行，支持本地与云任务）、 Web（云端环境免安装）、Mobile（派发管理任务，设备离线自动切云执行）。 Desktop 给 Agent 窗口与 IDE 窗口双窗口；IDE 窗口内 IDE 模式与 SOLO 模式切换。

Official framing: three clients — Desktop (a standalone app that does not depend on TRAE IDE to run; supports local and cloud tasks), Web (a no-install cloud environment), Mobile (dispatch and manage tasks; auto-switches to cloud execution when the device is offline). Desktop gives dual windows: the Agent window and the IDE window; inside the IDE window you switch between IDE mode and SOLO mode.

本地文件Local files

官方安全页明示：代码库文件始终留在本地设备（Privacy mode 语境）； 沙箱执行把 agent 生成的命令放进受限环境（文件访问控制+高危命令拦截）。云任务线的数据边界未逐条核验。

The official security page states explicitly: codebase files always stay on the local device (in the Privacy mode context). Sandboxed execution puts agent-generated commands into a restricted environment (file-access control + high-risk command interception). Data boundaries of the cloud-task line: not verified one by one.

关机后的任务Tasks after shutdown

后台/异步面是官方叙事的一部分：Desktop 支持长任务交云、Mobile 跨设备监控任务进度、 离线自动切云执行——任务状态三端同步（官方文档口径）。

The background/async surface is part of the official narrative: Desktop supports handing long tasks to the cloud, Mobile monitors task progress across devices, offline auto-switches to cloud execution — task state syncs across the three clients (official docs framing).

工具与扩展Tools & extensions

agent 可搜代码库、多步计划、调工具；自定义 agent 可配 prompt/MCP 服务器/工具集（官方文档明示 MCP 配置面）； CUE 补全线（多行编辑/下一编辑预测）独立成页。

The agent can search the codebase, plan in multiple steps and call tools. Custom agents can configure prompt / MCP servers / tool sets (the official docs state the MCP configuration surface explicitly). The CUE completion line (multi-line edits / next-edit prediction) has its own page.
