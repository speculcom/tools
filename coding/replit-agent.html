Replit Agent 是「从自然语言到能上线的应用」的云 IDE agent：建项目、装基础设施、测试、部署一条龙， Free/Power/Max 模式选档不选裸模型，checkpoint 兜底回滚。

Replit Agent is the cloud-IDE agent from plain language to a deployable app: it builds the project, sets up infrastructure, tests, and deploys in one chain; Free/Power/Max modes pick tiers rather than bare models, with checkpoints as the rollback safety net.

适合与不适合When to use it, when not to

适合：想法直达可部署应用、非工程师原型、多产物同后端。 不适合：以你现有代码库为主战场、要模型完全自选。

Fits: idea straight to a deployable app (database/deploy included), non-engineer prototypes, multiple artifacts sharing one backend. Not a fit: your existing codebase as the main battlefield; fully self-selecting models.

模型与开放条件Model & openness

按「模式」选而非按裸模型选：官方文档列 Free/Auto/Power/Max 四态——Free 是套餐额度内的免费档， Auto 自动路由，Power/Max 是付费档（Max 用最强前沿模型）；具体每档挂哪些模型官方按套餐页口径给， 未逐条清点。企业工作区只有一个 Auto 模式，管理员可用 Enterprise model controls 管模型访问。

运行位置Where it runs

云端 IDE 内建 agent：项目、依赖、数据库、部署全在 Replit 云上；官方文档明确 Agent 会 「写代码、搭基础设施、测结果」并自动建 checkpoint 可回滚。桌面/手机是入口，执行在云上。

本地文件Local files

代码与数据默认在 Replit 云项目里，不在你本机；产物可导出（官方有导出/迁移线，细节未逐条核验）。 连接外部服务（BigQuery/Slack/Notion/Linear 等）经官方 connector 从聊天直接取数。

关机后的任务Tasks after shutdown

有后台任务面：官方文档给 Core 1 个、Pro 10 个「Active background tasks」的配额行—— 后台跑任务是产品语义的一部分；Plan mode 先出任务清单供审批再动工。

工具与扩展Tools & extensions

agent 自带建项目/装依赖/测试/部署全链；connector 面（BigQuery/Slack/Notion/Linear 等） 是官方列出的连接目录，未逐条清点。MCP 支持状态未核验到官方声明。

上下文与记忆Context & memory

项目内多产物共享同一后端与数据（web/mobile/slides/视频同项目）；checkpoint 提供状态回滚面。 跨项目记忆未见官方声明。

权限与限制Permissions & limits

账号+套餐体系；付费动作需确认（官方 FAQ：paid actions require confirmation before they start， Free 不够时给 Allow once 单次放行）；企业版有模型访问管控。部署即 Replit 托管 URL。

适合什么任务Best for

适合：从自然语言直接到「能上线的应用」（含数据库/部署）、非工程师做原型、要 checkpoint 回滚兜底。 不适合：要接你自己已有的代码库为主战场（它主轴是从想法到新项目）、要模型层完全自选。

头号误解Top misconception

  • 把 Replit Agent 当「装进现有仓库的编码 agent」——官方定位是从想法到新项目（含基础设施），
  • 现有代码库协作不是它文档的主叙事
  • Free/Power/Max 是「模式」不是模型名——每档背后挂什么模型随官方调整，别把档位当固定模型清单
  • 产物与数据默认在 Replit 云上——导出与迁移线存在但边界要自己核（未逐条核验）
