模型与开放条件Model & openness

按「模式」选而非按裸模型选。官方文档列 Free/Auto/Power/Max 四态。Free 是套餐额度内的免费档。Auto 自动路由。

Power/Max 是付费档（Max 使用官方定位的前沿模型）。每档可用模型在账户内 Model selector 实时展示。官方口径是模型清单以账户为准，随套餐与滚动上线变化。

企业工作区只有一个 Auto 模式。管理员可用 Enterprise model controls 管模型访问。

Choose by "mode" rather than by bare model: the official docs list four modes — Free/Auto/Power/Max. Free is the free tier within plan allowances, Auto routes automatically, Power/Max are paid tiers (Max uses the strongest frontier models). Which models sit behind each tier is shown live by the in-account Model selector (official framing: the model list is account-specific and shifts with plans and staged rollouts). Enterprise workspaces have only the Auto mode; admins can manage model access via Enterprise model controls.

运行位置Where it runs

依据： 云端 IDE 内建 agent。项目、依赖、数据库与部署全在 Replit 云上。官方文档明确 Agent 会写代码、搭基础设施、测结果，并自动建 checkpoint 可回滚。桌面/手机是入口，执行在云上。

Built-in agent in a cloud IDE: projects, dependencies, databases and deployments all live on Replit cloud. The official docs state the Agent "writes code, sets up infrastructure, tests results" and automatically creates checkpoints you can roll back to. Desktop/mobile are entry points; execution happens in the cloud.
