① Asks per path, with an "allow just this once"

v2.1.284 added an option:

`` Added a "Yes, but ask again next time" answer to auto mode's prompt before a read outside the working directories, so you can allow that one read and still be asked about later ones ``

This design deserves its own record. Most tools' approvals have only two states — allow / deny. Claude Code offers a third state: allow this once, but keep asking.

It resolves a real dilemma:
