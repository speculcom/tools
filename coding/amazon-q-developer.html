Amazon Q Developer is AWS's coding-and-operations assistant (powered by Bedrock): the IDE plugin does completions/generation/security scans/Java upgrades, and Q&A is grounded in your AWS resources and architecture — but AWS has published an EOL: IDE plugin support ends 2027-04-30 and the Q CLI has become the Kiro CLI; AWS is betting its agentic-coding future on Kiro.
