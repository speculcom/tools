Lovable 是瑞典 Lovable 的全栈 AI 建站平台：自然语言生成带前端/数据库/认证/托管的完整应用， 内置后端基于 Supabase 开源底座，Git 双向同步把代码放进你自己的仓库—— 官方口径「never locked in」，但构建模型不能指定、训练数据政策按计划分层。

Lovable is Sweden's full-stack AI app builder: natural language in, a working app out with frontend, database, auth and hosting — the built-in backend runs on the Supabase open-source foundation, Git two-way sync puts code in your own repo, and the official line is 'never locked in'. But you cannot pick the build model, and the training-data policy splits by plan.

适合与不适合When to use it, when not to

适合：想法到上线一条龙、Git 同步进自己仓库、企业治理（SSO/SCIM/审计/EU inference）。 不适合：要指定构建模型、要免费把代码下载回本地。

Fits: idea-to-launch in one place, Git sync into your own repo, enterprise governance (SSO/SCIM/audit/EU inference). Not a fit: wanting to pick the build model; wanting to download the codebase back for free (a paid-plan feature).

模型与开放条件Model & openness

官方 FAQ 明示：构建侧模型由 Lovable 选并自动更新，用户不能为 Build/Plan/Chat 模式指定具体模型； 你自己应用内的 AI 功能可从官方 AI features 页的支持清单选模型（聊天/图像/视频/语音等各有页）。 企业版有 EU inference（模型请求留在欧洲端点）。

运行位置Where it runs

网页端为主形态；官方另有桌面应用、iOS/Android 移动应用、Lovable API（发布项目/管理工作区）、 Lovable MCP server（把 Lovable 接进 IDE 与外部 agent）。项目在 workspace 内建， 一个项目对应一个可同步出代码库的应用（官方 welcome 页口径）。

本地文件Local files

项目代码存在 Lovable 平台内；Git sync 与 GitHub/GitLab/Bitbucket 仓库自动双向同步（官方页明示）， 也可 Download codebase（付费计划）。内置后端（Cloud）由 Lovable 托管，基于 Supabase 开源底座 （官方 cloud 页明示：数据库/认证/存储/edge functions，无需自建 Supabase）。 官方「部署托管与所有权」页口径「you are never locked in」：可导出代码、迁移数据、自托管部分或全部栈。

关机后的任务Tasks after shutdown

托管面是产品语义一部分：应用托管随流量自动扩、数据库实例可调（官方 cloud 页）； project monitoring 按计划检查应用抓 bug 与访客错误；Subagents 把复杂任务的调研/代码探索拆开并行。 关闭浏览器后构建任务是否续跑未核验到官方声明。

头号误解Top misconception

  • 构建侧模型不能指定（官方 FAQ：Lovable 为 Build/Plan/Chat 模式选模型并自动更新）—— 与 IDE 类工具的「模型选择器」体验完全不同；能选的是你应用内的 AI 功能模型You cannot pick the build-side model (official FAQ: Lovable chooses and auto-updates models for Build/Plan/Chat modes) — a completely different experience from IDE-style model pickers; what you can pick are the AI-feature models inside your own app
  • 训练政策按计划分层：官方 FAQ 明示 2026-09-09 起 Free/Pro 的客户数据默认可能用于训练（可在账户设置关闭）， Business/Enterprise 默认排除——数据边界别按「一个产品一个答案」推断Training policy splits by plan: the official FAQ states that from 2026-09-09 Free/Pro customer data may be used for training by default (switchable off in account settings), while Business/Enterprise is excluded by default — don't flatten the data boundary into one answer for the whole product
  • 「代码可导出」不等于「后端可白拿」：内置后端是 Lovable 托管的 Supabase 开源底座， 数据库迁移与外部托管要走官方迁移路径（deployment-hosting-ownership 页给路径与边界）'Code is exportable' does not mean 'the backend comes free': the built-in backend is Lovable-hosted on the Supabase open-source foundation; database migration and external hosting follow the official migration paths (the deployment-hosting-ownership page gives routes and boundaries)
