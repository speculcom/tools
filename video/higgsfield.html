A hybrid of in-house and partner models: in-house covers Soul 2.0 (photoreal images), Soul Cinema (cinematic images), Higgsfield DOP (cinematic video), Keyframes (storyboards) and Cinema Studio (a 1,296-lens and colour workspace), with an in-house reasoning engine orchestrating both lines. The API catalogue also lists Seedance, Kling, Wan, MiniMax, LTX, PixVerse, Grok, Recraft, Ideogram and Qwen (2026-11-21).

运行位置Where it runs

入口： 网页为 higgsfield.ai，异步 API（https://api.higgsfield.ai，有 Python/TypeScript SDK）。网页跑 Cinema Studio、Soul ID 等工作台。

API 按模型端点提交，额度用预付美元余额。单 key 解锁 20 并发（2026-11-21）。

Web at higgsfield.ai plus an asynchronous API (https://api.higgsfield.ai, Python/TypeScript SDKs). The web runs Cinema Studio/Soul ID workspaces, while the API submits to model endpoints, bills from a prepaid USD balance and unlocks 20 concurrent requests per key (2026-11-21).

本地文件Local files

不碰本机模型。输入图片或视频走 URL。提交后拿 request_id 与 status_url。轮询或 webhook 到 completed 再下载成片。作品在账户库，导出落本地由用户保存（2026-11-21）。

No local model: image/video inputs arrive as URLs, and a submission returns request_id and status_url; clients poll or receive a webhook until completed, then download the output. Works live in the account library, with exports saved locally by the user (2026-11-21).

关机后的任务Tasks after shutdown

异步请求有固定生命周期：submit、存 request_id、poll status_url 或 webhook、completed 后下载。模型各有超时上限；超时标记失败且不扣费，可重提。

Cinema Studio 单条最长 30 秒，最多 50 张参考图（2026-11-21）。

An asynchronous lifecycle: submit, store request_id, poll status_url or wait for a webhook, then download on completion. Each model has its own timeout, timed-out requests fail without charge and can be resubmitted; Cinema Studio supports up to 30 seconds and 50 reference images per generation (2026-11-21).
