跨会话不继承对话上下文，复用靠显式参考素材（2026-11-21）。

Work is organised by generation tasks and output history; one generation puts text, images, video and audio into a single multimodal context, and Omni Reference keeps character, motion, camera and voice consistent through reference files. Chat context is not carried across sessions, so reuse relies on explicit reference assets (2026-11-21).
