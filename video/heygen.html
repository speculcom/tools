HeyGen 是数字人视频台：Avatar+Voice+Translation 三线，主打企业视频本地化（翻译+对口型） 与授权克隆口播；「人说话」的生成，不是「造世界」的生成。

HeyGen is the digital-human video console: Avatar + Voice + Translation, leading with enterprise video localization (translation + lip-sync) and consented cloned presenters; it generates 'people talking', not 'worlds'.

适合与不适合When to use it, when not to

Fits: enterprise training/marketing localization, consented cloned presenters, batch talking-head video. Not a fit: creative narrative, entertainment AI-look, cloning others without consent (terms red line).

模型与开放条件Model & openness

Digital-human video lines: Avatar, Voice (dubbing/cloning) and Translation (video translation and lip-sync). Official pages do not disclose model-by-model versions; check the product capability table and API docs (2026-11-21).

运行位置Where it runs

网页（heygen.com）+ API（developers.heygen.com）；生成在厂商云端，API 以异步任务返回 video_id，客户端轮询状态或接 webhook。本机不跑模型（2026-11-21）。

Web (heygen.com) plus API (developers.heygen.com); generation runs in the vendor cloud, and the API returns a video_id for an asynchronous job that the client polls or receives via webhook. No model runs locally (2026-11-21).

本地文件Local files

作品存账户侧云端，生成历史在网页作品页可见；API 返回的下载 URL 有效期 7 天，需在有效期内取回，下载后归本地。官方 FAQ 说明 100% 用户数据不用于模型训练（2026-11-21）。

Works live in the account cloud, with generation history visible on the web works page. Download URLs from the API expire after seven days and must be retrieved within that window; downloads then belong to the local machine. The official FAQ says 100% of user data is not used for model training (2026-11-21).

关机后的任务Tasks after shutdown

生成在云端异步排队：API 提交后返回 video_id，客户端轮询状态或接收 webhook，任务不依赖本机在线；官方未给用户可暂停/续跑的队列面板，批量生产按 API 状态机编排（2026-11-21）。

Generation queues asynchronously in the cloud: the API returns a video_id, and the client polls status or receives webhooks, so jobs do not depend on the local machine being online. Official pages offer no pause/resume queue panel; batch production is orchestrated through the API state machine (2026-11-21).

权限与限制Permissions & limits

Accounts, subscriptions and enterprise tiers. The official product page says every custom avatar must pass an on-camera identity verification by the person, without which no avatar can be created, and HeyGen honours removal requests. The FAQ says consent, avatar-usage and content guidelines are strictly enforced, and 100% of user data is not used for training (2026-11-21).
