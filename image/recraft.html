Recraft 是设计向图像台里罕见的「矢量原生」：真 SVG 输出、brand kit 品牌一致性、图内文字精确定位； 免费档作品公开且不可商用是它最关键的档位硬线。

Recraft is the rare vector-native design console: true SVG output, brand-kit consistency, precise in-image text placement; free-plan works are public and not licensed for commercial use — the plan-level hard line.

适合什么任务Best for

适合：设计向产出（logo/图标/插画要可编辑 SVG）、品牌一致性（brand kit）、图内文字精确排版。 不适合：免费商用（免费档不可商用是硬线）、要照片级写实主打（它偏设计）。

头号误解Top misconception

  • 免费档作品默认公开且不可商用——这是官方文档明示的档位差异，别按「免费=可商用」的惯性理解Free-plan works are public and not licensed for commercial use — an official-docs hard line; don't apply the 'free = commercial' habit
  • ComfyUI 官方节点≠离线权重——它调的是 Recraft API（需 key），「本地跑 Recraft」不成立ComfyUI official nodes ≠ offline weights — they call the Recraft API (key required); 'running Recraft locally' is not viable
  • 「矢量输出」是 V3 Vector 线专属（recraftv3_vector）——不是所有模型值都出 SVG'Vector output' is the V3 Vector line only (recraftv3_vector) — not every model value emits SVG
