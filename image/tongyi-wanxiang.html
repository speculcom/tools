通义万相是「云端产品 + Apache-2.0 开源权重」双轨的国产图视频创作台（Wan 系列）： 合规敏感场景可本地跑，备案号经阿里云官方公示核验；产品端与开源线数据边界完全不同。

Tongyi Wanxiang is Alibaba's image/video creation console with an open-weights twin: the Wan weight family is Apache-2.0 (verified via GitHub API), runnable locally; the cloud console carries filing number Shanghai-TongYiWanXiang-202410090024.

适合与不适合When to use it, when not to

适合：双轨可选（云端/本地）、图视频同族、中文语义。 不适合：要完全托管长任务、要产品端脱离账号。

Fits: image+video creation with an open-weights twin (Wan Apache-2.0 runnable locally), Alibaba Cloud ecosystem. Not a fit: account-free use, treating the console and the weights as one product.

模型与开放条件Model & openness

万相（Wan）系列模型双轨：产品端（tongyi.aliyun.com/wanxiang）+ 开源权重（Wan-Video 组织 GitHub、 Wan-AI 组织 HF——两组织直抓 200 核验）。产品端模型档位以站内展示为准； 开源权重可经 runner/ComfyUI 生态本地跑（Apache-2.0 代码核验）。

运行位置Where it runs

网页产品 + App；生成在阿里云端处理。开源线是它的独特面：同一模型族可在云端产品与本地部署间选。

本地文件Local files

产品端作品与素材存云端账户；开源线权重与生成物全在你侧——两条线数据边界完全不同。

产品端生成任务云端排队；开源线本地跑则完全由你的进程决定。无「关机续跑」的托管任务面（未核验到声明）。
