Clipdrop 是「单图原子操作」的图像编辑工具集：抠图/去物/重打光（招牌 Relight）/放大/扩图各成一工具； 归属三跳（InitML→Stability→Jasper），API 现在走 Jasper 口径。

Clipdrop is the single-image atomic-operation toolkit: cutout/cleanup/relight (its signature)/upscale/uncrop each as a standalone tool; ownership moved three times (InitML→Stability→Jasper, Feb 2024) — API terms now run on Jasper's side.

适合与不适合When to use it, when not to

适合：电商产品图批量处理、抠图/重打光等原子操作、API 集成。 不适合：创作向生成、风格一致性、项目管理流。

Fits: e-commerce product-image batches, atomic operations (cutout/relight/upscale), API integration into own products. Not a fit: creation-oriented generation, style consistency, project management flows.
