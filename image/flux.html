图像模型家族的双路线供应商：官方 API/playground 托管生成，部分权重开源可自托管甚至进端侧； 「不主张所有权、但禁训练其他模型」是条款里最锋利的一刀。

The dual-route supplier of the FLUX model family: hosted generation via the official API/playground, some weights open for self-hosting and even on-device; “claims no ownership, but bans training other models” is the sharpest cut in the terms.

适合与不适合When to use it, when not to

适合要接 FLUX API 做集成、或要自托管开源权重的团队。做模型训练的人先读 1.3(n)—— 用 FLUX 输出训练其他模型被条款禁止。要开箱即用的创作社区形态，对照 Midjourney 再选。

Teams integrating the FLUX API or self-hosting open weights. Anyone doing model training reads 1.3(n) first — training other models on FLUX outputs is prohibited by the terms.

Not a fit for out-of-the-box creative-community workflows — compare Midjourney before choosing.

API/playground can upload images as input; on the self-hosted line, when the model runs locally the data never leaves your machine.

关机后的任务Tasks after shutdown

API 为请求-产出制：任务在云端跑，客户端可断开后轮询取回； 没有「关机续跑」形态的官方声明——模型接口本身不承载跨会话任务。

The API is request-output based: tasks run in the cloud, clients can disconnect and poll to retrieve results; no official statement of a "keep-running-after-shutdown" form — the model interface itself carries no cross-session tasks.

Official ToS: inputs and outputs may by default be used to improve the model, opting out requires an email request to legal@blackforestlabs.ai; the terms explicitly restrict "training other models on Outputs" (1.3(n)).
