Ideogram 是「图内排版文字」最强的图像模型族：4.0 开放量化权重（非商用免费/商用自托管需许可）， 4.5 闭源托管主打 precise edit；官方 MCP server 可直接接进 agent 工作流。

Ideogram is the typography-first image generator (text rendering inside images is its signature): 4.0 released open quantized weights (free but non-commercial), 4.5 is closed; direct access from the mainland measures 000.

适合与不适合When to use it, when not to

适合：海报/品牌物料的图内文字、开放权重研究+商业自托管路径、MCP 接入。 不适合：要免费商用自托管、要 4.5 权重（闭源）。

Fits: posters/packaging with in-image text, typography-heavy output, trying 4.0 quantized weights. Not a fit: commercial use of the open weights (non-commercial line), mainland direct access.
