本站是「核验快照」，不是实测榜单This site is a verification snapshot, not a benchmark chart

每份档案的每个字段都能回到官方一手源核对，附来源类型与核验日期。但我们还没有在同一批任务上实测过这些工具——所以本站给的是能力边界与证据，不给总分排名。Every field of every entry traces back to an official first-hand source, with source kind and checked date. But we have not yet run these tools on the same batch of tasks — so this site gives capability boundaries and evidence, not an overall ranking.

「未知」是合法答案——查不到就写未知并说明原因，不用推测填充。"Unknown" is a legitimate answer — if it cannot be found, we say so and explain why, instead of filling the gap with guesses.

八个维度，每格都能回溯Eight dimensions, every cell traceable

档案都在同一坐标系下被描述（MCP 大类另有 3 个特有维度）。点开任一对象，每一格下面都有官方源链接与核验日期——不认同可以自己回去查。Entries are described on one coordinate system (MCP servers carry 3 additional dimensions). Open any object and every cell carries an official source link and a checked date — disagree and verify it yourself.
