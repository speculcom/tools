逐个适用条件When each fits

Perplexity：适合带来源的事实问答与快速研究入口，英文检索较强；Comet 浏览器把检索延伸成 agent 浏览。什么情况下选另一个：要自己控制索引与隐私，选 Kagi；要读自己上传的一批 PDF，选 NotebookLM。

Kagi：适合要无广告、无追踪与自建索引的人；付费换隐私是主轴，AI 答案层是附加。什么情况下选另一个：要免费、要社交化答案页，选 Perplexity。

NotebookLM：适合把一组文档、网页或笔记变成可问答资料集，并生成音频概览与学习指南。什么情况下选另一个：要从零找资料，选 Perplexity 或 Kagi。

Elicit：适合系统性文献综述：研究问题 → 论文筛选 → 抽取表 → 带引用综述。什么情况下选另一个：只是日常事实问答，NotebookLM 或 Perplexity 更轻。

核验事实Dated facts

1. Perplexity 的答案带来源角标，并有多模型路由与 Comet 浏览器线（官方站，2026-10 档案核验）。 2. Kagi 使用自建索引，付费、无广告、无追踪；AI 答案层为 FastGPT / Teclis（官方站，2026-10 档案核验）。 3. NotebookLM 只在用户给定的源内回答，并可生成音频概览与学习指南（官方站，2026-10 档案核验）。 4. Elicit 输出结构化抽取表与带引用综述，每个单元格仍需回原文核对（官方站，2026-10 档案核验）。

以上日期为本站档案核验快照日；具体额度与档位以官方页面当日为准。

组合用法A workable combination

1. 从零找：Perplexity 做第一轮，Kagi 做补充检索。 2. 建资料集：把关键原文丢进 NotebookLM，问题只在源内问。 3. 做综述：Elicit 建抽取表，再回原文逐格核对。 4. 留痕：保存检索日期、查询词、来源 URL 与版本。

常见误判Common misreads

  • 把「有角标」当成「已核实」：角标只证明它引了，没证明引对。
  • 把「源内回答」当成「不会编」：源本身错，回答照样错。
  • 把「抽取表」当成「结论」：表格是中间产物，判断仍要人做。
  • 把「付费搜索」当成「更准」：付费买的是隐私与索引控制，不是事实正确。
