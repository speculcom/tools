浏览器 Agent 三选一：Playwright MCP / Browserbase MCP / Chrome DevTools MCPBrowser agents: Playwright, Browserbase, DevTools

规划Planning

三个浏览器 MCP 的适用条件、能力边界与价格档位；按「本地还是云端、要不要模型、要不要性能分析」给出一句选择，并写明什么情况下换另一个。

Applicability, capability limits and plan tiers for three browser MCP servers; a one-line choice based on local vs cloud, whether a model is needed and whether performance analysis is required, plus when to switch.

一句话选择One-line choice

  • 本机浏览器 + 结构化页面快照 + 不需视觉模型：选 Playwright MCP。
  • 不想在本机起浏览器 + 要自然语言驱动网页：选 Browserbase MCP。
  • 给编码 Agent 看页面、抓性能与 console：选 Chrome DevTools MCP。
  • Local browser, structured page snapshots, no vision-model requirement: examine Playwright MCP.
  • Cloud browser with natural-language interaction: examine Browserbase MCP.
  • Page inspection, performance and console evidence for a coding agent: examine Chrome DevTools MCP.

能力边界Capability limits

Playwright MCP

  • 默认有头模式，--headless 可切；headless 默认空闲 1 小时关闭，headed 默认不自动关闭。
  • 用户 profile 默认落盘在 Playwright 缓存目录（按 workspace hash 隔离），--isolated 可改为仅存内存。
  • 官方工具包括文件上传；可访问路径与客户端授权、工作区配置有关。不要据“核心是浏览器控制”推断不能读取或上传本地文件。
  • 版本仍是 0.0.x（v0.0.83 于 2026-09-28），工具名可能继续变。

Browserbase MCP

  • 托管线由 Browserbase 提供 Gemini 的 LLM 成本；自托管线要自备 GEMINI_API_KEY（可换模型并配对应 key）。
  • 自托管只是 server 在你机器上，浏览器会话仍在 Browserbase 云端，BROWSERBASE_API_KEY 与 project id 照要。
  • GitHub 仓 browserbase/mcp-server-browserbase 已归档（归档状态与 2026-07-20 停推已核验）；现役实现是托管线。
  • act 能在真实网页点击填表，授权边界按目标站点把关。

Chrome DevTools MCP

  • 驱动真实浏览器：客户端让它访问什么就访问什么，server 本身没有 URL 白名单的官方说明。
  • 能力集中在运行时：页面、网络、console、performance trace、CPU/网络节流。
  • 不读写项目源码；那是 filesystem server 的职责。
  • 随客户端生死（stdio 子进程），无后台任务语义。

Playwright MCP

  • The recorded defaults use headed mode, with --headless available. The snapshot records a one-hour idle shutdown in headless mode and no automatic shutdown in headed mode.
  • Profiles are stored in the Playwright cache, isolated by workspace hash; --isolated keeps them in memory.
  • Official tools include file upload. Accessible paths depend on client authorisation and workspace configuration. Browser control does not imply that local files cannot be read or uploaded.
  • The recorded version is in the 0.0.x line (v0.0.83, 2026-09-28); tool names may change.

Browserbase MCP

  • The hosted offering covers its Gemini model cost; self-hosting the server requires your own GEMINI_API_KEY, or the key for another configured model.
  • Self-hosting the server does not move browser sessions off Browserbase's cloud. A BROWSERBASE_API_KEY and project ID are still required.
  • The browserbase/mcp-server-browserbase repository is archived in the recorded snapshot, with its last push on 2026-07-20; the hosted offering is the active implementation described here.
  • act can click and fill real web forms; authorisation must cover actions on the destination site.

Chrome DevTools MCP

  • It controls a real browser at the client's direction. This snapshot found no official server-side URL-allowlist statement.
  • It focuses on runtime inspection: pages, network, console, performance traces, and CPU/network throttling.
  • Editing project source is a separate filesystem-tool responsibility.
  • As a stdio child process it follows the client lifecycle; that does not establish background-task continuation.

什么情况选另一个When to switch

  • 选 Playwright 后，如果不想在本机维护浏览器与依赖：换 Browserbase。
  • 选 Browserbase 后，如果要开源可审计的完整实现：换 Playwright 或 Chrome DevTools（Browserbase 现役实现闭源在托管侧）。
  • 选 Chrome DevTools 后，如果要脱离本机、批量跑多会话：换 Browserbase。
  • 选 Chrome DevTools 后，如果只要稳定的固定流程、不要调试面：换 Playwright。
  • 选 Playwright 后，如果目标是性能 trace 与 console 取证：换 Chrome DevTools。
  • From Playwright, examine Browserbase if you do not want to maintain local browsers and dependencies.
  • From Browserbase, examine Playwright or Chrome DevTools if you need an open-source implementation to inspect; the active Browserbase hosted implementation is closed-source in this snapshot.
  • From Chrome DevTools, examine Browserbase for browser sessions running off your local machine at scale.
  • From Chrome DevTools, examine Playwright when repeatable interaction matters more than debugging tools.
  • From Playwright, examine Chrome DevTools for performance traces and console investigation.
