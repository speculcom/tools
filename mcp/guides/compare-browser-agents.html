浏览器 Agent 三选一：Playwright MCP / Browserbase MCP / Chrome DevTools MCPBrowser agents: Playwright, Browserbase, DevTools

规划Planning

三个浏览器 MCP 的适用条件、能力边界与价格档位；按「本地还是云端、要不要模型、要不要性能分析」给出一句选择，并写明什么情况下换另一个。

Applicability, capability limits and plan tiers for three browser MCP servers; a one-line choice based on local vs cloud, whether a model is needed and whether performance analysis is required, plus when to switch.

English summaries and interface labels are available. The guide body below is currently in Chinese.

一句话选择One-line choice

  • 本机浏览器 + 稳定 selector + 不要模型：选 Playwright MCP。
  • 不想在本机起浏览器 + 要自然语言驱动网页：选 Browserbase MCP。
  • 给编码 Agent 看页面、抓性能与 console：选 Chrome DevTools MCP。

能力边界Capability limits

Playwright MCP

  • 默认有头模式，--headless 可切；headless 默认空闲 1 小时关闭，headed 默认不自动关闭。
  • 用户 profile 默认落盘在 Playwright 缓存目录（按 workspace hash 隔离），--isolated 可改为仅存内存。
  • 没有本地文件访问能力；核心是浏览器控制。
  • 版本仍是 0.0.x（v0.0.83 于 2026-09-28），工具名可能继续变。

Browserbase MCP

  • 托管线由 Browserbase 提供 Gemini 的 LLM 成本；自托管线要自备 GEMINI_API_KEY（可换模型并配对应 key）。
  • 自托管只是 server 在你机器上，浏览器会话仍在 Browserbase 云端，BROWSERBASE_API_KEY 与 project id 照要。
  • GitHub 仓 browserbase/mcp-server-browserbase 已归档（归档状态与 2026-07-20 停推已核验）；现役实现是托管线。
  • act 能在真实网页点击填表，授权边界按目标站点把关。

Chrome DevTools MCP

  • 驱动真实浏览器：客户端让它访问什么就访问什么，server 本身没有 URL 白名单的官方说明。
  • 能力集中在运行时：页面、网络、console、performance trace、CPU/网络节流。
  • 不读写项目源码；那是 filesystem server 的职责。
  • 随客户端生死（stdio 子进程），无后台任务语义。

价格档位Plan tiers

只列档位名，不写价格数字（单价与额度查官方定价页当日值）：

产品档位
Playwright MCP开源仓库，无付费档位
Browserbase MCPFree / Developer / Startup / Scale（Scale 为定制）
Chrome DevTools MCP开源仓库（Apache-2.0），无付费档位

Browserbase 的免费档有并发浏览器的上限，付费档按并发与浏览器小时递增；具体数字以定价页为准。

什么情况选另一个When to switch

  • 选 Playwright 后，如果不想在本机维护浏览器与依赖：换 Browserbase。
  • 选 Browserbase 后，如果要开源可审计的完整实现：换 Playwright 或 Chrome DevTools（Browserbase 现役实现闭源在托管侧）。
  • 选 Chrome DevTools 后，如果要脱离本机、批量跑多会话：换 Browserbase。
  • 选 Chrome DevTools 后，如果只要稳定的固定流程、不要调试面：换 Playwright。
  • 选 Playwright 后，如果目标是性能 trace 与 console 取证：换 Chrome DevTools。

核验事实Dated facts

1. Playwright MCP 由 Microsoft 维护，本地 Node.js 18+、stdio 通信，工具数 72（2026-10-08 核对），最新记录版本 v0.0.83（2026-09-28）。 2. Browserbase MCP 托管端点为 https://mcp.browserbase.com/mcp（streamable-http），工具 6 个；GitHub 仓 archived（2026-07-20 停推）。 3. Browserbase 定价页档位为 Free / Developer / Startup / Scale（2026-11-03 直抓）；D9 口径不采价格数字。 4. Chrome DevTools MCP 为 Apache-2.0，v1.12.0 于 2026-10-22 发布；仓库 54,460★、最近推送 2026-10-29（GitHub API 核验）。
