练习包 · Manager：写一页供应商决策备忘录Exercise: a one-page vendor decision memo

规划Planning

用三个成本维度对比「调 API」与「自己部署」，交一页决策备忘录、评分表、5 个尽职调查问题与退出计划；评分标准看口径、可复核与退出路径。

Compare API usage with self-hosting on three cost dimensions and deliver a one-page decision memo, a score sheet, five due-diligence questions and an exit plan; the rubric checks conventions, reproducibility and exit paths.

任务The task

为一个真实业务流写一页决策备忘录：继续调 API，还是把模型放到自有基础设施。不做技术教程，只做决策。评分与篇幅仅用于练习，不形成本站产品排名；下方数字示例是假设，不能代替实际迁移估算。

必须包含：

  1. 三个成本维度：调用量、固定成本、返工与人工。
  2. 一张 5 行评分表：成本、锁定、合规、运维、扩展，各 1–5 分。
  3. 5 个尽职调查问题，问厂商或内部安全团队。
  4. 退出计划：换供应商要导出什么、多久、谁负责。
  5. 明确结论：选哪个，以及什么条件下推翻。

Write a one-page decision memo for a real business workflow: continue using an API or run a model on your own infrastructure. This is a decision exercise rather than a technical tutorial. Scores and length limits are teaching conventions, not this site's product rankings. Numerical examples below are assumptions, not actual migration estimates.

Include:

  1. Three cost dimensions: usage, fixed costs, and rework plus labour.
  2. A five-row score sheet covering cost, lock-in, compliance, operations and scaling, each scored 1–5.
  3. Five due-diligence questions for the vendor or internal security team.
  4. An exit plan: what must be exported to switch vendors, how long it takes and who owns the work.
  5. A clear choice and the conditions that would overturn it.

评分标准Rubric

每项 0–2 分，共 12 分：

维度0 分1 分2 分
成本口径只算单价算了调用量但漏固定成本调用量、固定成本、返工与人工三线齐
结论没有结论有结论但无条件结论 + 推翻条件
可复核数字来路不明部分有来源每个数字有假设或来源
尽职调查泛泛而谈有 5 问但不可答每问对应官方文档可查项
退出没写只写「可导出」格式、耗时、负责人齐
锁定评估只看价格提到迁移成本写清迁移成本与备选

参考答案结构Model answer outline

备忘录的合格开头：

结论：本季度继续调 API；当月的调用量超过 X 或数据分类升到「不可出网」时，转自托管。

评分表的合格行：

维度：合规
分数：3/5
理由：当前区域可用，但数据驻留条款只在企业档提供；升档前不能算满分。

退出计划的合格写法：

导出：对话与文件用官方导出接口，格式 JSON/CSV；
耗时：按 10 万条估算，预留 2 个工作日；
负责人：IT 安全负责人；验证：抽样 20 条比对。

An acceptable opening:

Decision: continue with the API this quarter. Move to self-hosting if monthly usage
exceeds X or the data classification changes to “must not leave the network”.

An acceptable score-sheet row:

Dimension: compliance
Score: 3/5
Reason: the required region is currently available, but data residency terms require
the enterprise tier; do not treat the requirement as fully satisfied before upgrading.

An illustrative exit plan:

Export: conversations and files through the official export interface, in JSON/CSV.
Duration: assume 100,000 records and budget two working days.
Owner: IT security lead.
Validation: sample 20 records and compare.

These quantities are hypothetical. Replace them with the actual export interfaces, volume, timing and validation requirements.

常见失分Common misses

  • 只比 token 单价：漏掉席位、运维与返工。
  • 结论写成「看情况」：决策者要的是一句可执行的话。
  • 尽职调查问题问不出答案：如「你们安全吗」，应问「审计日志覆盖哪些事件、保留多久」。
  • 退出计划没有验证步骤：导出不等于可用。
  • Comparing token prices alone omits seats, operations and rework.
  • “It depends” is not an actionable decision; state a choice and its conditions.
  • Replace “Are you secure?” with an answerable question such as “Which events do audit logs cover, and how long are they retained?”
  • An exit plan needs validation; an exported file is not necessarily usable.
