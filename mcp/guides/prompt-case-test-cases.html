检查点Checkpoints

  • 三类 type 都有或说明缺因。
  • expected 可回连需求。
  • 未定义行为不填猜测。
  • All three types exist or gaps are explained.
  • Expected results link to requirements.
  • Undefined behaviour is not guessed.

失败分支Failure branches

  • 用例重复：按输入域合并。
  • 需求模糊：标 undefined_behavior。
  • Duplicate cases: merge by input domain.
  • Vague requirement: mark undefined_behavior.
