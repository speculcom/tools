规划Planning

四个可直接复制的文本块：评估 rubric、四层护栏清单、客服验收单、故障复盘清单。

Four copyable text blocks: an evaluation rubric, a four-layer guardrail checklist, a service acceptance sheet and an incident review checklist.

English summaries and interface labels are available. The guide body below is currently in Chinese.

怎么用这页How to use

四个块用于上线前评审与事故复盘；括号里替换成你的项目值。

5. Agent 评估 rubric

| 维度         | 权重 | 通过线 | 证据来源       |
|--------------|------|--------|----------------|
| 任务完成率   | 30%  | ≥【X】% | 100 条离线集   |
| 引用准确率   | 20%  | ≥【X】% | 抽 20 条回原文 |
| 该拒答时拒答 | 20%  | ≥【X】% | 禁区问题集     |
| 工具调用正确 | 15%  | ≥【X】% | 调用日志       |
| 平均轮次     | 10%  | ≤【N】轮 | 会话日志       |
| 延迟         | 5%   | ≤【N】秒 | 监控           |

评分：每维 1–5 分；任一维低于 3 分不得上线。

6. 四层护栏清单

输入层
- [ ] PII 识别与脱敏
- [ ] 提示注入检测
- [ ] 超长输入截断
- [ ] 文件类型白名单

知识层
- [ ] 只答库内内容
- [ ] 每条回答引用原文句
- [ ] 过期条目标记并下线
- [ ] 冲突来源同时保留

工具层
- [ ] 工具白名单
- [ ] 参数 schema 校验
- [ ] 写操作人工确认
- [ ] 调用频率限制

输出层
- [ ] 敏感承诺过滤
- [ ] 转人工触发条件
- [ ] 全链路日志留痕
- [ ] 一键回滚开关

7. 客服 Agent 验收单

- [ ] 意图清单与禁区清单已评审
- [ ] 知识库只含已发布内容，带生效日期
- [ ] 写操作全部人工确认
- [ ] 离线集 100 条，覆盖高频与禁区
- [ ] 错误承诺率 0（灰度期）
- [ ] 转人工条件与责任人写清
- [ ] 日志保留周期符合合规
- [ ] 回滚开关演练过一次

8. 故障复盘清单

| 问题 | 记录 |
|------|------|
| 发生时间 / 发现时间 | |
| 影响范围（用户/订单/数据） | |
| 触发路径（输入/知识/工具/输出） | |
| 当时模型与版本 | |
| 是否有护栏拦截 | |
| 回滚时间与方式 | |
| 根因（可复现证据） | |
| 修复与回归测试 | |
| 同类风险排查结果 | |

纪律：先写证据，再写判断；不要写「疑似」「可能」当根因。

常见误用Common misuses

  • 评估只测「能答」：不测拒答，上线后错误承诺最多。
  • 护栏只写在文档：没有指标与日志，出事无法定位。
  • 验收单不复核：一次通过就永久通过，知识库更新后失效。
  • 复盘写情绪：没有可复现证据，修复只能靠猜。
