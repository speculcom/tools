9. Agent 权限矩阵

| 操作             | 读 | 写 | 删除 | 需要确认 | 审计 |
|------------------|----|----|------|----------|------|
| 读仓库文件       | ✓  |    |      | 否       | 否   |
| 改代码           |    | ✓  |      | 是       | 是   |
| 跑测试           | ✓  |    |      | 否       | 是   |
| 装依赖           |    | ✓  |      | 是       | 是   |
| 推远端           |    | ✓  |      | 是       | 是   |
| 删文件           |    |    | ✓    | 是       | 是   |
| 读生产数据库     | ✓  |    |      | 是       | 是   |
| 改生产数据库     |    | ✓  |      | 双人复核 | 是   |

原则：默认只读；写操作逐条确认；删除与生产写操作双人复核。

10. 模型许可检查表

- [ ] 权重许可证（MIT / Apache-2.0 / CC-BY / 自定义）
- [ ] 是否允许商用
- [ ] 是否允许自托管
- [ ] 是否要求署名或继承许可
- [ ] 是否禁止用输出训练其他模型
- [ ] 是否有用户数/营收门槛
- [ ] 量化版是否沿用原模型许可
- [ ] 工具许可证与权重许可证分开核对
- [ ] 许可页 URL 与核验日期已存档

| 生成片段 | 模型名+版本 | 平台条款 | | 条款截图 |
| 音乐 | 曲库 | 曲库许可 | | 订单号 |
| 音效 | 曲库/自制 | | | |

常见误用Common misuses

  • 权限矩阵只写「允许」：没有确认与审计列，等于没控制。
  • 许可只看工具：权重许可才是商用与否的关键。
  • 权利表事后补：素材来源记不清，只能重做。
  • 成本只算 token：检索、人工与维护通常占大头。
