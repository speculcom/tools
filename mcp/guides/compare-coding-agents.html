先定执行面，再挑产品Pick the surface first

写代码的 Agent 先分三类执行面，价格和模型都不是第一决策点：

执行面代表运行位置适合的活
终端Claude Code CLI、Codex CLI、Gemini CLI你的 shell 与仓库已有仓库、要脚本化、要看清每条命令
IDECursor、GitHub Copilot、Antigravity编辑器进程或厂商云边写边看、要补全与内联 diff
云端Devin、Cursor 云端 Agent厂商工作区工单批量委派、合上笔记本还要继续跑

先问一句：改动是在你机器上跑，还是交给厂商云跑？ 这一步会直接排除一半候选。

First distinguish three execution surfaces for a coding agent. Price and model choice come after deciding where work runs:

CloudDevin, Cursor Cloud AgentsVendor workspaceDelegated issues and work continuing after the laptop closes

Ask whether changes run on your machine or in a vendor cloud. This can eliminate unsuitable candidates before other comparisons.

每个候选的适用条件When each fits

Claude Code CLI：适合已有仓库、想把每一步命令摊在终端里看的人；使用前需核对命令、文件与工具的授权范围。能力边界是模型线固定在 Anthropic，要多模型得另配。什么情况下选另一个：要 IDE 内联补全就选 Cursor 或 Copilot；要完全开源可改的 CLI 就选 Gemini CLI。

Codex CLI：适合 OpenAI 生态、要线程续接与脚本化的人；Rust 实现、app server 是它的架构特征。什么情况下选另一个：团队已经押注 Anthropic，就选 Claude Code CLI。

Gemini CLI：Apache-2.0、npx 免安装、支持 MCP 与非交互脚本，适合 CI 与教学。什么情况下选另一个：需要按权限控制与变更记录对照时，再查 Claude Code CLI 的具体配置。

Cursor：适合要 IDE 体验、又要云端 Agent 续跑的人；官方区分云端 VM 与自托管机器的工具执行；自托管执行不等于模型请求、日志与全部数据都不出网，仍需核对网络设置与条款。什么情况下选另一个：只要终端、不想装编辑器，就选三家 CLI 之一。

Devin：适合把工单批量丢给云端、拿草稿 PR 再接管的人；Slack / Linear / Jira 可直接派单。什么情况下选另一个：改动必须在你本机、不能出网，就选终端或 IDE。

Antigravity：适合要在桌面指挥中心、CLI、IDE 扩展与 Python SDK 之间共用一套 harness 的团队；官方给了三档命令执行策略。什么情况下选另一个：只需要编辑器内工作流，可对照 Cursor 的 IDE 形态。

Claude Code CLI: a candidate for working in an existing repository with commands visible in a terminal. Check authorisation for commands, files and tools. Its default model line in this snapshot is Anthropic; other model requirements need separate configuration checks. Consider Cursor or Copilot for IDE completion, or Gemini CLI for an Apache-2.0 CLI you can modify.

Codex CLI: a candidate for the OpenAI ecosystem, thread continuation and scripting. Rust implementation and the app server are recorded architectural features. Consider Claude Code CLI when the team's requirements are tied to Anthropic.

Gemini CLI: Apache-2.0, launchable through npx, with MCP and non-interactive scripting for CI and teaching. For a permission-control comparison, examine Claude Code CLI's specific settings and change records.

Cursor: a candidate for an IDE workflow alongside cloud continuation. Official documentation distinguishes cloud VMs from tool execution on self-hosted machines. Self-hosted execution does not establish that model requests, logs and all other data stay offline; inspect network settings and terms separately. Consider a CLI when you only need a terminal.

Devin: a candidate for delegating issues to a cloud workspace and reviewing draft PRs afterwards, with Slack / Linear / Jira integrations. If work must run locally without outbound data, investigate the actual local execution and data path of terminal or IDE options.

Antigravity: a candidate for sharing a harness across desktop, CLI, IDE extension and Python SDK, with three documented command policies in this snapshot. If you only need an editor workflow, compare Cursor's IDE form.

核验事实Dated facts

  1. Gemini CLI 采用 Apache-2.0，支持 npx 启动与 MCP（仓库 README，2026-10 快照）。
  2. Cursor 云端 Agent 在独立云端 VM 中运行，不依赖本机持续联网；官方另提供自托管机器执行路线。执行位置不能单独证明全链路不出网（官方 Cloud Agents 文档，2026-11-04 局部复核）。
  3. Antigravity 的命令执行策略为官方显式三档（2026-10-13 release notes 核验）。
  4. Claude Code CLI 有独立 CHANGELOG 与 Atom feed；源码可见但许可证为 All rights reserved（仓库页）。
  5. Codex CLI 为 Rust 实现，架构以 app server 与线程续接为核心（仓库与 releases）。

上表区分原有核验快照与第 2 项的局部复核日；版本发布日以官方 releases 为准，局部复核不代表全文重新核验。

  1. Gemini CLI is Apache-2.0-licensed and supports npx startup and MCP (repository README; October 2026 snapshot).
  2. Cursor Cloud Agents run in isolated cloud VMs without requiring the local machine to stay online; a separate self-hosted machine execution path is documented. Execution location alone does not prove end-to-end offline processing (official Cloud Agents documentation; this item rechecked 2026-11-04).
  3. Antigravity explicitly documents three command-execution policies (release notes checked 2026-10-13).
  4. Claude Code CLI has a separate CHANGELOG and Atom feed; source is visible but the licence is All rights reserved (repository snapshot).
  5. Codex CLI is implemented in Rust, with app-server architecture and thread continuation recorded in its repository and releases.

These entries distinguish earlier verification snapshots from the scoped recheck of item 2. Use official releases for publication dates; a scoped recheck is not a new full-guide verification.

常见误判Common misreads

  • 把「能跑终端」当成「能安全跑终端」：权限模型不同，默认确认与白名单是两回事。
  • 把「云端续跑」当成「不用看」：草稿 PR 仍要人审，云端只省等待时间。
  • 把「开源 CLI」当成「模型也开源」：CLI 的许可证与模型权重许可是两份文件。
  • 把「支持 MCP」当成「工具即插即用」：server 的权限与数据范围仍要逐条看。
  • Terminal execution does not establish safe execution. Default confirmations and allowlists are different permission designs.
  • Cloud continuation does not remove review; a draft PR still needs inspection.
  • An open-source CLI does not establish model-weight rights; their licences are separate.
  • MCP support does not make tools ready for unrestricted use. Inspect each server's permissions and data scope.
