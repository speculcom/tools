工具箱：提示词、上下文预算、RAG 清单、选型表Toolkit: prompt and context

规划Planning

四个可直接复制的文本块：提示词结构、上下文预算表、RAG 分块与重排清单、模型选型工作表。

Four copyable text blocks: a prompt structure, a context budget table, a RAG chunking/reranking checklist and a model selection worksheet.

English summaries and interface labels are available. The guide body below is currently in Chinese.

怎么用这页How to use

四个块都是纯文本，复制到你的文档或仓库里改。括号里是占位，不是可直接运行的代码。

1. 提示词结构模板

角色：你是【角色】，只负责【任务范围】。
输入：用户给出【输入类型】；缺失信息请先问，不要猜。
约束：
- 必须引用【允许的知识源】，找不到就写「未找到」。
- 不得编造数字、日期、许可、作者。
- 输出格式：先结论，再依据，最后未确认项。
输出：
1) 结论（不超过 3 句）
2) 依据（每条带来源与日期）
3) 未确认项（没有就写「无」）
拒答条件：【列出不该回答的问题】

2. 上下文预算表

| 槽位            | 预算占比 | 内容                         |
|-----------------|----------|------------------------------|
| 系统指令        | 10%      | 角色、约束、输出格式         |
| 任务与示例      | 30%      | 当前任务、1–3 个正例/反例    |
| 检索资料        | 40%      | 分块原文，带来源编号         |
| 对话历史        | 10%      | 最近 3–5 轮，摘要化          |
| 保留余量        | 10%      | 给输出与重试                 |

规则：先砍历史，再砍示例，最后才砍检索资料；系统指令不砍。

3. RAG 分块与重排清单

- [ ] 分块按语义，不按固定字数；每块保留原文标题与 URL
- [ ] 每块不超过【N】字，超长再拆，不截断句子
- [ ] 表格与代码单独成块，不混进段落
- [ ] 元数据至少含：来源、日期、版本、章节
- [ ] 检索先粗排（BM25/向量），再重排（交叉编码器）
- [ ] 重排后只留 top【K】块，按来源去重
- [ ] 冲突来源同时保留，标红，不合并
- [ ] 回答必须引用块编号；无命中写「未找到」
- [ ] 每次更新文档跑一遍回归问题集

4. 模型选型工作表

| 约束             | 你的答案 | 排除的产品 |
|------------------|----------|------------|
| 硬件（显存/平台）|          |            |
| 数据能否出网     |          |            |
| 许可（商用/自托管）|        |            |
| 上下文长度需求   |          |            |
| 并发与延迟       |          |            |
| 预算单位（席位/用量）|      |            |
| 中文/多语言要求  |          |            |
| 必须接的生态     |          |            |

结论：主选【 】，备选【 】；理由写三条，不写「综合最强」。

常见误用Common misuses

  • 把模板当提示词直接跑：占位符没填，模型会自由发挥。
  • 预算表只算输入：输出与重试也要留余量。
  • RAG 只调 topK：不重排、不去重，噪声会挤掉正确块。
  • 选型表只填一半：未填的约束会在上线后变成返工。
