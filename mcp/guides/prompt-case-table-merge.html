任务与输入Task and inputs

按规则合并多表并记录冲突。 输入：多个表格、主键、合并规则、优先级。

Output a merged table and conflict log; conflicts are not silently overwritten. Inputs: Multiple tables, key fields, merge rules, and priority.

提示词本体The prompt

按主键 {key} 合并表格。规则：{rules}。输出 merged[] 与 conflicts[]。同主键字段不一致时保留所有候选值并在 conflicts 写来源表与字段；不得按优先级静默覆盖，除非规则明确授权。

占位符用 {字段} 标注，运行前替换为本次输入。

Merge tables on {key}. Rules: {rules}. Output merged[] and conflicts[]. When same-key fields disagree, keep all candidate values and record source table and field in conflicts; do not silently overwrite by priority unless the rules explicitly authorise it.

Replace {field} placeholders with the current inputs before running.

预期输出形态Expected output shape

merged[] 与 conflicts[]，冲突含来源与候选值。

merged[] and conflicts[] with sources and candidate values.

检查点Checkpoints

  • 主键唯一或冲突已记录。
  • 每个覆盖都有规则授权。
  • 行数等于输入主键并集。
  • Keys are unique or conflicts recorded.
  • Every overwrite has rule authorisation.
  • Row count equals the union of input keys.

失败分支Failure branches

  • 主键选错：先核对字段含义。
  • 冲突过多：人工定规则后再跑。
  • Wrong key: check field meanings first.
  • Too many conflicts: define rules manually before rerunning.
