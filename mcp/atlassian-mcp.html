模型与开放条件Model & openness

它自己不调模型，是被 MCP 客户端调用的接口实现。它把 Jira、Confluence、Bitbucket 与 Teamwork Graph 的搜索、 读写能力包装成工具。

供 Claude、Cursor、VS Code、ChatGPT 等 agent 使用（2026-11-21）。

The server does not call models itself. It is an MCP-facing implementation that wraps Jira, Confluence, Bitbucket and Teamwork Graph search and read/write capabilities as tools for Claude, Cursor, VS Code, ChatGPT and other agents (2026-11-21).

运行位置Where it runs

官方云托管远程 MCP server。单端点覆盖 Jira、Confluence 与更多 Atlassian 产品。

官方支持页说明客户端可一键安装到 Cursor、VS Code、ChatGPT、Claude。服务在 Atlassian 云端。不在本地起进程（2026-11-21）。

An officially cloud-hosted remote MCP server: one endpoint covers Jira, Confluence and more Atlassian products. The official support page says clients install it into Cursor, VS Code, ChatGPT and Claude in one click. The service runs in Atlassian’s cloud, not as a local process (2026-11-21).

本地文件Local files

不碰本机文件系统。作用域是 Atlassian 云端站点的 issue、page、Bitbucket 仓库与项目元数据。客户端只持有连接配置与工具调用记录。

站点内容不落本地缓存（2026-11-21）。

No local filesystem access. The scope is issue, page, Bitbucket repository and project metadata on the Atlassian cloud site. The client keeps only connection configuration and tool-call records, with no site content cached locally (2026-11-21).

关机后的任务Tasks after shutdown

请求-响应语义。MCP 工具调用随客户端请求执行。服务在 Atlassian 侧。它没有独立后台任务队列或延时作业。长操作由客户端自身的超时与重试控制（2026-11-21）。

MCP tool calls execute with the client request, and the service runs on Atlassian’s side. There is no independent job queue or delayed work. Long operations are governed by the client’s own timeouts and retries (2026-11-21).

工具与扩展Tools & extensions

官方产品页列 Jira 搜索/创建 issue、Confluence 搜索/创建页面，以及 Cursor、VS Code、ChatGPT、Claude 等客户端接入。

官方支持页另列 Rovo search/fetch、Teamwork Graph 上下文与审计日志能力。完整工具清单按官方文档与客户端工具列表核对（2026-11-21）。

The official product page lists Jira issue search/create and Confluence page search/create, plus Cursor, VS Code, ChatGPT and Claude clients. The support page adds Rovo search/fetch, Teamwork Graph context and audit logging. The full tool list should be checked against the official docs and the client’s tool list (2026-11-21).

上下文与记忆Context & memory

无 server 侧跨会话记忆。每次工具调用按当前 OAuth 2.1 授权与站点状态取数。状态在 Jira/Confluence 本身。

不在 MCP server 里保留对话上下文（2026-11-21）。

There is no server-side cross-session memory. Each tool call reads data under the current OAuth 2.1 grant and site state. State lives in Jira/Confluence, not in conversation context retained by the MCP server (2026-11-21).

权限与限制Permissions & limits

OAuth 2.1 用户鉴权。agent 可见面等于所连账号在站点的权限，含项目级限制。官方文档说明站点或组织管理员可管理、审查或撤销 MCP 应用访问。支持域名与 IP 允许列表。

每次工具调用写入审计日志。写能力直接生效，按「它能替你改 wiki」设防（2026-11-21）。

OAuth 2.1 user authorisation: what the agent can see equals the connected account’s site permissions, including project-level limits. Official docs say site or org admins can manage, review or revoke the MCP app’s access. They also list domain and IP allowlists and an audit-log event for every tool call. Write capabilities take effect directly, so assume it can edit your wiki (2026-11-21).

Data Center 自建版支持状态以官方文档为准（2026-11-21）。

Fit: enterprise development flows where an agent needs Jira requirement context, writes Confluence docs and searches across Bitbucket and Teamwork Graph. Not fit: approval workflows. Data Center self-hosted support should follow the official docs (2026-11-21).
