Supabase 官方 MCP server（Apache-2.0，仓现名 supabase/mcp）：编码 agent 直接查 schema、 跑迁移、看日志。安全口径一句话：它的 SQL 执行面是真的——按「能改库的凭据」设防，裁剪不是沙箱。

Supabase's official MCP server (Apache-2.0, repo now supabase/mcp): agents inspect schema, run migrations, read logs. Security in one line: its SQL execution surface is real — defend as if it can change your database; tool trimming is not a sandbox.

适合与不适合When to use it, when not to

适合：Supabase 栈项目的 agent 开发流（schema/迁移/日志一条龙）。 不适合：要硬只读边界；非 Supabase 项目（它不是通用数据库 server）。

Fits: agent dev flows on the Supabase stack (schema/migrations/logs in one lane). Not a fit: hard read-only boundaries; non-Supabase projects (it is not a generic database server).

模型与开放条件Model & openness

它自己不调模型——被 MCP 客户端调用的接口实现。它把 Supabase 平台能力 （项目、数据库查询、迁移、日志、文档检索）包装成工具给编码 agent 用。

It calls no model itself — an interface implementation called by MCP clients. It wraps Supabase platform capabilities (projects, database queries, migrations, logs, docs retrieval) as tools for coding agents.

权限与限制Permissions & limits

凭据=Supabase 访问令牌，权限面大：能连项目级 API（含 SQL 执行面）。 官方提供工具裁剪与只读类工具区分，但 SQL 写/DDL 能力真实存在—— 接 agent 前按「给它一个能改库的凭据」这个最坏假设设防。

Credential = Supabase access token, a large permission surface: it can reach project-level APIs (including the SQL execution surface). The official side offers tool trimming and read-only tool distinctions, but SQL write/DDL capabilities genuinely exist — before hooking up an agent, defend on the worst-case assumption "you gave it a credential that can modify the database".

适合什么任务Best for

Fits: coding agents directly managing your own Supabase projects (inspect schema, run migrations, read logs). Not a fit: hard boundaries needing "read-only insurance" (trimming narrows but is not a sandbox); non-Supabase-stack projects.

权限范围Permission scope

项目级：读 schema、执行 SQL（含写/DDL）、管迁移、看日志。 工具组裁剪可缩小暴露面；无工具级人工审批机制的官方说明。

Project level: read schema, execute SQL (including writes/DDL), manage migrations, read logs. Tool-group trimming can shrink the exposure surface; no official docs for a tool-level human approval mechanism.
