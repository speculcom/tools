索引算法、上下文窗口、会话恢复与分叉、跨会话记忆边界。Indexing algorithm, context window, session resume and fork, and the boundary of cross-session memory.

传输方式Transport

认证机制Authentication

怎么证明身份。注意认证 ≠ 授权，前者是「你是谁」，后者是「你能做什么」。How identity is proved. Note that authentication is not authorisation: the former is who you are, the latter is what you may do.

为什么这里不给总分排名Why there is no overall ranking

这不是省略，是方法上的明确取舍。This is not an omission but a deliberate methodological choice.

  • 缺统一实测，就不给分。跨工具的跑分口径不同——题目、预算、执行环境都不一样，A 的 90 分和 B 的 88 分不可比。No shared measurement, no score. Benchmarks across tools use different rules — different questions, budgets and environments. A 90 and a B 88 are not comparable.
  • 「未知」是合法答案。查不到就写「未知」并说明为什么，不用推测填充。缺信息本身也是信息。"Unknown" is a legitimate answer. If it cannot be found, we write "unknown" and explain why, instead of filling the gap with guesses. Missing information is itself information.
  • 来源链接、类型与核验日都在详情页里，可以逐条回去复核。The source link, its kind and the checked date are all on the detail page, so you can walk any of them back and re-check.
  • lifecycle 单独标注。核验日新不等于数据有效——上游归档后数据会失效，所以单独标 active / maintenance / archived。lifecycle is marked separately. A recent check date does not mean the data is still valid — it goes stale when upstream archives the repo, so active / maintenance / archived are tracked separately.
  • 不同族不混排。找现成的、自己搭的、接上与跑起来的是三种角色，坐标系不同；硬合成一张总表只会制造假的可比性。Families are not mixed. Ready-made tools, things you build yourself, and plug-in-and-run components are three different roles with different coordinate systems; forcing them into one master table would manufacture false comparability.
