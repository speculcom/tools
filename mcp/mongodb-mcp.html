MongoDB's official MCP server (mongodb-js repo, Apache-2.0): agents connect to databases, query collections, run aggregations, write data, manage Atlas. Honest note: the docs/mcp path 404s — the live official line is the GitHub repo. Delete tools carry confirmation parameters, but confirmation is not a sandbox — credentials are the boundary.
