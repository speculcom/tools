模型与开放条件Model & openness

它自己不调模型——被 MCP 客户端调用的接口实现。它把 Stripe 后台能力包装成工具给 agent 用。含产品、价格、客户、支付查询与文档检索。

It calls no model itself — an interface implementation called by MCP clients. It wraps Stripe dashboard capabilities (product/price/customer/payment queries, docs retrieval) as tools for agents.

运行位置Where it runs

本地进程（Python/TS 包起 stdio）为主。GitHub stripe/ai 2,000★。最近推送 2026-10-30（API 核验）。

Stripe 另有 agentic commerce 产品线（ACP 等）。 那是「agent 直接收款」的另一层。不算这个 server 本体。

Mainly a local process (Python/TS packages starting stdio); GitHub stripe/ai 2,000★, last push 2026-10-30 (API verified). Stripe also has an agentic commerce product line (ACP etc.) — that is a separate layer of "agents taking payments directly" and does not count as this server itself.

本地文件Local files

不碰本机文件系统。作用域是 Stripe 云端账户数据（customers/products/invoices 等）。

Never touches the local file system — the scope is Stripe cloud account data (customers/products/invoices etc.).
