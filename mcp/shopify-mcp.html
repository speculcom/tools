Shopify 官方 Dev MCP server（npm ISC，本地 stdio，无鉴权）：给编码 agent 补 Shopify 平台上下文—— 文档检索（search_dev_docs/fetch_docs_by_path）+ Admin GraphQL schema 探查（introspect_admin_schema）。 它是 Shopify AI Toolkit 三形态之一（插件 / agent skills / Dev MCP）； GitHub 无独立 dev-mcp 仓（代码随 npm 发布），inventory 旧 URL agents-of-change 已 404。 纯读面、不碰店铺数据——店铺操作走 Shopify CLI 线，别混。

Shopify official Dev MCP server (npm ISC, local stdio, no auth): gives your coding agent Shopify platform context — doc retrieval (search_dev_docs/fetch_docs_by_path) + Admin GraphQL schema probing (introspect_admin_schema). It is one of the three forms of the Shopify AI Toolkit (plugin / agent skills / Dev MCP); there is no standalone dev-mcp GitHub repo (code ships with npm), and the inventory's old agents-of-change URL is now 404. Pure read — it never touches store data; store operations go through the Shopify CLI line, don't mix them.

适合与不适合When to use it, when not to

适合：Shopify 开发者要 agent 写对 API 字段/schema/CLI；零鉴权零配置起步。 不适合：要 agent 直接操作店铺（无店铺面）；非 Shopify 生态。

Fits: Shopify developers having agents write correct API fields/schema/CLI; zero-auth zero-config start. Not a fit: agents operating the store directly (no store surface); non-Shopify ecosystems.

The release line lives on npm (1.18.0, 2026-10-27, 143 versions); there is no standalone dev-mcp GitHub repo (Shopify/dev-mcp is 404) — the code ships with the npm package, while the plugin/skills line lives in the Shopify/Shopify-AI-Toolkit repo (MIT 621★, pushed 2026-10-27). 不需要鉴权（官方明写 server 本地跑无 auth）——它只读公开文档与 schema， 不碰你的店铺数据；要店铺操作（建 app/主题/跑 CLI）走 Shopify CLI 的认证上下文， 那是 AI Toolkit 的另一条线，不是这个 MCP server 的能力。 instrumentation 遥测默认开，OPT_OUT_INSTRUMENTATION=true 退出。

No authentication needed (the official docs state the local server needs no auth) — it only reads public docs and schemas, it never touches your store data; store operations (creating apps/themes, running the CLI) go through Shopify CLI's authenticated context, which is a different line of the AI Toolkit, not this MCP server's capability. Instrumentation telemetry is on by default; OPT_OUT_INSTRUMENTATION=true opts out.
