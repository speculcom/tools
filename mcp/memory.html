用本地知识图谱做跨会话持久记忆的 reference server。它记忆落盘、跨会话共享，但没有访问控制。

A reference server implementing cross-session persistent memory with a local knowledge graph — memory is written to disk, shared across sessions, with no access control.

适合与不适合When to use it, when not to

让 Agent 跨会话记住用户偏好、项目背景等长期信息。

不适合存放需要审计或追溯的场景（图谱会原地修改）， 也不适合存放高敏感信息——记忆文件无加密、无独立访问控制， 任何能读该文件的进程都能拿到全部记忆。

Scenarios needing cross-session memory that survives restarts and is queryable as a graph.

Not a fit for anything with access-control requirements — memory is written to disk with no access control.

数据结构Data structures

关系用主动语态存储，如 works_at 而非 works at。这是文档里的明确约定。

ConceptDescriptionExample
Entitya graph node with a unique name, type and observation list{name: "X", entityType: "person", observations: [...]}
Relationa directed connection between entities{from: "A", to: "B", relationType: "works_at"}
Observationan atomic fact attached to an entityone fact per observation is recommended

Relations are stored in active voice, e.g. works_at rather than "works at". This is an explicit convention in the docs.
