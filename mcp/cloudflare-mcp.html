模型与开放条件Model & openness

它自己不调模型——被 MCP 客户端调用的接口实现。它把 Cloudflare 平台 （Workers、Pages、D1、R2、DNS、docs 检索等）包装成工具给 agent 用。

It calls no model itself — an interface implementation called by MCP clients. It wraps the Cloudflare platform (Workers, Pages, D1, R2, DNS, docs retrieval, etc.) as tools for agents.

权限与限制Permissions & limits

API token 权限=agent 权限：Cloudflare token 可细粒度限定资源与操作面—— 官方推荐用受限 token 接 MCP。这是同类里凭据粒度做得最细的一条线， 但「能部署代码到 Workers」意味着能跑任意代码——按此最坏面设防。

API-token permissions = agent permissions: Cloudflare tokens can narrowly restrict resources and operation surfaces — the official recommendation is to connect MCP with a restricted token. This is the finest-grained credential line among its peers, but "able to deploy code to Workers" means able to run arbitrary code — defend against that worst case.

适合什么任务Best for

适合：Cloudflare 栈的 agent 部署流（写 Worker→部署→查日志）、docs 检索。 不适合：要「只配置不部署」的硬边界（token 粒度能收窄但要仔细配）。

Fits: the agent deployment flow on the Cloudflare stack (write Worker → deploy → check logs), docs retrieval. Not a fit: a hard "configure but never deploy" boundary (token granularity can narrow it, but must be configured carefully).
