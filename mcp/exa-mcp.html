工具与扩展Tools & extensions

默认两工具：web_search_exa（搜索取干净内容）、web_fetch_exa（按 URL 读全文 markdown）； 可选工具经 URL 参数 ?tools= 开启：web_search_advanced_exa（过滤/域名/日期/子页爬取）、 agent_run（Exa Agent 多步研究/列表构建/结构化输出）。 仓内 skills/ 目录带 search 与 exa-agent 两个 Agent Skill（插件安装时装载）。

Two tools by default: web_search_exa (search for clean content), web_fetch_exa (read full-page markdown by URL); optional tools are enabled via the URL parameter ?tools=: web_search_advanced_exa (filters/domains/dates/subpage crawling), agent_run (Exa Agent multi-step research / list building / structured output). The repo's skills/ directory ships two Agent Skills, search and exa-agent (loaded when the plugin is installed).

No server-side cross-session memory — each retrieval is independent; multi-step state lives inside the Exa Agent task.

权限与限制Permissions & limits

匿名可用：托管端点匿名接入带速率限制（官方 README 口径）； 提额与 Exa Agent 要 OAuth（推荐，客户端弹登录）或 API key （?exaApiKey= 参数 / Authorization Bearer / x-api-key 三种传法）。 纯读面——不能写任何系统，风险面是查询内容外发与配额。

Usable anonymously: the hosted endpoint accepts anonymous connections with rate limits (official README wording); higher quotas and Exa Agent require OAuth (recommended, the client pops a login) or an API key (three ways: ?exaApiKey= parameter / Authorization Bearer / x-api-key). Purely read-only surface — it cannot write to any system; the risk surface is query content leaving your machine and quota.

适合什么任务Best for

适合：给 agent 一路「搜索+读正文」二合一的检索面（默认两工具就覆盖）、 零门槛接入（匿名可用）、要多步研究 Agent 的进阶面。 不适合：要深度站点级爬取编排（crawl/map 这类面在 firecrawl 线）； 要完全离线（托管线要连 Exa）。

Fits: giving an agent one route with a combined "search + read text" retrieval surface (the two default tools cover it), zero-barrier onboarding (anonymous works), and the advanced multi-step research Agent surface. Not a fit: deep site-level crawl orchestration (the crawl/map surface lives in the firecrawl line); fully offline use (the hosted line needs to reach Exa).
