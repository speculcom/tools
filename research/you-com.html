关机后的任务Tasks after shutdown

问答即时返回。Research API 在单次请求内完成多轮搜索、交叉引用与综合。属同步 API 而非可暂停作业队列。企业批量任务由调用方自行排队（2026-11-21）。

Q&A returns immediately; the Research API runs multiple searches, cross-references sources and synthesises within one request, making it a synchronous API rather than a pauseable job queue. Enterprise batch work must be queued by the caller (2026-11-21).
