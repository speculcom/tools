模型与开放条件Model & openness

自研检索+生成架构。Trantora AI index 覆盖 25B+ 页面。按语义与可信度排序，垃圾在入库时过滤。生成侧用 ensemble of models。

API 按 searchMode 分 low-cost、fast、balanced、deep、exhaustive 五档自动/手动选择（2026-11-21）。

An in-house retrieval-plus-generation stack: the Trantora AI index covers 25B+ pages, ranks by meaning and credibility and filters spam at ingestion; generation uses an ensemble of models, and the API exposes low-cost, fast, balanced, deep and exhaustive searchMode tiers, auto-selected or pinned (2026-11-21).

运行位置Where it runs

依据： 网页 andisearch.com + PWA + Chrome 扩展 + REST API（https://api.andiai.com）+ 远程 MCP（https://api.andiai.com/mcp）+ CLI。检索与生成在厂商云端，CLI 在本地（2026-11-21）。

Web at andisearch.com plus a PWA, Chrome extension, REST API (https://api.andiai.com), remote MCP (https://api.andiai.com/mcp) and CLI; retrieval and generation run in the vendor cloud, while the CLI runs locally (2026-11-21).

本地文件Local files

匿名使用时不建账户。设置与历史只存浏览器本地。API 返回结构化 JSON 或 LLM-ready Markdown。format=context 直接喂 RAG，不在本地落文件。

CLI 读 ANDI_API_KEY 环境变量（2026-11-21）。

Anonymous use needs no account: settings and history stay in browser storage. The API returns structured JSON or LLM-ready Markdown, with format=context feeding RAG directly and no local file writes; the CLI reads ANDI_API_KEY from the environment (2026-11-21).

关机后的任务Tasks after shutdown

请求-响应式。fast 模式亚秒返回，deep 约 2–3 秒。exhaustive 覆盖最大。无托管任务队列或关机续跑形态。长任务由调用方自己拆（2026-11-21）。

Request-response: fast mode returns sub-second, deep takes about 2–3 seconds and exhaustive maximises coverage. There is no hosted job queue or resume-after-shutdown surface; long workflows are split by the caller (2026-11-21).

工具与扩展Tools & extensions

直接答案+来源标注、Reader Mode 去广告阅读、Summarize、News/Images/Videos 标签。

API 有 /api/v1/search、/api/v1/fetch、多查询（最多 5 条合并去重）、OpenSearch 兼容端点、format=context 与 MCP 搜索/抓页工具（2026-11-21）。

Direct answers with sources, an ad-free Reader Mode, Summarize and News/Images/Videos tabs; the API offers /api/v1/search, /api/v1/fetch, multi-query (up to five merged and deduplicated), an OpenSearch-compatible endpoint, format=context and MCP search/fetch tools (2026-11-21).

上下文与记忆Context & memory

匿名搜索不记录、不存画像，跨会话没有记忆。登录账户只存提供功能所需的信息。浏览器本地保存设置与历史。MCP/API 每次调用独立（2026-11-21）。

Anonymous searches are not logged and no profile is built, so there is no cross-session memory; signed-in accounts store only what the feature needs; browser storage holds local settings and history, and each MCP/API call is independent (2026-11-21).

权限与限制Permissions & limits

消费端免费、无广告、无追踪、默认匿名。API 按结果计费（官方标 <1¢/query，响应里给 metrics.cost_dollars），用 x-api-key 鉴权。

隐私政策承诺不出售数据、不记录搜索（2026-11-21）。

The consumer product is free, ad-free, untracked and anonymous by default; the API is outcome-priced (official page cites under 1¢ per query, with metrics.cost_dollars in each response) and authenticated with x-api-key; the privacy policy promises no data sales and no search logging (2026-11-21).
