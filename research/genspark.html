运行位置Where it runs

网页（genspark.ai）+ App。官方帮助中心说明 Super Agent 在云端计算机上规划并执行步骤。New 模式每个项目分配一台全新云电脑。

Classic 模式无云电脑（2026-11-21）。

Web (genspark.ai) plus apps. The official help centre says Super Agent plans and executes on a cloud computer, with New mode giving each project a fresh cloud computer and Classic mode running without one (2026-11-21).

本地文件Local files

产物（报告/页面/表格/PPT）存账户侧云端与项目工作区。官方帮助中心说明每个项目有自己的聊天、文件与云电脑，产物可下载归本地。未见官方本机模型面（2026-11-21）。

Outputs such as reports, pages, sheets and decks live in the account cloud and the project workspace; the official help centre says each project has its own chat, files and cloud computer, and outputs can be downloaded locally. Official pages list no local model surface (2026-11-21).

关机后的任务Tasks after shutdown

任务制：提交任务→云端多步执行→产物进项目库。官方帮助中心说明长任务最长运行 2 小时。关闭标签页后仍继续。Super Agent 不支持定时任务，2026-11-21 核验。

A task model: submit a task → multi-step cloud execution → outputs land in the project library. The official help centre says long jobs can run for up to two hours, keep going after the tab closes, and Super Agent cannot run scheduled jobs (2026-11-21).

上下文与记忆Context & memory

以项目组织：每个项目包含聊天、文件与云电脑，任务上下文在项目内延续。官方帮助中心未列跨项目长期记忆。GenTeam 明确私聊内容不会带入群聊（2026-11-21）。

Organised by project: each project carries its own chat, files and cloud computer, so task context persists within the project. The official help centre lists no cross-project long-term memory, and GenTeam states that direct-message content is not carried into group chats (2026-11-21).

权限与限制Permissions & limits

账号+积分/订阅体系。官方帮助中心说明云端 agent 消耗创建者的积分。个人电脑上的 agent 使用本机模型访问。

企业版宣称 SOC 2 Type II、ISO 27001、Zero model training。数据保留与删除按隐私页（2026-11-21）。

Accounts plus credits/subscriptions. The official help centre says cloud agents consume their creator’s credits, while agents on a personal computer use that machine’s model access. Business plans claim SOC 2 Type II, ISO 27001 and zero model training, with retention and deletion governed by the privacy page (2026-11-21).
